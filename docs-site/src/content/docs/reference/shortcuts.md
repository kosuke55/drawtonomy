## Tool switching

| Key  | Tool                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (pan)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Edit operations

| Keys | Function |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copy |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Paste |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Cut |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete selected shape(s) |

## Modifiers while drawing

| Modifier | Effect |
|---|---|
| <kbd>Shift</kbd> | Temporarily disable [snap](/guides/snap/) |
| <kbd>Alt</kbd> + click | [Share an existing point](/guides/point-sharing/) (Linestring / Polygon / Path) |
| Double-click | Enter [segment editing](/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Movement

| Keys | Effect |
|---|---|
| Arrow keys | Move selection by 1 px |
| <kbd>Shift</kbd> + arrow | Move selection by 10 px |
