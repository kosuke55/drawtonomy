## Hình mẫu kịch bản lái xe

| Hình mẫu | Mục đích |
|---|---|
| **Linestring** | Đường liên tục, dùng cho biên làn đường, lề đường, vạch kẻ. |
| **Lane** | Một làn đường có thể đi được với hai biên, một đường tâm và các khe kết nối (Next / Previous / Left / Right). |
| **Vehicle** | Phương tiện được mẫu hóa (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | Người đi bộ được mẫu hóa (Walking, Simple). |
| **Path** | Quỹ đạo dùng cho mũi tên, nhóm dấu chân hoặc đường đi kịch bản. Kiểu mũi tên hoặc dải. |
| **Polygon** | Vùng đóng (bãi đậu xe, vùng gạch chéo). |
| **Crosswalk** | Vạch sang đường được tạo kiểu sẵn. |
| **TrafficLight** | Tín hiệu phương tiện hoặc người đi bộ. |
| **Intersection** | Mẫu giao lộ nhiều làn. |

## Hình mẫu cơ bản

| Hình mẫu | Mục đích |
|---|---|
| **LineArrow** | Mũi tên đoạn đơn. |
| **Arrow** | Mũi tên tự do. |
| **Text** | Văn bản thuần hoặc có chú thích. |
| **Freehand** | Vẽ với nét bút. |
| **Rectangle** | Hình chữ nhật căn theo trục. |
| **Ellipse** | Hình elip căn theo trục. |
| **Image** | PNG / JPG / SVG được nhập vào. |

## Mẫu tùy chỉnh

Bạn có thể thêm các mẫu SVG cho phương tiện, người đi bộ, vạch kẻ đường và biển báo. Quy trình đóng góp nằm trong [Hướng dẫn Mẫu](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
