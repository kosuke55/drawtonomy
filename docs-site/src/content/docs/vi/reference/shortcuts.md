## Chuyển đổi công cụ

| Phím  | Công cụ                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (pan)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Thao tác chỉnh sửa

| Phím | Chức năng |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Hoàn tác |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Làm lại |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Sao chép |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Dán |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Cắt |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Xóa hình mẫu được chọn |

## Phím sửa đổi khi vẽ

| Phím sửa đổi | Hiệu ứng |
|---|---|
| <kbd>Shift</kbd> | Tạm thời tắt [snap](/vi/guides/snap/) |
| <kbd>Alt</kbd> + nhấp | [Chia sẻ một điểm hiện có](/vi/guides/point-sharing/) (Linestring / Polygon / Path) |
| Nhấp đúp | Vào [chỉnh sửa đoạn](/vi/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Di chuyển

| Phím | Hiệu ứng |
|---|---|
| Phím mũi tên | Di chuyển vùng chọn 1 px |
| <kbd>Shift</kbd> + mũi tên | Di chuyển vùng chọn 10 px |
