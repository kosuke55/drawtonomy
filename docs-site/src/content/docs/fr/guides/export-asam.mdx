drawtonomy peut exporter votre scène en ASAM [OpenDRIVE](https://www.asam.net/standards/detail/opendrive/) (`.xodr`) et [OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/) (`.xosc`), ou regrouper les deux dans une archive zip prête pour la lecture [esmini](https://github.com/esmini/esmini).

![Une scène drawtonomy rejouée dans esmini après export](/img/asam-esmini.png)

## Exporter depuis l'éditeur

1. Dessinez votre scène (voies, véhicules, feux tricolores…).
2. Ouvrez **Fichier → Exporter → Exporter pour esmini**.
3. Saisissez un nom de base lorsque demandé.
4. Une archive `<nom>.zip` contenant `<nom>.xodr` et `<nom>.xosc` se télécharge.

## La rejouer

```bash
unzip ma-scene.zip
esmini --osc ma-scene/ma-scene.xosc --window 60 60 1024 768
```

## Formats individuels

Si vous n'avez besoin que de l'un des deux :

- **Fichier → Exporter → OpenDRIVE (.xodr)**
- **Fichier → Exporter → OpenSCENARIO (.xosc)**

## Export programmatique

L'exporteur fait partie de `@drawtonomy/sdk` et fonctionne sans l'éditeur. Utilisez-le dans des pipelines CI, des outils côté serveur ou des extensions de navigateur :

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'ma-scene',
})
```

Pour l'API complète et les points d'extension, voir la [référence du SDK Exporteur](/fr/extend/exporter-sdk/).

|---|---|
| OpenDRIVE | 1.8 |
