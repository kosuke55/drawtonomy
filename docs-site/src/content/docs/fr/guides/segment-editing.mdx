L'édition de segments vous permet d'ajuster les formes entre deux sommets adjacents, d'ajouter un nouveau sommet, ou d'en supprimer un — sans redessiner la forme depuis le début.

<Demo src="/videos/segment-demo.mp4" caption="Double-cliquez pour entrer en mode édition de segment, puis glissez un point ou cliquez sur un segment pour en ajouter un." />

## Entrer en mode édition de segments

1. Appuyez sur <kbd>V</kbd> pour l'outil Sélection.
2. Double-cliquez sur un Linestring, une Voie ou un Polygone.
3. La forme bascule en mode édition de points : chaque sommet devient une poignée indigo glissable.

## Déplacer un point

Cliquez et glissez un sommet. Si le point est partagé avec une autre forme (voir [Partage de points](/fr/guides/point-sharing/)), toutes les formes qui le contiennent se déplacent ensemble.

Pour les voies, glisser un point de bord met à jour les deux voies qui partagent ce bord — voir [Modèle de connexions de voies](/fr/explanation/lane-model/).

## Ajouter un point

Cliquez n'importe où sur un segment (la ligne entre deux points existants). Un nouveau sommet est inséré à la position du clic.

C'est la façon la plus rapide d'introduire une courbe dans une section précédemment droite : ajoutez un point, puis glissez-le.

## Supprimer un point

Sélectionnez le sommet (il devient indigo plein) et appuyez sur <kbd>Suppr</kbd> ou <kbd>Retour arrière</kbd>.

## Quitter l'édition de segments

Appuyez sur <kbd>Échap</kbd>, cliquez en dehors de la forme, ou choisissez un autre outil. La forme revient au mode de sélection normal.
