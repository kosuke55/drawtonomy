drawtonomy propose plusieurs formats d'export. Celui qu'il faut privilégier la plupart du temps est **drawtonomy.svg** — un SVG standard avec des métadonnées additionnelles, qui vous permet de rouvrir le fichier et de reprendre où vous en étiez. C'est aussi un SVG valide ; il s'affiche donc correctement dans les navigateurs, présentations et chaînes de documentation, sans conversion.

Les autres formats — PNG, JPG, SVG (plat), PDF, EPS — sont destinés aux cas où vous voulez une image statique sans avoir besoin de la rééditer.

Pour la sortie vers les simulateurs de conduite (OpenDRIVE / OpenSCENARIO / Lanelet2), voir la page dédiée [Export ASAM](/fr/guides/export-asam/).

## Par où commencer : drawtonomy.svg

`drawtonomy.svg` préserve les IDs des formes, les connexions de voies, les points partagés, les groupes d'empreinte, le style et les relations *quelle-forme-est-au-dessus*. Le même fichier est :

- **Ré-éditable.** Glissez-le à nouveau dans drawtonomy et la scène réapparaît exactement comme vous l'aviez laissée — chaque connexion, point partagé et relation de superposition intact.
- **Prévisualisable.** C'est un SVG valide ; GitHub, navigateurs, rendus Markdown et outils de présentation l'affichent correctement sans conversion.
- **Adapté à la documentation.** Vectoriel, échelle propre, faible taille de fichier, aucun artefact de pixellisation. Il reste net à n'importe quel zoom dans un README ou la figure d'un article.

`drawtonomy.svg` est un choix par défaut raisonnable pour tout ce qui pourrait être réédité, partagé avec un collègue qui utilise drawtonomy, ou intégré dans la documentation technique.

### Enregistrer en drawtonomy.svg

1. Ouvrez le menu (en haut à gauche).
2. Cliquez sur **Exporter**.
3. Choisissez **drawtonomy.svg**.

Le fichier se télécharge avec un nom basé sur le titre de la scène.

### Rouvrir

Glissez le fichier à nouveau dans drawtonomy, ou utilisez **Importer** dans le même menu. La scène complète apparaît dans un nouvel onglet, chaque forme étant sélectionnable. Le panneau d'attributs affiche une section **OBJETS QUI SE CHEVAUCHENT** lorsque vous cliquez dans une zone où des formes se superposent — la relation entre, disons, un véhicule et la voie sur laquelle il repose survit à l'aller-retour.

## Autres formats d'image

Lorsque vous n'avez besoin que d'une image plate — ni édition, ni métadonnées — choisissez l'un de ceux-ci dans le même menu Exporter.

| Format | À utiliser pour | Notes |
|---|---|---|
| **PNG** | Présentations, documents, pages web | Raster sans perte. |
| **JPG** | Fichiers plus petits sans transparence | Raster avec perte. |
| **SVG** (plat) | Post-traitement dans Illustrator / Inkscape, intégration web | Visuellement identique à drawtonomy.svg, mais les métadonnées sont supprimées. |
| **PDF** | Impression, archivage, articles | Vectoriel, prend en charge la transparence. |
| **EPS** | Chaînes d'édition héritées | Vectoriel. **Ne prend pas en charge la transparence** — voir ci-dessous. |

### EPS et transparence

EPS n'encode pas la transparence. Une forme avec une opacité de 60 % sera exportée à pleine opacité. Si votre scène repose sur la transparence, exportez plutôt en PDF ou SVG.
