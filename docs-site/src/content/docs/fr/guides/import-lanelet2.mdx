drawtonomy peut lire les cartes au format OSM [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2). Des cartes d'exemple sont disponibles dans la [documentation Autoware](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="Importation d'un fichier Lanelet2 complet." />

## Importer le fichier complet

1. Ouvrez le menu **Fichier** → **Importer**.
2. Choisissez le fichier `.osm`.
3. drawtonomy parse le fichier et peuple le canevas avec des formes Voie ainsi que leurs connexions.

## N'importer que certaines voies

Pour les grandes cartes, importer toutes les voies ralentira l'éditeur. Utilisez plutôt la boîte de dialogue de sélection de voies :

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="Sélectionnez par glissement uniquement les voies qui vous intéressent, puis importez." />

1. Ouvrez le menu **Fichier** → **Importer → Sélectionner des voies**.
2. drawtonomy affiche une carte de prévisualisation.
3. Cliquez ou glissez pour sélectionner les voies souhaitées.
4. Cliquez sur **Importer la sélection**.

## Conseils de performance

Gardez la scène importée sous environ **500 voies** pour un éditeur réactif. Pour des zones plus vastes, répartissez votre travail sur plusieurs fichiers, ou n'importez que la région nécessaire.

## Après l'import

Les voies importées sont des formes Voie pleine fidélité ; les connexions du fichier Lanelet2 sont préservées. Éditez, [lissez](/fr/guides/smooth-lanes/) ou [exportez](/fr/guides/export-asam/) sans perdre la topologie.
