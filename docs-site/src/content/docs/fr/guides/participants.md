drawtonomy fournit des modèles pour les acteurs et les éléments de circulation dont vous avez besoin dans les scénarios de conduite.

## Véhicules

1. Appuyez sur <kbd>P</kbd> pour ouvrir **Participants**.
2. Choisissez un modèle de véhicule (Berline, Bus, Camion, Moto).
3. Cliquez sur le canevas pour le placer. Le véhicule apparaît à la taille par défaut du modèle.

Glissez une poignée de coin pour redimensionner. Glissez la poignée de rotation pour l'aligner avec une voie.

## Piétons

Dans le même menu Participants, choisissez un modèle de piéton (Marchant, Simple).

## Feux tricolores

Le menu Participants comprend également les signaux véhicules et piétons. Placez-les aux coins des intersections. Ce sont des formes statiques ; elles ne simulent pas les phases de signalisation.

## Modèles personnalisés

Vous pouvez ajouter vos propres modèles SVG et les contribuer par PR. Voir le [Guide des modèles](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).

## Peupler une trajectoire de véhicules

Pour placer une rangée de véhicules le long d'une trajectoire (pour des diagrammes d'intervalle ou des scènes en file), utilisez l'[Empreinte de trajectoire](/fr/guides/path-footprint/).
