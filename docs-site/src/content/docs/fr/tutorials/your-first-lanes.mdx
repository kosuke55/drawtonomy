Cette leçon suit la démo officielle de l'outil Voie. À la fin, vous aurez utilisé les deux façons dont drawtonomy crée des voies :

- **Mode Ligne médiane** — vous dessinez la ligne médiane ; les bords gauche et droit sont générés pour vous.
- **Mode Bord** — vous choisissez deux linestrings de bord existants et drawtonomy ajuste une voie entre eux.

La démo dessine deux voies en mode Ligne médiane, puis bascule en mode Bord pour une troisième voie qui comble l'écart.

<Demo src="/videos/lane-tool-demo.mp4" caption="Deux voies en mode Ligne médiane, puis une troisième voie construite à partir de bords existants en mode Bord." />

## 1. Sélectionner l'outil Voie

Ouvrez [drawtonomy.com](https://drawtonomy.com). Appuyez sur <kbd>N</kbd> (ou cliquez sur l'icône de voie dans la barre d'outils inférieure).

Le côté droit de l'écran affiche maintenant le panneau de création **Voie**, avec **Ligne médiane** sélectionné par défaut :

![Panneau Voie — mode Ligne médiane actif, Largeur de voie 50 px](/img/frames/lane-tool-panel.png)

Laissez les valeurs par défaut pour le moment.

## 2. Dessiner deux voies en mode Ligne médiane

En mode Ligne médiane, cliquez sur le canevas pour déposer le premier point de la ligne médiane, cliquez à nouveau plus loin pour déposer le suivant, puis appuyez sur <kbd>Entrée</kbd> pour terminer. Les bords gauche et droit apparaissent automatiquement à l'aide de la valeur **Largeur de voie** (50 px par défaut).

L'outil Voie reste actif après chaque voie ; cliquez donc à nouveau ailleurs pour commencer la deuxième. Déposez quelques points à droite de la première voie et appuyez sur <kbd>Entrée</kbd> :

![Deux voies dessinées côte à côte en mode Ligne médiane](/img/frames/lane-tool-two-lanes.png)

À ce stade, les deux voies sont indépendantes — elles ne partagent aucun bord et ne se connaissent pas.

## 3. Basculer en mode Bord

Cliquez sur **Bord** dans le même panneau, à côté de **Ligne médiane**, pour changer de mode de création. En mode Bord, vous ne cliquez pas dans le vide ; vous cliquez sur des **linestrings de bord existants**, et drawtonomy ajuste une voie entre eux.

Survolez le **bord droit de la voie de gauche** — drawtonomy met le linestring en surbrillance indigo lorsque le curseur est suffisamment proche — et cliquez :

![Mode Bord — le bord droit de la voie de gauche est en surbrillance, prêt à être sélectionné](/img/frames/lane-tool-boundary-mode.png)

Cliquez ensuite sur le **bord gauche de la voie de droite**. Une nouvelle voie remplit l'écart, en utilisant les deux linestrings cliqués comme bords gauche et droit.

## 4. Inspecter le résultat

Appuyez sur <kbd>V</kbd> pour l'outil Sélection et cliquez sur la nouvelle voie centrale. Le panneau de droite bascule sur ses attributs :

![Panneau d'attributs — la nouvelle voie centrale partage les bords way/1 et way/2 avec ses voisines](/img/frames/lane-attributes.png)

Les bords sont réutilisés :

- **ID de voie** — `lane/2`, une toute nouvelle voie.
- **Bord gauche** — `way/1`, le même linestring que le bord droit de la voie de gauche.
- **Bord droit** — `way/2`, partagé de la même manière avec la voie de droite.

Comme les bords sont partagés, glisser un point de chaque côté déplace les deux voies adjacentes ensemble. C'est sur ce principe que reposent les [connexions de voies](/fr/explanation/lane-model/) ; lisez cette page ensuite pour le modèle sous-jacent.

Le panneau expose également **Direction**, **Couleur de voie**, **Opacité de voie** et les quatre emplacements de connexion **Voies suivantes / Voies précédentes / Voie gauche / Voie droite**, que nous laissons vides pour le moment.

## Ce que vous avez appris

- Les voies peuvent être dessinées de deux façons : à partir d'une ligne médiane, ou en sélectionnant deux linestrings de bord existants.
- Le mode Ligne médiane est l'option rapide pour un canevas vide ; le mode Bord insère une voie entre une géométrie existante sans rien redessiner.
- Une voie construite à partir de bords existants partage ces bords avec ses voisines.
