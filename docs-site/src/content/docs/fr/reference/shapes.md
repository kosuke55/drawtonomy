## Formes pour scénarios de conduite

| Forme | Rôle |
|---|---|
| **Linestring** | Ligne continue, utilisée pour les bords de voies, bordures, marquages. |
| **Voie** | Voie carrossable avec deux bords, une ligne médiane et des emplacements de connexion (Suivante / Précédente / Gauche / Droite). |
| **Véhicule** | Véhicule par modèle (Berline, Bus, Camion, Moto). |
| **Piéton** | Piéton par modèle (Marchant, Simple). |
| **Trajectoire** | Trajectoire utilisée pour flèches, groupes d'empreintes ou trajectoires de scénario. Style flèche ou bande. |
| **Polygone** | Zone fermée (parking, zone hachurée). |
| **Passage piéton** | Passage piéton pré-stylisé. |
| **Feu tricolore** | Signal véhicule ou piéton. |
| **Intersection** | Modèle de carrefour multi-voies. |

## Formes de base

| Forme | Rôle |
|---|---|
| **Flèche linéaire** | Flèche à un seul segment. |
| **Flèche** | Flèche libre. |
| **Texte** | Texte simple ou annoté. |
| **Main levée** | Tracé au stylo. |
| **Rectangle** | Rectangle aligné sur les axes. |
| **Ellipse** | Ellipse alignée sur les axes. |
| **Image** | PNG / JPG / SVG importé. |

## Modèles personnalisés

Vous pouvez ajouter des modèles SVG pour véhicules, piétons, marquages au sol et panneaux. Le flux de contribution est dans le [Guide des modèles](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
