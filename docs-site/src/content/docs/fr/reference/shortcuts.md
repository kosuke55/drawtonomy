## Changement d'outil

| Touche  | Outil                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Main (déplacer)            |
| <kbd>V</kbd>    | Sélection                  |
| <kbd>L</kbd>    | Linestring                 |
| <kbd>N</kbd>    | Voie                       |
| <kbd>P</kbd>    | Participants (Véhicule / Piéton) |
| <kbd>H</kbd>    | Trajectoire                |
| <kbd>G</kbd>    | Polygone                   |
| <kbd>X</kbd>    | Passage piéton             |
| <kbd>I</kbd>    | Intersection               |
| <kbd>W</kbd>    | Flèche linéaire            |
| <kbd>T</kbd>    | Texte                      |
| <kbd>D</kbd>    | Main levée                 |

## Opérations d'édition

| Touches | Fonction |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Annuler |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Rétablir |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copier |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Coller |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Couper |
| <kbd>Suppr</kbd> / <kbd>Retour arrière</kbd> | Supprimer la ou les forme(s) sélectionnée(s) |

## Modificateurs en cours de tracé

| Modificateur | Effet |
|---|---|
| <kbd>Maj</kbd> | Désactive temporairement l'[accrochage](/fr/guides/snap/) |
| <kbd>Alt</kbd> + clic | [Partager un point existant](/fr/guides/point-sharing/) (Linestring / Polygone / Trajectoire) |
| Double-clic | Entrer en [édition de segments](/fr/guides/segment-editing/) (Linestring / Voie / Polygone) |

## Déplacement

| Touches | Effet |
|---|---|
| Flèches | Déplacer la sélection de 1 px |
| <kbd>Maj</kbd> + flèche | Déplacer la sélection de 10 px |
