Cinq minutes du canevas vide à une scène exportée. Aucune installation.

## 1. Ouvrir l'application

Rendez-vous sur [drawtonomy.com](https://drawtonomy.com). Tout fonctionne dans le navigateur ; rien n'est téléversé.

## 2. Dessiner une voie

1. Appuyez sur <kbd>N</kbd>, ou cliquez sur l'outil **Voie** dans la barre d'outils.
2. Cliquez sur le canevas pour placer le début de la ligne médiane, cliquez à nouveau pour le sommet suivant, puis appuyez sur <kbd>Entrée</kbd> pour terminer.
3. Les bords gauche et droit apparaissent automatiquement.

:::tip
Maintenez <kbd>Maj</kbd> pendant le tracé pour désactiver l'[accrochage](/fr/guides/snap/) lors de ce clic.
:::

## 3. Placer un véhicule

1. Appuyez sur <kbd>P</kbd> pour ouvrir l'outil **Participants**.
2. Choisissez **Véhicule → Berline** et cliquez sur la voie que vous venez de dessiner.
3. Glissez une poignée de coin pour redimensionner, ou utilisez la poignée de rotation pour l'aligner avec la voie.

## 4. Exporter la scène

Ouvrez le menu d'export et choisissez un format :

- **PNG / SVG / PDF** — partager comme image plate.
- **drawtonomy.svg** — enregistre toutes les connexions afin que vous (ou un collègue) puissiez rouvrir et continuer l'édition plus tard.
- **Exporter pour esmini** — un zip contenant OpenDRIVE + OpenSCENARIO prêt à jouer dans [esmini](https://github.com/esmini/esmini).

[Exporter votre scène](/fr/guides/export/) couvre les formats en détail.
