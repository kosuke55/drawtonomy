## أشكال سيناريوهات القيادة

| الشكل | الغرض |
|---|---|
| **Linestring** | خط متصل، يُستخدم لحدود المسارات والأرصفة والعلامات. |
| **Lane** | مسار قابل للقيادة بحدّيْن وخط مركزي وفتحات وصل (Next / Previous / Left / Right). |
| **Vehicle** | مركبة بقالب (Sedan أو Bus أو Truck أو Motorcycle). |
| **Pedestrian** | مشاة بقالب (Walking أو Simple). |
| **Path** | مسار حركة يُستخدم للأسهم أو مجموعات الآثار أو مسارات السيناريو. نمط سهم أو شريط. |
| **Polygon** | منطقة مغلقة (موقف سيارات أو منطقة مظللة). |
| **Crosswalk** | ممر مشاة بنمط جاهز. |
| **TrafficLight** | إشارة مركبات أو مشاة. |
| **Intersection** | قالب تقاطع متعدد المسارات. |

## الأشكال الأساسية

| الشكل | الغرض |
|---|---|
| **LineArrow** | سهم بقطعة واحدة. |
| **Arrow** | سهم حر الشكل. |
| **Text** | نص عادي أو مشروح. |
| **Freehand** | يُرسم بضربة شبيهة بالقلم. |
| **Rectangle** | مستطيل محاذٍ للمحاور. |
| **Ellipse** | شكل بيضاوي محاذٍ للمحاور. |
| **Image** | PNG / JPG / SVG مستوردة. |

## القوالب المخصصة

يمكنك إضافة قوالب SVG للمركبات والمشاة وعلامات الطرق والإشارات. تدفّق المساهمة في [دليل القوالب](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
