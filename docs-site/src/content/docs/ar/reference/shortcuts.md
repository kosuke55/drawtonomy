## تبديل الأدوات

| المفتاح  | الأداة                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (التحريك)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## عمليات التحرير

| المفاتيح | الوظيفة |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | التراجع |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | الإعادة |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | نسخ |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | لصق |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | قص |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | حذف الأشكال المحددة |

## المُعدِّلات أثناء الرسم

| المُعدِّل | الأثر |
|---|---|
| <kbd>Shift</kbd> | تعطيل [الالتقاط (snap)](/ar/guides/snap/) مؤقتًا |
| <kbd>Alt</kbd> + نقرة | [مشاركة نقطة قائمة](/ar/guides/point-sharing/) (Linestring / Polygon / Path) |
| نقر مزدوج | الدخول إلى [تحرير القطع](/ar/guides/segment-editing/) (Linestring / Lane / Polygon) |

## الحركة

| المفاتيح | الأثر |
|---|---|
| مفاتيح الأسهم | تحريك التحديد بمقدار 1 بكسل |
| <kbd>Shift</kbd> + سهم | تحريك التحديد بمقدار 10 بكسل |
