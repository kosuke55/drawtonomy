ملف `drawtonomy.svg` هو SVG عادي مُعزَّز ببيانات وصفية تسجّل الحالة الخاصة بالمحرر فقط.

## البنية

- المحتوى البصري (المسارات والنصوص والصور) هو SVG عادي. أي عارض SVG يعرضه بشكل صحيح.
- يحوي قسم `<metadata>` في أعلى الوثيقة البيانات الخاصة بـ drawtonomy:
  - معرّفات الأشكال وخصائصها (القالب، النمط، إلخ)
  - فتحات وصلات المسارات (`next` و`previous` و`left` و`right`)
  - مراجع النقاط المشتركة
  - عضوية مجموعات الآثار (footprint)
  - ترتيب الطبقات (z-order)

## التوافق

عند تحرير `drawtonomy.svg` في محرر SVG عام (Illustrator أو Inkscape أو المتصفح)، يُحذف قسم البيانات الوصفية عند الحفظ ما لم تحافظ عليه صراحة. لا يزال drawtonomy قادرًا على فتح الناتج، لكن الوصلات والنقاط المشتركة ستكون مفقودة.

للحصول على تعديلات قابلة لدورة كاملة خارج drawtonomy، استخدم SDK ([`@drawtonomy/sdk`](/ar/reference/sdk/)) — فهو يستطيع قراءة الصيغة وكتابتها دون المرور بالمحرر.

## إدارة الإصدارات

تُهجَّر الملفات الأقدم تلقائيًا عند الاستيراد. يحوّل المساعد `resolveColorKey()` في SDK مفاتيح الألوان القديمة (مثلًا، `grey-700` من v1.x) إلى الحالية.
