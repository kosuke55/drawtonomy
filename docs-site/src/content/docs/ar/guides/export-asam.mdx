يستطيع drawtonomy تصدير مشهدك بصيغة ASAM [OpenDRIVE](https://www.asam.net/standards/detail/opendrive/) (`.xodr`) و[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/) (`.xosc`)، أو حزمهما معًا في zip جاهز لتشغيل [esmini](https://github.com/esmini/esmini).

![مشهد drawtonomy يُشغَّل في esmini بعد التصدير](/img/asam-esmini.png)

## التصدير من المحرر

1. ارسم مشهدك (مسارات، مركبات، إشارات مرور...).
2. افتح **File → Export → Export for esmini**.
3. أدخل اسمًا أساسيًا عند الطلب.
4. يُنزَّل ملف `<name>.zip` يحتوي `<name>.xodr` و`<name>.xosc`.

## شغّله

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## الصيغ الفردية

إن احتجت إلى واحدة فقط من الاثنتين:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## التصدير البرمجي

المُصدِّر جزء من `@drawtonomy/sdk` ويعمل دون المحرر. استخدمه في خطوط CI أو الأدوات على الخادم أو ملحقات المتصفح:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

للاطلاع على واجهة API الكاملة ونقاط التوسعة، راجع [مرجع Exporter SDK](/ar/extend/exporter-sdk/).

## الإصدارات المُنتَجة

| الصيغة | الإصدار |
|---|---|
| OpenDRIVE | 1.8 |
| OpenSCENARIO | 1.3 |
