drawtonomy سبورة بيضاء لسيناريوهات القيادة. تلك الصور التي تضعها في ورقة بحثية، أو الشريحة التي ترسمها قبل مراجعة تصميم، أو المخطط الذي ترسمه أثناء مكالمة لشرح حالة استثنائية لبقية الفريق، أو المشهد الذي تخطّط له قبل كتابة ملف OpenSCENARIO.

المسارات والتقاطعات والمركبات والمشاة وإشارات المرور وعلامات الطرق وممرات المشاة أشكال مدمجة. والمسارات تدرك الطوبولوجيا — تحمل وصلات Next / Previous / Left / Right — لذا فالمخطط شبكة قابلة للتحرير لا صورة تعيد رسمها كلما تغيرت هندسة الطريق.

التطبيق على [drawtonomy.com](https://drawtonomy.com). أما SDK والإضافات وشيفرة موقع الوثائق فعلى [GitHub](https://github.com/kosuke55/drawtonomy).

## لماذا يستخدمه الناس

- **صور للأوراق البحثية والرسائل العلمية والتقارير الفنية.** ناتج متجه (`drawtonomy.svg` وPDF وEPS) يُدمج بسلاسة في LaTeX وMarkdown والشرائح.
- **الشرائح والعروض التقديمية.** مخططات لمناورات تغيير المسار والتقاطعات وحالات حجب الرؤية وغيرها من سيناريوهات القيادة — تُرسم في ثوانٍ بدلًا من دقائق لكل شكل.
- **مناقشات التصميم والخوارزميات.** سطح رسم مشترك لمناقشة سلوك القيادة والحالات الاستثنائية وحجج السلامة مع الزملاء.
- **تأليف السيناريوهات.** ارسم المشهد قبل كتابة OpenSCENARIO XML، أو استورد ملف `.xosc` قائم وحرّره بصريًا.
- **شرح الخرائط وROS.** ارسم المسارات فوق خلفية صورة فضائية، أو حرّر خرائط Lanelet2 OSM، أو أضف شروحًا لشبكة إشغال ROS بمسارات وعقبات.

## لمن هذا الموقع

- **مهندسو القيادة الذاتية وADAS** الذين يرسمون مخططات للوثائق الداخلية ومراجعات التصميم وتقارير الحوادث.
- **باحثو وطلاب AV** الذين يُنتجون صورًا للأوراق البحثية والرسائل العلمية والمحاضرات في المؤتمرات.
- **مؤلفو السيناريوهات** الذين يعملون مع محاكيات مثل [esmini](https://github.com/esmini/esmini) أو CARLA أو الأدوات الداخلية.
- **مستخدمو خرائط HD وLanelet2** الذين يرسمون تعديلات على شبكة طرق قائمة.
- **فرق ROS والروبوتات** الذين يرسمون فوق شبكات الإشغال المُنشأة بـ nav2 أو Cartographer أو Gmapping.
- **مدرسو القيادة والمعلمون** الذين يُنتجون مخططات لمواد تعليمية.
- **بناة الأدوات** الذين يوسّعون المحرر بمصدّرين ومستوردين أو ميزات بمساعدة الذكاء الاصطناعي عبر [SDK الإضافات](/ar/extend/).
