從空白畫布到匯出場景只需五分鐘。無需安裝。

## 1. 開啟應用程式

前往 [drawtonomy.com](https://drawtonomy.com)。一切都在瀏覽器中執行;不會上傳任何資料。

## 2. 繪製車道

1. 按下 <kbd>N</kbd>,或點擊工具列中的**車道**工具。
2. 在畫布上點擊以放置中心線起點,再次點擊放置下一個頂點,最後按下 <kbd>Enter</kbd> 完成。
3. 左右邊界會自動產生。

:::tip
繪圖時按住 <kbd>Shift</kbd> 可暫時跳過該次點擊的[吸附](/zh-tw/guides/snap/)。
:::

## 3. 放置車輛

1. 按下 <kbd>P</kbd> 開啟**參與者**工具。
2. 選擇**車輛 → 房車**,然後點擊您剛繪製的車道。
3. 拖曳邊角控點調整大小,或使用旋轉控點將其與車道對齊。

## 4. 匯出場景

開啟匯出選單並選擇格式:

- **PNG / SVG / PDF** — 以平面影像分享。
- **drawtonomy.svg** — 儲存所有連接,讓您(或隊友)日後可重新開啟並繼續編輯。
- **匯出至 esmini** — 一個包含 OpenDRIVE + OpenSCENARIO 的 zip,可直接在 [esmini](https://github.com/esmini/esmini) 中重播。

[匯出您的場景](/zh-tw/guides/export/)詳細介紹各種格式。
