吸附與點共享都處理「這個點要在那個東西上」的情境。它們在 UI 中看起來相似,但會帶來不同的結果。把它們搞混是「我的形狀為何漂走?」這類錯誤最常見的根源。

## 吸附 = 相同座標

吸附會將您的游標(或您正在拖曳的頂點)移動到落在既有目標上。結果是兩個*恰好*共享座標的不同點。

之後若移動原本的目標,您吸附的點不會跟著動。它們從未連結。

當您在勾勒草圖時,這是您想要的:精確對齊、無隱藏耦合。

## 共享 = 相同識別

共享點是被多個形狀引用的單一物件。移動它一次,每個持有引用的形狀都會跟著移動。

按住 <kbd>Alt</kbd> 同時點擊,或在區段編輯模式中將頂點拖曳至既有頂點上,即可建立共享點。

這是您對於絕不該分離的邊界所想要的——兩條相鄰車道邊緣、兩個需保持焊接的多邊形角點、一條路徑的尾端與另一條的起點。

## 為何要區分

如果兩個應該是相同的形狀邊緣實際上是兩個吸附的點,拖曳其中一個、匯出至 OpenDRIVE,道路網路會在該頂點裂開。模擬器可能將該間隙解讀為不連續,或視工具而定加以塗抹。

共享邊界的車道 Left/Right 鄰居在內部一律使用共享點——這不是可選的,也非使用者可控。對任意形狀(折線、多邊形、路徑),選擇權在您。

## 視覺提示

- 吸附目標顯示單一高亮控點並拉動游標。
- 共享點在區段編輯模式中以雙重控點呈現。
