drawtonomy 內建您在自駕場景中需要的演員與交通元素範本。

## 車輛

1. 按下 <kbd>P</kbd> 開啟**參與者**。
2. 選擇車輛範本(房車、巴士、卡車、機車)。
3. 點擊畫布以放置。車輛會以範本預設大小放置。

拖曳邊角控點調整大小。拖曳旋轉控點將其與車道對齊。

## 行人

在同一個參與者選單中,選擇行人範本(行走、簡單)。

## 紅綠燈

參與者選單也包含車輛與行人號誌。將它們放置在路口轉角。它們是靜態形狀;不會執行訊號階段。

## 自訂範本

您可以新增自己的 SVG 範本並透過 PR 貢獻。請參閱[範本指南](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md)。

## 沿路徑填入車輛

要沿路徑放置一排車輛(用於車距示意圖或跟車情境),請使用[路徑足跡](/zh-tw/guides/path-footprint/)。
