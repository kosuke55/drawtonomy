吸附預設啟用,並在每個工具中運作。當游標靠近既有點或邊時,drawtonomy 會鎖定到該處並亮起靛藍色指示器。

<Demo src="/videos/snap-demo.mp4" caption="先以單一折線作為起始目標;接著第二條折線吸附到它,然後車輛與矩形依序吸附到特徵。" />

## 跨形狀類型

示範以三種不同工具對相同類型的目標進行操作。

### 折線吸附至折線

從單一垂直折線開始,第二條折線繪製成其角點正好落在第一條的頂端。結果是一個共享點的直角——而非僅視覺上重疊的像素。

![兩條折線,第二條吸附至第一條形成轉角](/img/frames/snap-linestring.png)

### 車輛吸附至車道

切換到車輛工具並將汽車放置於車道上時,車輛會吸附至車道中心線並沿車道方向定向。

![車輛放置於水平車道上,吸附至其中心線](/img/frames/snap-vehicle.png)

### 矩形吸附至車輛 / 畫布點

矩形工具具有相同的吸附行為。虛線指示器顯示角點被拉向何處。

![矩形繪製於車輛附近;虛線顯示吸附目標](/img/frames/snap-rectangle.png)

## 暫時停用吸附

點擊或拖曳時按住 <kbd>Shift</kbd> 可單次跳過吸附。釋放 <kbd>Shift</kbd> 即恢復吸附。

當您想將點放置在既有目標附近但不完全重合時,這是正確的做法。
