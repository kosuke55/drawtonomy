*共享點*是被多個形狀引用的單一頂點。移動它一次,每個引用它的形狀都會跟著移動。用此功能保持相鄰車道邊界、多邊形角點與路徑接點鎖定在一起。

<Demo src="/videos/share-demo.mp4" caption="按住 Alt 並點擊以將既有點與新形狀共享。" />

## 繪製時建立共享點

1. 選擇折線 (<kbd>L</kbd>)、多邊形 (<kbd>G</kbd>) 或路徑 (<kbd>H</kbd>) 工具。
2. 按住 <kbd>Alt</kbd>(macOS 為 Option)。
3. 點擊另一個形狀的既有頂點。

新形狀會獲得一個與既有形狀*共享*的頂點——而非僅吸附到相同座標。

## 將既有頂點轉為共享點

1. 雙擊形狀進入[區段編輯](/zh-tw/guides/segment-editing/)。
2. 按住 <kbd>Alt</kbd> 並將頂點拖曳至既有頂點上。

## 視覺提示

共享點在區段編輯模式中以雙重控點呈現。一般吸附點則以單一控點呈現。
