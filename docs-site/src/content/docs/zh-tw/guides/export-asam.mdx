drawtonomy 可將您的場景匯出為 ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) 與
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`),或將兩者打包為可在 [esmini](https://github.com/esmini/esmini) 中重播的 zip。

![drawtonomy 場景匯出後在 esmini 中重播](/img/asam-esmini.png)

## 從編輯器匯出

1. 繪製您的場景(車道、車輛、紅綠燈……)。
2. 開啟**檔案 → 匯出 → 匯出至 esmini**。
3. 出現提示時輸入基底名稱。
4. 會下載一個 `<name>.zip`,內含 `<name>.xodr` 與 `<name>.xosc`。

## 重播

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## 個別格式

如果只需要其中之一:

- **檔案 → 匯出 → OpenDRIVE (.xodr)**
- **檔案 → 匯出 → OpenSCENARIO (.xosc)**

## 程式化匯出

匯出器是 `@drawtonomy/sdk` 的一部分,無需編輯器即可執行。可用於 CI 流程、伺服器端工具或瀏覽器擴充功能:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

完整 API 與擴充點請參閱[匯出器 SDK 參考](/zh-tw/extend/exporter-sdk/)。

## 輸出版本

| 格式 | 版本 |
|---|---|
| OpenDRIVE | 1.8 |
| OpenSCENARIO | 1.3 |
