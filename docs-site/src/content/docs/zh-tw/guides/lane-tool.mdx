按下 <kbd>N</kbd> 切換到**車道**工具。右側會開啟一個面板,並在工具啟用期間保持顯示。面板頂部是 **CREATION MODE** 切換:

兩種模式做不同的事;請選擇符合您情境的一種。

<Demo src="/videos/lane-tool-demo.mp4" caption="以中心線模式繪製兩條車道,以邊界模式插入第三條。" />

## 中心線模式

您繪製中心線;drawtonomy 依**車道寬度**值產生左右邊界。當您從零開始時使用此模式。

1. 在畫布上點擊以放置第一個中心線點。
2. 再次點擊放置下一個點,依此類推。
3. 按下 <kbd>Enter</kbd>(或雙擊最後一個點)以完成。

車道工具仍保持啟用,可在他處再次點擊以開始新車道。以此方式繪製的兩條車道:

![從中心線繪製的兩條車道](/img/frames/lane-tool-two-lanes.png)

可在繪製車道之間於面板變更顏色、透明度或車道寬度——新值會套用到接下來繪製的車道,而非選取的車道。

## 邊界模式

點擊面板頂部的**邊界**以切換模式。在邊界模式下,您不點擊空白處;而是點擊兩條既有邊界折線,drawtonomy 會建立一條以它們為左右邊界的車道。

將游標移到折線上——當游標靠近時,drawtonomy 會以靛藍色高亮——然後點擊:

![邊界模式 — 既有的右邊界已高亮,可選取](/img/frames/lane-tool-boundary-mode.png)

點擊第二條折線,在其間出現一條新車道。新車道會與其他使用這些邊界的形狀共享邊界,因此移動邊界點會更新所有依賴它的車道。

當您已有幾何(手繪、從 Lanelet2 匯入或由車道產生器產生)並希望在其間配出車道時,使用邊界模式。

## 檢視車道

按下 <kbd>V</kbd> 切換到選取,然後點擊車道。面板會切換為車道屬性:

![車道屬性面板 — 車道 ID、共享邊界 ID、方向、四個連接欄位](/img/frames/lane-attributes.png)

顯示內容:

- **車道 ID** 以及**左邊界**/**右邊界**折線的 ID(例如 `way/1`、`way/2`)。共享折線的兩條車道會在此顯示相同的 ID。
- **車道顏色**、**車道透明度**、**方向(反轉)** — 車道本身的視覺與拓樸設定。
- **Next Lanes / Prev Lanes / Left Lane / Right Lane** — 四個連接欄位,各有**建立**(製作新的相鄰車道)與**設定**(指向既有車道)。請參閱[管理車道連接](/zh-tw/guides/lane-connections/)。
