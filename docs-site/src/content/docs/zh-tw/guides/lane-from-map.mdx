車道產生器會從 OpenStreetMap 拉取真實道路幾何,並將其轉換為與地圖背景對齊的可編輯車道形狀。

<Demo src="/videos/map-to-lane-demo.mp4" caption="點擊一條道路產生一條車道,拖曳區域產生多條。" maxWidth="900px" />

## 開啟地圖背景

1. 開啟畫布左上角的**背景**選單。
2. 選擇 **Satellite**(衛星)或 **Roadmap**(示意圖)。
3. 平移與縮放至您想處理的區域。

地圖會在畫布後方呈現,並在您繪圖時保持錨定。

## 產生單一車道

1. 按下 <kbd>N</kbd> 切換到車道工具。
2. 在工具列啟用**產生器**模式。
3. 將游標移到道路上。drawtonomy 會在游標下高亮匹配的 OSM 道路段。
4. 點擊。該段會被擷取並轉換為車道形狀。

## 產生區域內的所有道路

啟用產生器模式後:

1. 在您要擷取的區域上拖曳矩形。
2. 釋放。矩形內的所有道路會在一次批次中變成車道。

對整個路口、社區或測試場地很有用。

## 建議限制

OSM 擷取與轉換在瀏覽器中執行。為維持流暢的編輯體驗,請將產生的場景控制在約 **500 條車道**以下——若需更多,請將較大區域拆分為多個檔案。

## 產生後

產生的車道是普通的車道形狀。您可以:

- 拖曳點以精修幾何。
- 套用[平滑](/zh-tw/guides/smooth-lanes/)以將密集折線替換為樣條曲線。
- 在產生器未自動推斷的地方設定[連接](/zh-tw/guides/lane-connections/)。
- 在其上放置車輛、行人或路徑。
