drawtonomy 可讀取 [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2) OSM 格式地圖。範例地圖可從 [Autoware 文件](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map)取得。

<Demo src="/videos/lanelet-import-demo.mp4" caption="匯入完整的 Lanelet2 檔案。" />

## 匯入整個檔案

1. 開啟**檔案**選單 → **匯入**。
2. 選擇 `.osm` 檔案。
3. drawtonomy 會解析檔案並用車道形狀及其連接填充畫布。

## 只匯入特定車道

對於大型地圖,匯入每條車道會使編輯器變慢。改用車道選擇對話框:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="拖曳選取您想要的車道,然後匯入。" />

1. 開啟**檔案**選單 → **匯入 → 選擇車道**。
2. drawtonomy 會顯示預覽地圖。
3. 點擊或拖曳以選取您想要的車道。
4. 點擊**匯入選取項目**。

## 效能提示

匯入後的場景請維持在約 **500 條車道**以下,以保持流暢的編輯體驗。若需處理較大區域,可將工作拆分為多個檔案,或僅匯入您需要的區域。

## 匯入後

匯入的車道是完整保真度的車道形狀;Lanelet2 檔案中的連接皆會保留。可編輯、[平滑處理](/zh-tw/guides/smooth-lanes/)或[匯出回去](/zh-tw/guides/export-asam/)而不會失去拓樸。
