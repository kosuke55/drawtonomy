drawtonomy 提供多種匯出格式。最常使用的是 **drawtonomy.svg** —— 帶有額外詮釋資料的標準 SVG,讓您可重新開啟檔案並從中斷處繼續。它也是有效的 SVG,因此無需轉換即可在瀏覽器、簡報與文件流程中正確預覽。

其他格式 —— PNG、JPG、SVG(平面)、PDF、EPS —— 適用於您只需要靜態影像、不需重新編輯的情境。

模擬器輸出(OpenDRIVE / OpenSCENARIO / Lanelet2)請參閱專屬的 [ASAM 匯出](/zh-tw/guides/export-asam/)頁面。

## 從哪裡開始:drawtonomy.svg

`drawtonomy.svg` 保留形狀 ID、車道連接、共享點、足跡群組、樣式以及*哪個形狀在最上方*的關係。同一個檔案是:

- **可重新編輯。**將其拖回 drawtonomy,場景會完整還原——每個連接、共享點與重疊關係皆完整。
- **可預覽。**它是有效的 SVG,因此 GitHub、瀏覽器、Markdown 與簡報工具皆能正確顯示,無需轉換。
- **適合文件。**向量、可乾淨縮放、檔案小、無點陣化偽影。在 README 或論文配圖中以任何縮放等級都能保持清晰。

當內容可能再次被編輯、與已安裝 drawtonomy 的隊友分享、或嵌入技術文件時,`drawtonomy.svg` 是合理的預設值。

### 儲存為 drawtonomy.svg

1. 開啟選單(左上角)。
2. 點擊**匯出**。
3. 選擇 **drawtonomy.svg**。

檔案會以場景標題為基底的名稱下載。

### 重新開啟

將檔案拖回 drawtonomy,或在同一選單中使用**匯入**。整個場景會在新分頁中出現,每個形狀皆可選取。當您點擊形狀重疊的區域時,屬性面板會顯示 **OVERLAPPING OBJECTS** 區段——例如車輛與其所在車道的關係,在來回轉換中皆能保留。

## 其他影像格式

當您只需要平面圖片——無編輯、無詮釋資料——可從同一匯出選單中挑選。

| 格式 | 適用情境 | 備註 |
|---|---|---|
| **PNG** | 簡報、文件、網頁 | 無損點陣。 |
| **JPG** | 不需透明度的較小檔案 | 有損點陣。 |
| **SVG**(平面)| 在 Illustrator / Inkscape 中後製、網頁嵌入 | 視覺上與 drawtonomy.svg 相同,但詮釋資料已剝除。 |
| **PDF** | 列印、典藏、論文 | 向量,支援透明度。 |
| **EPS** | 傳統出版流程 | 向量。**不支援透明度**——見下文。 |

### EPS 與透明度

EPS 不編碼透明度。透明度 60% 的形狀會以完全不透明匯出。如果您的場景仰賴透明度,請改用 PDF 或 SVG 匯出。
