每個形狀都有自己的樣式。您也可以變更整個編輯器的預設值,讓新形狀以您想要的方式開始。

<Demo src="/videos/style-demo.mp4" caption="從屬性面板設定每個形狀的顏色、透明度、寬度與範本變體。" />

## 個別形狀樣式

1. 按下 <kbd>V</kbd> 切換到選取,然後點擊形狀。
2. 右側的**屬性面板**會顯示:
   - **顏色**(調色盤 + 自訂)
   - **透明度**(0–100%)
   - **寬度**(線條類形狀)
   - **樣式**(實線 / 虛線 / 範本變體)

可多選以一次將相同變更套用至多個形狀。

## 預設值

要讓每條新車道從 60% 透明度開始,例如:

1. 開啟**漢堡**選單。
2. 選擇**預設值**。
3. 在**車道**下變更該值。

預設值會在新建立的形狀上生效。既有形狀不受影響。

## 調色盤

drawtonomy 使用 Tailwind 風格的調色盤(grey-100 至 grey-900,加上其他顏色)。完整清單請參閱[調色盤參考](/zh-tw/reference/color-palette/)。
