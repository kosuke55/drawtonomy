## 自駕場景形狀

| 形狀 | 用途 |
|---|---|
| **折線(Linestring)** | 連續線,用於車道邊界、路緣與標線。 |
| **車道(Lane)** | 可行駛的車道,具有兩條邊界、中心線與連接欄位(Next / Previous / Left / Right)。 |
| **車輛(Vehicle)** | 範本化的車輛(房車、巴士、卡車、機車)。 |
| **行人(Pedestrian)** | 範本化的行人(行走、簡單)。 |
| **路徑(Path)** | 用於箭頭、足跡群組或場景路徑的軌跡。箭頭或帶狀樣式。 |
| **多邊形(Polygon)** | 封閉區域(停車場、斜線區)。 |
| **行人穿越道(Crosswalk)** | 預先樣式化的行人穿越道。 |
| **紅綠燈(TrafficLight)** | 車輛或行人號誌。 |
| **路口(Intersection)** | 多車道交會點範本。 |

## 基本形狀

| 形狀 | 用途 |
|---|---|
| **LineArrow** | 單一區段的箭頭。 |
| **Arrow** | 自由形式箭頭。 |
| **Text** | 純文字或加註文字。 |
| **Freehand** | 以筆刷描繪。 |
| **Rectangle** | 軸對齊矩形。 |
| **Ellipse** | 軸對齊橢圓。 |
| **Image** | 匯入的 PNG / JPG / SVG。 |

## 自訂範本
