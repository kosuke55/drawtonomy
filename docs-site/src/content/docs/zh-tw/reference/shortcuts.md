## 工具切換

| 按鍵  | 工具                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | 手形(平移)              |
| <kbd>V</kbd>    | 選取                      |
| <kbd>L</kbd>    | 折線                      |
| <kbd>N</kbd>    | 車道                      |
| <kbd>P</kbd>    | 參與者(車輛 / 行人)     |
| <kbd>H</kbd>    | 路徑                      |
| <kbd>G</kbd>    | 多邊形                    |
| <kbd>X</kbd>    | 行人穿越道                |
| <kbd>I</kbd>    | 路口                      |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | 文字                      |
| <kbd>D</kbd>    | 自由繪                    |

## 編輯操作

| 按鍵 | 功能 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | 復原 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 取消復原 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | 複製 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | 貼上 |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | 剪下 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 刪除選取的形狀 |

## 繪圖時的修飾鍵

| 修飾鍵 | 效果 |
|---|---|
| <kbd>Shift</kbd> | 暫時停用[吸附](/zh-tw/guides/snap/) |
| <kbd>Alt</kbd> + 點擊 | [共享既有點](/zh-tw/guides/point-sharing/)(折線 / 多邊形 / 路徑) |
| 雙擊 | 進入[區段編輯](/zh-tw/guides/segment-editing/)(折線 / 車道 / 多邊形) |

## 移動

| 按鍵 | 效果 |
|---|---|
| 方向鍵 | 將選取項目移動 1 px |
| <kbd>Shift</kbd> + 方向鍵 | 將選取項目移動 10 px |
