本課程以真實位置為起點。您會開啟**道路**或**衛星**背景,旋轉畫布讓道路朝向方便的方向,然後對著下方的照片手動描繪車道。文末的進階段落會介紹直接從 OSM 資料拉取車道的一鍵產生器。

## 1. 開啟地圖背景

開啟選單(左上角)並找到**地圖**列:

![選單已開啟,地圖列被標示;選項為 Off / Road / Satellite](/img/mapBackground.png)

選擇 **Road** 顯示 OpenStreetMap 的示意圖,或選擇 **Satellite** 顯示衛星照片。地圖會在您所有繪圖內容後方呈現,並保持錨定——在上面繪圖不會移動它。

要關閉,從同一列選擇 **Off**。

## 2. 用旋轉控制對齊畫布

左下角有兩個精簡面板:

![左下控制 — 左為縮放,右為旋轉](/img/bottomLeft.png)

- **縮放** — `−` 與 `+` 按鈕,中間顯示目前百分比。也可用雙指捏合或滾輪縮放。
- **旋轉** — 指南針圖示與目前角度(預設 `0°`)。可用此將畫布旋轉,讓道路更容易跟著游標描繪。

旋轉的操作:

- **點擊**指南針進入旋轉模式。游標會變成旋轉控點;在畫布上拖曳即可旋轉整個畫布(地圖背景也會跟著旋轉)。
- **再次點擊**指南針可退出旋轉模式。
- **雙擊**指南針可重置回 `0°`。

旋轉到您想處理的道路段大致呈水平或垂直——以您覺得方便描繪為主。

## 3. 用車道工具描繪道路

按下 <kbd>N</kbd> 切換到車道工具。車道建立面板會在右側開啟。預設選擇**中心線**模式。

如果地圖中的道路是彎曲的,在點擊前先在面板開啟**平滑邊界**——車道邊界會呈現平滑曲線而非折線。(若要複習,請參閱[平滑車道邊界](/zh-tw/tutorials/smooth-lanes/)。)

沿著地圖中道路的中央點擊,每當道路明顯改變方向時放置一個點。按下 <kbd>Enter</kbd> 完成車道。

描繪時的幾個小技巧:

- 若預設值與地圖上的道路不符,可在繪製前先調整面板上的**車道寬度**。
- 點擊時按住 <kbd>Shift</kbd> 可單次跳過[吸附](/zh-tw/guides/snap/)——當您想放置在某點附近但不完全重合時很方便。
- 多車道道路請分別繪製每條車道。第一條邊界完成後,可使用[邊界模式](/zh-tw/guides/lane-tool/#boundary-mode)讓下一條車道自動共享該邊界。

## 4. 儲存

描繪完成後,匯出為 **drawtonomy.svg**,如此地圖背景、車道幾何與連接皆能在重新開啟檔案時完整還原。請參閱[匯出您的場景](/zh-tw/guides/export/)。

## 進階:一鍵車道產生

若您信任該區域的 OSM 資料,drawtonomy 可直接將道路轉換為可編輯的車道形狀——無需手動描繪。

<Demo src="/videos/map-to-lane-demo.mp4" caption="點擊一條道路產生一條車道;拖曳區域產生其中所有道路。" maxWidth="900px" />

開啟地圖背景後:

1. 按下 <kbd>N</kbd> 切換到車道工具,然後在工具列啟用**產生器**模式。
2. **點擊**道路段以將該段轉換為車道。
3. **拖曳**矩形涵蓋區域,可一次將其中所有道路轉換為車道。

這是快捷功能,並非取代手動描繪。輸出就是普通的車道形狀——之後可透過[區段編輯](/zh-tw/guides/segment-editing/)精修、[平滑處理](/zh-tw/guides/smooth-lanes/)或補上缺失的[連接](/zh-tw/guides/lane-connections/)。

對於複雜或不熟悉的區域,手動描繪通常比產生器產生的結果更乾淨,因為 OSM 道路資料可能有雜訊,或使用的中心線與衛星影像不完全吻合。

## 您學到了什麼

- 地圖背景位於選單的**地圖**列,有 **Off**、**Road** 與 **Satellite** 選項。
- 左下角的**旋轉**指南針可旋轉整個畫布,讓道路更易描繪;雙擊可重置為 `0°`。
- 用車道工具描繪道路可完全掌控幾何;當 OSM 資料夠好時,車道產生器是一鍵快捷選項。
