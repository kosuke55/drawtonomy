本課程跟隨官方車道工具示範。完成後,您將會使用 drawtonomy 建立車道的兩種方式:

- **中心線模式** — 繪製中心線;左右邊界會自動產生。
- **邊界模式** — 選取兩條既有邊界折線,drawtonomy 會在兩者之間配出車道。

示範會先以中心線模式繪製兩條車道,再切換到邊界模式以填補空隙的方式建立第三條車道。

<Demo src="/videos/lane-tool-demo.mp4" caption="兩條中心線車道,接著以邊界模式從既有邊界建立第三條車道。" />

## 1. 選擇車道工具

開啟 [drawtonomy.com](https://drawtonomy.com)。按下 <kbd>N</kbd>(或點擊底部工具列的車道圖示)。

畫面右側會顯示**車道**建立面板,預設選擇**中心線**:

![車道面板 — 中心線模式啟用,車道寬度 50 px](/img/frames/lane-tool-panel.png)

暫時保持預設值。

## 2. 以中心線模式繪製兩條車道

在中心線模式下,在畫布上點擊以放置第一個中心線點,沿路再次點擊放置下一個點,最後按下 <kbd>Enter</kbd> 完成。左右邊界會依據**車道寬度**值(預設 50 px)自動產生。

每條車道完成後車道工具仍保持啟用,所以可在他處再次點擊以開始第二條車道。在第一條車道右側點幾個點,然後按下 <kbd>Enter</kbd>:

![以中心線模式並排繪製兩條車道](/img/frames/lane-tool-two-lanes.png)

目前兩條車道是獨立的——它們不共享邊界,也彼此不知情。

## 3. 切換到邊界模式

在同一面板中點擊**邊界**(位於**中心線**旁邊)以切換建立模式。在邊界模式下,您不點擊空白處;而是點擊**既有的邊界折線**,drawtonomy 會在兩條折線之間配出車道。

將游標移到**左車道的右邊界**——當游標靠近時,drawtonomy 會以靛藍色高亮該折線——然後點擊:

![邊界模式 — 左車道的右邊界已高亮,可選取](/img/frames/lane-tool-boundary-mode.png)

接著點擊**右車道的左邊界**。一條新車道會填入空隙,以兩條被點擊的折線作為其左右邊界。

## 4. 檢視結果

按下 <kbd>V</kbd> 切換到選取工具,並點擊新的中間車道。右側面板會切換為其屬性:

![屬性面板 — 新的中間車道與相鄰車道共享邊界 way/1 與 way/2](/img/frames/lane-attributes.png)

邊界被重複使用:

- **車道 ID** — `lane/2`,全新的車道。
- **左邊界** — `way/1`,與左車道右邊界相同的折線。
- **右邊界** — `way/2`,同樣與右車道共享。

由於邊界共享,拖曳任一側的點都會同時移動兩條相鄰的車道。這就是[車道連接](/zh-tw/explanation/lane-model/)的基礎;接下來請閱讀該頁了解底層模型。

面板還會列出**方向**、**車道顏色**、**車道透明度**,以及四個連接欄位 **Next Lanes / Prev Lanes / Left Lane / Right Lane**,目前先保持空白。

## 您學到了什麼

- 車道有兩種繪製方式:從中心線繪製,或選取兩條既有邊界折線。
- 中心線模式適合空白畫布的快速建立;邊界模式可在既有幾何之間插入車道,而無需重畫。
- 從既有邊界建立的車道會與相鄰車道共享這些邊界。
