## 我可以用 drawtonomy 為自動駕駛論文、簡報或文件繪製配圖嗎?

可以——這是主要使用情境之一。車道、路口、車輛與行人皆為內建形狀,因此一張在一般繪圖工具中需要花上半小時的自駕場景圖,只需數分鐘即可完成。可匯出為 [`drawtonomy.svg`](/zh-tw/guides/export/)、PDF 或 EPS,適用於 LaTeX、簡報與 Markdown。

## drawtonomy 可以免費使用嗎?

是的。[drawtonomy.com](https://drawtonomy.com) 完全在您的瀏覽器中執行。無需帳號、無需安裝,也不會上傳任何資料。SDK 與擴充功能在 [GitHub](https://github.com/kosuke55/drawtonomy) 以開源形式提供。

## drawtonomy 是免費的 OpenSCENARIO 與 OpenDRIVE 編輯器嗎?

drawtonomy 是一款可**匯出至** ASAM OpenDRIVE 1.8 與 OpenSCENARIO 1.3 的白板,並可打包成單一 zip 套件供 [esmini](https://github.com/esmini/esmini) 重播。您以視覺方式繪製場景——車道、路口、車輛、路徑——drawtonomy 會產生 `.xodr` 與 `.xosc` 檔案。請參閱[匯出至 OpenDRIVE / OpenSCENARIO / esmini](/zh-tw/guides/export-asam/)。

## drawtonomy 可以在瀏覽器中編輯 Lanelet2 (.osm) 地圖嗎?

可以。drawtonomy 能匯入 [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2) OSM 檔案(包括 [Autoware 範例地圖](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map)),以視覺方式編輯車道幾何與連接,並匯出回 Lanelet2 OSM。為獲得最佳效能,單一場景的匯入量請控制在約 500 條車道以下。請參閱[匯入 Lanelet2 (.osm) 檔案](/zh-tw/guides/import-lanelet2/)。

## 我可以匯入 ROS 佔據網格地圖嗎?

可以。drawtonomy 可讀取 [nav2](https://navigation.ros.org/)、Cartographer、Gmapping 等 SLAM 工具使用的 ROS `map_server` 格式(`.pgm` + `.yaml`)。網格會以背景圖層呈現,您可直接在其上勾勒車道、路徑與障礙物。請參閱[匯入 ROS OccupancyGrid](/zh-tw/guides/import-ros-map/)。

## drawtonomy 與一般繪圖工具有何不同?

一般繪圖工具只認識通用形狀,所以車道只是一個矩形,每當道路轉彎時就得重畫。drawtonomy 將**車道、路口、行人穿越道、紅綠燈、道路標線、車輛與行人都當作內建形狀**,且車道帶有 **Next / Previous / Left / Right** 連接。拖曳邊界時,連接的車道會跟著移動。請參閱[為什麼選擇 drawtonomy](/zh-tw/explanation/why-drawtonomy/)與[車道連接模型](/zh-tw/explanation/lane-model/)。

## 我需要安裝任何東西嗎?

不需要。drawtonomy 可在任何現代瀏覽器中執行。開啟 [drawtonomy.com](https://drawtonomy.com) 即可開始繪製。擴充功能開發者也可使用本機開發伺服器([`@drawtonomy/dev-server`](https://www.npmjs.com/package/@drawtonomy/dev-server)),它會在 localhost 代管編輯器。

## drawtonomy 可以從自然語言生成自動駕駛場景嗎?

可以。[AI 場景產生器](/zh-tw/tutorials/ai-scene/)擴充功能可讀取自然語言提示或 OpenSCENARIO XML,並輸出可編輯的畫布——車道、車輛、路徑與行人皆為一般的 drawtonomy 形狀。支援 Anthropic Claude、OpenAI GPT 與 Google Gemini。

## 哪種檔案格式可保留 drawtonomy 場景的可編輯性?

`drawtonomy.svg`。它是標準 SVG 檔案——可在瀏覽器、GitHub、簡報與 Markdown 中預覽——並包含 drawtonomy 用來在重新開啟檔案時重建每個形狀、連接、共享點與重疊關係的詮釋資料。請參閱[匯出您的場景](/zh-tw/guides/export/)以及 [drawtonomy.svg 格式參考](/zh-tw/reference/drawtonomy-svg/)。

## 我可以新增自己的車輛或號誌範本嗎?

可以。範本是註冊在 `templates/manifest.json` 中的 SVG 檔案。將檔案放入正確的資料夾(`vehicle`、`pedestrian`、`road_marking`、`sign`、`other`),提交 PR,即可在編輯器選單中與內建範本並列。請參閱[貢獻範本](/zh-tw/extend/templates/)。

## drawtonomy 支援大型道路網路嗎?

drawtonomy 主要為示意圖而非城市規模地圖最佳化。為維持流暢的編輯體驗,單一場景請控制在約 **500 條車道**以下。若需處理較大區域,可將工作拆分為多個檔案,或僅匯入所需的區域。

## 我可以在論文、簡報或文件中使用 drawtonomy 圖表嗎?

可以。[`drawtonomy.svg`](/zh-tw/guides/export/) 格式為有效的 SVG,因此無需轉換即可嵌入論文、簡報、Markdown 與網站。也提供 PDF、PNG、JPG 與 EPS 供傳統出版流程使用。

## 原始碼在哪裡?

SDK、擴充功能、範本與本文件網站都位於 [github.com/kosuke55/drawtonomy](https://github.com/kosuke55/drawtonomy)。應用程式本身則位於 [drawtonomy.com](https://drawtonomy.com)。
