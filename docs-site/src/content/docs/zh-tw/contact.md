## 錯誤回報、功能建議與問題

➡ **[在 GitHub 提交 issue](https://github.com/kosuke55/drawtonomy/issues/new)**

回報錯誤時,簡短的重現步驟(步驟 + 預期結果與實際結果)會很有幫助。也歡迎附上螢幕截圖或當下狀態的 `drawtonomy.svg` 存檔。
