Os tutoriais são lições curtas e práticas. Cada um percorre uma
tarefa completa de ponta a ponta, para que você possa aprender o
editor seguindo junto.

Se você já sabe o que quer e só precisa dos passos, os
[Guias práticos](/pt/guides/) geralmente são uma escolha melhor.

## Lições

- [Início rápido](/pt/start/quickstart/) — sua primeira faixa e veículo em
  cinco minutos.
- [Suas primeiras três faixas](/pt/tutorials/your-first-lanes/) — os dois
  modos de criação da ferramenta Faixa (Linha Central e Borda).
- [Bordas de faixa suaves](/pt/tutorials/smooth-lanes/) — ativando
  Borda Suave antes de desenhar curvas.
- [Recriar uma estrada real a partir de um mapa](/pt/tutorials/road-from-map/) —
  traçando uma estrada sobre um fundo de satélite, com o gerador
  de um clique apresentado como atalho.
- [Gerar uma cena com IA, depois refinar à mão](/pt/tutorials/ai-scene/) —
  descrevendo um cenário em linguagem natural e editando o resultado.
