O drawtonomy traz vários formatos de exportação. O que você vai
querer usar na maioria das vezes é o **drawtonomy.svg** — um SVG
comum com metadados extras, então você pode reabrir o arquivo e
continuar de onde parou. Também é SVG válido, então tem
pré-visualização correta em navegadores, slides e pipelines de
documentação sem conversão.

Os outros formatos — PNG, JPG, SVG (plano), PDF, EPS — são para
casos em que você quer uma imagem estática e não precisa reeditá-la.

Para saída de simulador de condução (OpenDRIVE / OpenSCENARIO /
Lanelet2), veja a página dedicada de
[exportação ASAM](/pt/guides/export-asam/).

## Onde começar: drawtonomy.svg

`drawtonomy.svg` preserva os IDs das formas, conexões de faixa,
pontos compartilhados, grupos de pegadas, estilo e as relações
*qual-forma-está-em-cima*. O mesmo arquivo é:

- **Reeditável.** Arraste-o de volta para o drawtonomy e a cena
  volta exatamente como você deixou — toda conexão, ponto
  compartilhado e relação de sobreposição intactos.
- **Pré-visualizável.** É SVG válido, então GitHub, navegadores,
  renderizadores Markdown e ferramentas de slide o exibem
  corretamente sem conversão.
- **Amigável a documentação.** Vetor, escala bem, tamanho de
  arquivo pequeno, sem artefatos de rasterização. Mantém-se nítido
  em qualquer zoom em um README ou figura de artigo.

`drawtonomy.svg` é um padrão razoável para qualquer coisa que possa
ser editada novamente, compartilhada com um colega de equipe que
tenha o drawtonomy ou incorporada em documentação técnica.

### Salvar como drawtonomy.svg

1. Abra o menu (canto superior esquerdo).
2. Clique em **Exportar**.
3. Escolha **drawtonomy.svg**.

O arquivo é baixado com um nome baseado no título da cena.

### Reabrir

Arraste o arquivo de volta para o drawtonomy, ou use **Importar** no
mesmo menu. A cena inteira aparece em uma aba nova com cada forma
selecionável. O Painel de Atributos mostra uma seção
**OBJETOS SOBREPOSTOS** quando você clica em uma área onde formas se
sobrepõem — a relação entre, digamos, um veículo e a faixa onde ele
está, sobrevive ao round-trip.

## Outros formatos de imagem

Quando você só precisa de uma imagem plana — sem edição, sem
metadados — escolha um destes no mesmo menu Exportar.

| Formato | Use para | Notas |
|---|---|---|
| **PNG** | Slides, documentos, páginas web | Raster sem perdas. |
| **JPG** | Arquivos menores quando não precisa de transparência | Raster com perdas. |
| **SVG** (plano) | Pós-processamento em Illustrator / Inkscape, incorporação web | Visualmente idêntico ao drawtonomy.svg, mas os metadados são removidos. |
| **PDF** | Impressão, arquivamento, artigos | Vetor, suporta transparência. |
| **EPS** | Pipelines de publicação legados | Vetor. **Não suporta transparência** — veja abaixo. |

### EPS e transparência

EPS não codifica transparência. Uma forma com opacidade 60% será
exportada com opacidade total. Se sua cena depende de transparência,
exporte PDF ou SVG.
