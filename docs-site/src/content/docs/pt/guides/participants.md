---
title: Adicionar veículos, pedestres e semáforos
description: Posicione atores e elementos de tráfego na tela usando modelos integrados.
---

O drawtonomy traz modelos para os atores e elementos de tráfego que
você precisa em cenários de condução.

## Veículos

1. Pressione <kbd>P</kbd> para abrir **Participantes**.
2. Escolha um modelo de veículo (Sedan, Bus, Truck, Motorcycle).
3. Clique na tela para posicionar. O veículo cai no tamanho padrão
   do modelo.

Arraste uma alça de canto para redimensionar. Arraste a alça de
rotação para alinhá-lo com uma faixa.

## Pedestres

No mesmo menu de Participantes, escolha um modelo de pedestre
(Walking, Simple).

## Semáforos

O menu de Participantes também inclui sinais de veículos e pedestres.
Posicione-os nos cantos do cruzamento. Eles são formas estáticas; não
executam uma fase de sinal.

## Modelos personalizados

Você pode adicionar seus próprios modelos SVG e contribuí-los via PR.
Veja o [Guia de Modelos](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).

## Preenchendo uma trajetória com veículos

Para posicionar uma fileira de veículos ao longo de uma trajetória
(para diagramas de espaçamento ou cenas de seguir-o-líder), use
[Pegada de Trajetória](/pt/guides/path-footprint/).
