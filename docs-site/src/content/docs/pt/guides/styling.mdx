Cada forma carrega seu próprio estilo. Você também pode mudar os
padrões em todo o editor para que novas formas comecem do jeito que
você quer.

<Demo src="/videos/style-demo.mp4" caption="Cor, opacidade, largura e variante de modelo por forma a partir do Painel de Atributos." />

## Estilo por forma

1. Pressione <kbd>V</kbd> para Selecionar, depois clique numa forma.
2. O **Painel de Atributos** à direita expõe:
   - **Cor** (paleta + personalizada)
   - **Opacidade** (0–100%)
   - **Largura** (para formas tipo linha)
   - **Estilo** (sólido / tracejado / variante de modelo)

Selecione múltiplas para aplicar a mesma mudança em várias formas
de uma vez.

## Padrões

Para fazer toda nova faixa começar com, digamos, 60% de opacidade:

1. Abra o menu **hambúrguer**.
2. Escolha **Defaults**.
3. Mude o valor sob **Lane**.

Os padrões têm efeito para formas recém-criadas. Formas existentes
não são alteradas.
