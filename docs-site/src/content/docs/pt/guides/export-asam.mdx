O drawtonomy pode exportar sua cena como ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) e
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`), ou empacotar ambos como um zip pronto para reprodução no
[esmini](https://github.com/esmini/esmini).

![Uma cena drawtonomy reproduzida no esmini após a exportação](/img/asam-esmini.png)

## Exportar pelo editor

1. Desenhe sua cena (faixas, veículos, semáforos…).
2. Abra **Arquivo → Exportar → Exportar para esmini**.
3. Digite um nome base quando solicitado.
4. Um `<nome>.zip` contendo `<nome>.xodr` e `<nome>.xosc` é baixado.

## Reproduza

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Formatos individuais

Se você só precisa de um dos dois:

- **Arquivo → Exportar → OpenDRIVE (.xodr)**
- **Arquivo → Exportar → OpenSCENARIO (.xosc)**

## Exportação programática

O exportador faz parte do `@drawtonomy/sdk` e roda sem o editor.
Use-o em pipelines de CI, ferramentas no servidor ou extensões de
navegador:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Para a API completa e pontos de extensão, veja a
[Referência do SDK do Exportador](/pt/extend/exporter-sdk/).
