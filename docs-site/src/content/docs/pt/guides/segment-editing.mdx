A edição de segmentos permite ajustar formas entre dois vértices
adjacentes, adicionar um novo vértice ou apagar um — sem redesenhar a
forma do zero.

<Demo src="/videos/segment-demo.mp4" caption="Clique duplo para entrar no modo de edição de segmento, depois arraste um ponto ou clique num segmento para adicionar um." />

## Entre no modo de edição de segmento

1. Pressione <kbd>V</kbd> para a ferramenta Selecionar.
2. Clique duplo em uma Linestring, Faixa ou Polígono.
3. A forma muda para o modo de edição de pontos: cada vértice vira
   uma alça índigo arrastável.

## Mover um ponto

Clique e arraste um vértice. Se o ponto for compartilhado com outra
forma (veja [Compartilhamento de Pontos](/pt/guides/point-sharing/)),
toda forma que o contiver se move junto.

Para faixas, arrastar um ponto de borda atualiza ambas as faixas que
compartilham a borda — veja
[Modelo de conexão de faixas](/pt/explanation/lane-model/).

## Adicionar um ponto

Clique em qualquer lugar de um segmento (a linha entre dois pontos
existentes). Um novo vértice é inserido na posição do clique.

Esta é a forma mais rápida de introduzir uma curva em uma seção
anteriormente reta: adicione um ponto, depois arraste-o.

## Remover um ponto

Selecione o vértice (ele fica índigo sólido) e pressione
<kbd>Delete</kbd> ou <kbd>Backspace</kbd>.

## Sair da edição de segmento

Pressione <kbd>Esc</kbd>, clique fora da forma ou escolha outra
ferramenta. A forma volta ao modo de seleção normal.
