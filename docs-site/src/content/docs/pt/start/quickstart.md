Cinco minutos de uma tela em branco até uma cena exportada. Sem instalação.

## 1. Abra o app

Vá para [drawtonomy.com](https://drawtonomy.com). Tudo roda no
navegador; nada é enviado para servidores.

## 2. Desenhe uma faixa

1. Pressione <kbd>N</kbd>, ou clique na ferramenta **Faixa** na barra de ferramentas.
2. Clique na tela para colocar o início da linha central, clique
   novamente para o próximo vértice e pressione <kbd>Enter</kbd> para finalizar.
3. As bordas esquerda e direita aparecem automaticamente.

:::tip
Segure <kbd>Shift</kbd> enquanto desenha para ignorar o [snap](/pt/guides/snap/)
naquele clique.
:::

## 3. Posicione um veículo

1. Pressione <kbd>P</kbd> para abrir a ferramenta **Participantes**.
2. Escolha **Veículo → Sedan** e clique na faixa que você acabou de desenhar.
3. Arraste uma alça de canto para redimensionar, ou use a alça
   de rotação para alinhá-lo com a faixa.

## 4. Exporte a cena

Abra o menu de exportação e escolha um formato:

- **PNG / SVG / PDF** — compartilhe como uma imagem plana.
- **drawtonomy.svg** — salva todas as conexões para que você (ou um colega de equipe)
  possa reabrir e continuar editando depois.
- **Exportar para esmini** — um zip com OpenDRIVE + OpenSCENARIO pronto
  para reproduzir no [esmini](https://github.com/esmini/esmini).

[Exportar sua cena](/pt/guides/export/) cobre os formatos em detalhes.
