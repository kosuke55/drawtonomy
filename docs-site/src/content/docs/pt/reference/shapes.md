## Formas de cenário de condução

| Forma | Finalidade |
|---|---|
| **Linestring** | Linha contínua, usada para bordas de faixa, meios-fios, marcações. |
| **Faixa** | Uma faixa transitável com duas bordas, uma linha central e slots de conexão (Próxima / Anterior / Esquerda / Direita). |
| **Veículo** | Veículo modelado (Sedan, Bus, Truck, Motorcycle). |
| **Pedestre** | Pedestre modelado (Walking, Simple). |
| **Trajetória** | Trajetória usada para setas, grupos de pegadas ou trajetórias de cenário. Estilo seta ou faixa. |
| **Polígono** | Área fechada (estacionamento, zona hachurada). |
| **Faixa de pedestres** | Travessia de pedestres pré-estilizada. |
| **TrafficLight** | Sinal para veículos ou pedestres. |
| **Cruzamento** | Modelo de junção multi-faixas. |

## Formas básicas

| Forma | Finalidade |
|---|---|
| **LineArrow** | Seta de segmento único. |
| **Arrow** | Seta de forma livre. |
| **Texto** | Texto simples ou anotado. |
| **À mão livre** | Desenhada com traço estilo caneta. |
| **Retângulo** | Retângulo alinhado aos eixos. |
| **Elipse** | Elipse alinhada aos eixos. |
| **Imagem** | PNG / JPG / SVG importado. |

## Modelos personalizados

Você pode adicionar modelos SVG para veículos, pedestres, marcações
viárias e placas. O fluxo de contribuição está no
[Guia de Modelos](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
