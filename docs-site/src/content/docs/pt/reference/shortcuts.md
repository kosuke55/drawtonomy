## Troca de ferramenta

| Tecla  | Ferramenta                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Mão (mover)                |
| <kbd>V</kbd>    | Selecionar                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Faixa                      |
| <kbd>P</kbd>    | Participantes (Veículo / Pedestre) |
| <kbd>H</kbd>    | Trajetória                      |
| <kbd>G</kbd>    | Polígono                   |
| <kbd>X</kbd>    | Faixa de pedestres                 |
| <kbd>I</kbd>    | Cruzamento              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Texto                      |
| <kbd>D</kbd>    | À mão livre                  |

## Operações de edição

| Teclas | Função |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Desfazer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Refazer |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copiar |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Colar |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Recortar |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Apagar forma(s) selecionada(s) |

## Modificadores ao desenhar

| Modificador | Efeito |
|---|---|
| <kbd>Shift</kbd> | Desabilitar [snap](/pt/guides/snap/) temporariamente |
| <kbd>Alt</kbd> + clique | [Compartilhar um ponto existente](/pt/guides/point-sharing/) (Linestring / Polígono / Trajetória) |
| Clique duplo | Entrar em [edição de segmento](/pt/guides/segment-editing/) (Linestring / Faixa / Polígono) |

## Movimento

| Teclas | Efeito |
|---|---|
| Setas | Move a seleção em 1 px |
| <kbd>Shift</kbd> + seta | Move a seleção em 10 px |
