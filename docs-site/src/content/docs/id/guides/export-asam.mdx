drawtonomy dapat mengekspor adegan Anda sebagai ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) dan
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`), atau menggabungkan keduanya sebagai zip siap pemutaran
[esmini](https://github.com/esmini/esmini).

![Adegan drawtonomy yang diputar di esmini setelah ekspor](/img/asam-esmini.png)

## Ekspor dari editor

1. Gambar adegan Anda (jalur, kendaraan, lampu lalu lintas…).
2. Buka **File → Export → Export for esmini**.
3. Masukkan nama dasar saat diminta.
4. Sebuah `<name>.zip` yang berisi `<name>.xodr` dan `<name>.xosc`
   akan terunduh.

## Putar kembali

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Format individual

Jika Anda hanya membutuhkan salah satu dari keduanya:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## Ekspor programatik

Exporter adalah bagian dari `@drawtonomy/sdk` dan berjalan tanpa
editor. Gunakan dalam pipeline CI, tooling sisi server, atau ekstensi
peramban:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Untuk API lengkap dan titik ekstensi, lihat
[Referensi Exporter SDK](/id/extend/exporter-sdk/).
