drawtonomy menyediakan beberapa format ekspor. Yang paling sering
digunakan adalah **drawtonomy.svg** — SVG biasa dengan metadata
tambahan, sehingga Anda dapat membuka kembali berkas dan melanjutkan
dari tempat Anda berhenti. Format ini juga adalah SVG valid, sehingga
dipratinjau dengan benar di peramban, slide, dan pipeline dokumentasi
tanpa konversi.

Format lain — PNG, JPG, SVG (datar), PDF, EPS — adalah untuk kasus di
mana Anda ingin gambar statis dan tidak perlu mengedit ulang.

Untuk output simulator mengemudi (OpenDRIVE / OpenSCENARIO /
Lanelet2), lihat halaman khusus
[ekspor ASAM](/id/guides/export-asam/).

## Mulai dari mana: drawtonomy.svg

`drawtonomy.svg` mempertahankan ID bentuk, koneksi jalur, titik
bersama, grup footprint, gaya, dan relasi
*bentuk-mana-yang-di-atas*. Berkas yang sama:

- **Dapat diedit ulang.** Tarik kembali ke drawtonomy dan adegan
  kembali persis seperti saat Anda tinggalkan — setiap koneksi,
  titik bersama, dan relasi tumpang tindih utuh.
- **Dapat dipratinjau.** Ini adalah SVG valid, jadi GitHub, peramban,
  renderer Markdown, dan alat slide menampilkannya dengan benar
  tanpa konversi.
- **Ramah dokumentasi.** Vektor, skala bersih, ukuran berkas kecil,
  tanpa artefak rasterisasi. Tetap tajam pada zoom apa pun di README
  atau gambar paper.

`drawtonomy.svg` adalah default yang masuk akal untuk apa pun yang
mungkin akan diedit kembali, dibagikan dengan rekan tim yang memiliki
drawtonomy, atau disematkan di dokumentasi teknis.

### Simpan sebagai drawtonomy.svg

1. Buka menu (kiri atas).
2. Klik **Export**.
3. Pilih **drawtonomy.svg**.

Berkas terunduh dengan nama berdasarkan judul adegan.

### Buka kembali

Tarik berkas kembali ke drawtonomy, atau gunakan **Import** di menu
yang sama. Seluruh adegan muncul di tab baru dengan setiap bentuk
dapat dipilih. Attribute Panel menampilkan bagian **OVERLAPPING
OBJECTS** ketika Anda mengklik area di mana bentuk tumpang tindih —
relasi antara, katakanlah, kendaraan dan jalur tempatnya berada
bertahan dalam round-trip.

## Format gambar lain

Ketika Anda hanya membutuhkan gambar datar — tanpa pengeditan, tanpa
metadata — pilih salah satu dari menu Export yang sama.

| Format | Gunakan untuk | Catatan |
|---|---|---|
| **PNG** | Slide, dokumen, halaman web | Raster lossless. |
| **JPG** | Berkas lebih kecil saat transparansi tidak dibutuhkan | Raster lossy. |
| **SVG** (datar) | Pasca-pemrosesan di Illustrator / Inkscape, penyematan web | Secara visual identik dengan drawtonomy.svg, tetapi metadata dihapus. |
| **PDF** | Cetak, arsip, paper | Vektor, mendukung transparansi. |
| **EPS** | Pipeline penerbitan lawas | Vektor. **Tidak mendukung transparansi** — lihat di bawah. |

### EPS dan transparansi

EPS tidak mengkodekan transparansi. Bentuk dengan opasitas 60% akan
diekspor dengan opasitas penuh. Jika adegan Anda mengandalkan
transparansi, ekspor PDF atau SVG sebagai gantinya.
