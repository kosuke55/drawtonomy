Lima menit dari kanvas kosong hingga adegan yang diekspor. Tanpa
instalasi.

## 1. Buka aplikasinya

Kunjungi [drawtonomy.com](https://drawtonomy.com). Semuanya berjalan di
browser; tidak ada yang diunggah.

## 2. Gambar sebuah jalur

1. Tekan <kbd>N</kbd>, atau klik alat **Lane** di toolbar.
2. Klik di kanvas untuk menempatkan awal centerline, klik lagi untuk
   titik berikutnya, dan tekan <kbd>Enter</kbd> untuk menyelesaikan.
3. Batas kiri dan kanan akan muncul secara otomatis.

:::tip
Tahan <kbd>Shift</kbd> saat menggambar untuk melewati [snap](/id/guides/snap/)
pada klik tersebut.
:::

## 3. Letakkan sebuah kendaraan

1. Tekan <kbd>P</kbd> untuk membuka alat **Participants**.
2. Pilih **Vehicle → Sedan** dan klik pada jalur yang baru saja Anda
   gambar.
3. Tarik handle sudut untuk mengubah ukuran, atau gunakan handle rotasi
   untuk menyelaraskan dengan jalur.

## 4. Ekspor adegan

Buka menu ekspor dan pilih format:

- **PNG / SVG / PDF** — bagikan sebagai gambar datar.
- **drawtonomy.svg** — menyimpan setiap koneksi sehingga Anda (atau
  rekan tim) dapat membukanya kembali dan terus mengedit nanti.
- **Export for esmini** — zip dengan OpenDRIVE + OpenSCENARIO yang siap
  diputar di [esmini](https://github.com/esmini/esmini).

[Ekspor adegan Anda](/id/guides/export/) menjelaskan format secara
rinci.
