## Bisakah saya menggunakan drawtonomy untuk menggambar gambar di paper, slide, atau dokumen tentang berkendara otonom?

Ya — itu adalah salah satu kasus penggunaan utama. Jalur, persimpangan,
kendaraan, dan pejalan kaki adalah bentuk bawaan, sehingga gambar
skenario mengemudi yang biasanya butuh setengah jam di alat menggambar
generik dapat selesai dalam hitungan menit. Ekspor sebagai
[`drawtonomy.svg`](/id/guides/export/), PDF, atau EPS untuk LaTeX,
slide, dan Markdown.

## Apakah drawtonomy gratis digunakan?

Ya. [drawtonomy.com](https://drawtonomy.com) berjalan sepenuhnya di
browser Anda. Tidak ada akun, tidak perlu instalasi, dan tidak ada yang
diunggah. SDK dan ekstensi bersifat open-source di
[GitHub](https://github.com/kosuke55/drawtonomy).

## Apakah drawtonomy adalah editor OpenSCENARIO dan OpenDRIVE gratis?

drawtonomy adalah papan tulis yang **mengekspor ke** ASAM OpenDRIVE 1.8
dan OpenSCENARIO 1.3, termasuk satu paket zip yang siap untuk pemutaran
[esmini](https://github.com/esmini/esmini). Anda menggambar adegan
secara visual — jalur, persimpangan, kendaraan, path — dan drawtonomy
menghasilkan berkas `.xodr` dan `.xosc`. Lihat
[Ekspor ke OpenDRIVE / OpenSCENARIO / esmini](/id/guides/export-asam/).

## Bisakah drawtonomy mengedit peta Lanelet2 (.osm) di browser?

Ya. drawtonomy dapat mengimpor berkas
[Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)
OSM (termasuk
[peta sampel Autoware](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map)),
mengedit geometri jalur dan koneksi secara visual, dan ekspor kembali
ke Lanelet2 OSM. Untuk performa terbaik, jaga impor di bawah sekitar
500 jalur per adegan. Lihat
[Impor berkas Lanelet2 (.osm)](/id/guides/import-lanelet2/).

## Bisakah saya mengimpor peta grid hunian ROS?

Ya. drawtonomy membaca format ROS `map_server` (`.pgm` + `.yaml`)
yang digunakan oleh [nav2](https://navigation.ros.org/), Cartographer,
Gmapping, dan alat SLAM serupa. Grid dirender sebagai lapisan latar
sehingga Anda dapat menggambar jalur, path, dan rintangan langsung di
atasnya. Lihat
[Impor ROS OccupancyGrid](/id/guides/import-ros-map/).

## Apa bedanya drawtonomy dengan alat menggambar generik?

Alat menggambar generik hanya tahu tentang bentuk umum, sehingga jalur
hanyalah persegi panjang yang harus Anda gambar ulang setiap kali jalan
berbelok. drawtonomy menyediakan **jalur, persimpangan, zebra cross,
lampu lalu lintas, marka jalan, kendaraan, dan pejalan kaki sebagai
bentuk bawaan**, dan jalur membawa koneksi
**Next / Previous / Left / Right**. Tarik batas dan jalur yang
terhubung akan mengikuti. Lihat
[Mengapa drawtonomy](/id/explanation/why-drawtonomy/) dan
[model koneksi jalur](/id/explanation/lane-model/).

## Apakah saya perlu menginstal sesuatu?

Tidak. drawtonomy berjalan di peramban web modern apa pun. Buka
[drawtonomy.com](https://drawtonomy.com) dan mulai menggambar.
Pengembang ekstensi juga dapat menggunakan dev server lokal
([`@drawtonomy/dev-server`](https://www.npmjs.com/package/@drawtonomy/dev-server)),
yang menjalankan editor di localhost.

## Bisakah drawtonomy menghasilkan skenario mengemudi dari bahasa alami?

Ya. Ekstensi [AI Scene Generator](/id/tutorials/ai-scene/) membaca
prompt bahasa alami atau XML OpenSCENARIO dan menghasilkan kanvas yang
dapat diedit — jalur, kendaraan, path, dan pejalan kaki sebagai bentuk
drawtonomy biasa. Mendukung Anthropic Claude, OpenAI GPT, dan Google
Gemini.

## Format berkas apa yang menjaga adegan drawtonomy tetap dapat diedit ulang?

`drawtonomy.svg`. Berkas ini adalah SVG biasa — dapat dipratinjau di
peramban, GitHub, slide, dan renderer Markdown — dengan metadata yang
digunakan drawtonomy untuk membangun kembali setiap bentuk, koneksi,
titik bersama, dan relasi tumpang tindih saat Anda membukanya kembali.
Lihat [Ekspor adegan Anda](/id/guides/export/) dan
[referensi format drawtonomy.svg](/id/reference/drawtonomy-svg/).

## Bisakah saya menambahkan template kendaraan atau rambu sendiri?

Ya. Template adalah SVG yang terdaftar di `templates/manifest.json`.
Letakkan SVG Anda di folder yang tepat (`vehicle`, `pedestrian`,
`road_marking`, `sign`, `other`), buka PR, dan template akan tampil di
menu editor di samping template bawaan. Lihat
[Berkontribusi template](/id/extend/templates/).

## Apakah drawtonomy mendukung jaringan jalan besar?

drawtonomy disesuaikan untuk diagram, bukan peta seukuran kota. Untuk
pengeditan yang responsif, jaga satu adegan di bawah sekitar **500
jalur**. Untuk area yang lebih besar, bagi pekerjaan ke beberapa berkas
atau impor hanya wilayah yang Anda butuhkan.

## Bisakah saya menggunakan diagram drawtonomy di paper, slide, atau dokumentasi?

Ya. Format [`drawtonomy.svg`](/id/guides/export/) adalah SVG valid,
sehingga dapat disematkan di paper, slide, Markdown, dan situs web
tanpa konversi. PDF, PNG, JPG, dan EPS juga tersedia untuk pipeline
penerbitan tradisional.

## Di mana kode sumbernya?

SDK, ekstensi, template, dan situs dokumentasi ini berada di
[github.com/kosuke55/drawtonomy](https://github.com/kosuke55/drawtonomy).
Aplikasinya sendiri ada di
[drawtonomy.com](https://drawtonomy.com).
