---

## Bentuk skenario mengemudi

| Bentuk | Tujuan |
|---|---|
| **Linestring** | Garis kontinu, digunakan untuk batas jalur, trotoar, marka. |
| **Lane** | Jalur yang dapat dilalui dengan dua batas, centerline, dan slot koneksi (Next / Previous / Left / Right). |
| **Vehicle** | Kendaraan ber-template (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | Pejalan kaki ber-template (Walking, Simple). |
| **Path** | Trajektori yang digunakan untuk panah, grup footprint, atau path skenario. Gaya panah atau pita. |
| **Polygon** | Area tertutup (tempat parkir, zona berarsir). |
| **Crosswalk** | Penyeberangan pejalan kaki yang sudah bergaya. |
| **TrafficLight** | Sinyal kendaraan atau pejalan kaki. |
| **Intersection** | Template persimpangan multi-jalur. |

## Bentuk dasar

| Bentuk | Tujuan |
|---|---|
| **LineArrow** | Panah segmen tunggal. |
| **Arrow** | Panah bebas-bentuk. |
| **Text** | Teks biasa atau beranotasi. |
| **Freehand** | Digambar dengan goresan seperti pena. |
| **Rectangle** | Persegi panjang sejajar sumbu. |
| **Ellipse** | Elips sejajar sumbu. |
| **Image** | PNG / JPG / SVG yang diimpor. |

## Template kustom

Anda dapat menambahkan template SVG untuk kendaraan, pejalan kaki,
marka jalan, dan rambu. Alur kontribusi ada di
[Panduan Template](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
