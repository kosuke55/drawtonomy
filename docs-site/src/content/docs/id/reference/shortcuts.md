## Beralih alat

| Tombol  | Alat                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (geser)              |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Operasi edit

| Tombol | Fungsi |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Salin |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Tempel |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Potong |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Hapus bentuk yang dipilih |

## Modifier saat menggambar

| Modifier | Efek |
|---|---|
| <kbd>Shift</kbd> | Nonaktifkan [snap](/id/guides/snap/) sementara |
| <kbd>Alt</kbd> + klik | [Bagikan titik yang ada](/id/guides/point-sharing/) (Linestring / Polygon / Path) |
| Klik dua kali | Masuk ke [pengeditan segmen](/id/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Pergerakan

| Tombol | Efek |
|---|---|
| Tombol panah | Pindahkan seleksi 1 px |
| <kbd>Shift</kbd> + panah | Pindahkan seleksi 10 px |
