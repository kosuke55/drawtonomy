Tutorial ini berisi pelajaran singkat dan praktis. Masing-masing
memandu Anda melalui tugas lengkap dari ujung ke ujung, sehingga Anda
dapat memahami editor dengan mengikutinya.

Jika Anda sudah tahu apa yang ingin Anda lakukan dan hanya butuh
langkah-langkahnya, [Panduan how-to](/id/guides/) biasanya lebih
cocok.

## Pelajaran

- [Mulai Cepat](/id/start/quickstart/) — jalur dan kendaraan pertama
  Anda dalam lima menit.
- [Tiga jalur pertama Anda](/id/tutorials/your-first-lanes/) — dua mode
  pembuatan dari alat Lane (Center Line dan Boundary).
- [Batas jalur yang mulus](/id/tutorials/smooth-lanes/) — mengaktifkan
  Smooth Boundary sebelum menggambar kurva.
- [Bangun ulang jalan nyata dari peta](/id/tutorials/road-from-map/) —
  menelusuri jalan di latar satelit, dengan generator satu klik
  sebagai pintasan.
- [Hasilkan adegan dengan AI, lalu sempurnakan secara manual](/id/tutorials/ai-scene/) —
  menjelaskan skenario dalam bahasa alami dan mengedit hasilnya.
