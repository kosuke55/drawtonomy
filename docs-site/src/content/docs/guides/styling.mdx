Every shape carries its own style. You can also change the editor-wide
defaults so new shapes start the way you want.

<Demo src="/videos/style-demo.mp4" caption="Per-shape colour, opacity, width, and template variant from the Attribute Panel." />

## Per-shape style

1. Press <kbd>V</kbd> for Select, then click a shape.
2. The **Attribute Panel** on the right exposes:
   - **Color** (palette + custom)
   - **Opacity** (0–100%)
   - **Width** (for line-like shapes)
   - **Style** (solid / dashed / template variant)

Multi-select to apply the same change to several shapes at once.

## Defaults

To make every new lane start at, say, 60% opacity:

1. Open the **hamburger** menu.
2. Pick **Defaults**.
3. Change the value under **Lane**.

Defaults take effect for newly created shapes. Existing shapes are not
touched.

## Color palette

drawtonomy uses a Tailwind-style palette (grey-100 through grey-900,
plus colours). For the full list, see
