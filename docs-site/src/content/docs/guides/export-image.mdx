## Export

1. Open the **File** menu → **Export**.
2. Pick the format. The file downloads immediately.

## Format choice

| Format | Use it when |
|---|---|
| **PNG** | Embedding in slides, docs, or web pages. Lossless raster. |
| **JPG** | Smaller files when you do not need transparency. |
| **SVG** | Embedding in web pages or post-processing in Illustrator/Inkscape. Vector, scalable. |
| **PDF** | Print, papers, archival. Vector, supports transparency. |
| **EPS** | Legacy publishing pipelines. Vector, **does not support transparency** — see below. |

## EPS and transparency

EPS does not encode transparency. A shape with opacity 60% will export
at full opacity. If your scene relies on transparency, export PDF or
SVG instead.

## Re-edit later

For a re-editable file that preserves every connection and shared
point, use [drawtonomy.svg](/guides/export-drawtonomy-svg/).
