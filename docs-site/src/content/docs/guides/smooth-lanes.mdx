drawtonomy can generate spline-fitted lane boundaries instead of
angular polylines. The toggle is in the Lane creation panel and
applies to lanes you draw next; it does not retroactively smooth an
existing lane.

<Demo src="/videos/smooth-lane.mp4" caption="A lane drawn with Smooth Boundary off (left, angular) and on (right, smooth)." />

## Where the toggle is

Press <kbd>N</kbd> for the Lane tool. The right panel includes a
**SMOOTH BOUNDARY** row with **On** and **Off** buttons:

![Lane creation panel — SMOOTH BOUNDARY toggle highlighted, currently Off](/img/frames/smooth-toggle-off.png)

The default is **Off**. Switch it on before you start clicking the
centerline.

## Compare

The two screenshots below were drawn with the same centerline. The
only thing that changed is the toggle:

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![Angular curve drawn with smoothing off](/img/frames/smooth-off-result.png) | ![Smooth curve drawn with smoothing on](/img/frames/smooth-on-result.png) |

With the toggle off, each pair of centerline clicks becomes a
straight boundary segment. With it on, the same centerline is
fitted to a curve.

## Switching mid-session

You can flip the toggle whenever you want. New lanes pick up the
current value the next time you click. Existing lanes keep whatever
boundary style they were drawn with.
