drawtonomy può leggere mappe in formato OSM
[Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2).
Le mappe campione sono disponibili nella
[documentazione di Autoware](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="Importazione di un file Lanelet2 completo." />

## Importare l'intero file

1. Apri il menu **File** → **Import**.
2. Seleziona il file `.osm`.
3. drawtonomy analizza il file e popola la tela con forme Lane
   e le loro connessioni.

## Importare solo corsie specifiche

Per mappe grandi, importare ogni corsia rallenterà l'editor.
Usa invece la finestra di dialogo di selezione delle corsie:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="Trascina-seleziona solo le corsie di tuo interesse, poi importa." />

1. Apri il menu **File** → **Import → Select lanes**.
2. drawtonomy mostra una mappa di anteprima.
3. Clicca o trascina per selezionare le corsie che vuoi.
4. Clicca **Import selection**.

## Suggerimenti sulle prestazioni

Mantieni la scena importata sotto le **500 corsie** circa per un
editor reattivo. Per aree più grandi, suddividi il lavoro in più
file, oppure importa solo la regione necessaria.

## Dopo l'importazione

Le corsie importate sono forme Lane a piena fedeltà; le
connessioni dal file Lanelet2 sono preservate. Modifica,
[smussa](/it/guides/smooth-lanes/) o
[esporta nuovamente](/it/guides/export-asam/) senza perdere la
topologia.
