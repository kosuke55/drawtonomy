drawtonomy può esportare la tua scena come ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) e
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`), oppure raggruppare entrambi come zip pronto per la
riproduzione con [esmini](https://github.com/esmini/esmini).

![Una scena drawtonomy riprodotta in esmini dopo l'esportazione](/img/asam-esmini.png)

## Esportare dall'editor

1. Disegna la tua scena (corsie, veicoli, semafori…).
2. Apri **File → Export → Export for esmini**.
3. Inserisci un nome di base quando richiesto.
4. Viene scaricato un `<nome>.zip` contenente `<nome>.xodr` e
   `<nome>.xosc`.

## Riprodurla

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Formati individuali

Se ti serve solo uno dei due:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## Esportazione programmatica

L'esportatore fa parte di `@drawtonomy/sdk` e gira senza
l'editor. Usalo in pipeline CI, strumenti lato server o
estensioni del browser:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Per l'API completa e i punti di estensione, vedi il
[riferimento dell'Exporter SDK](/it/extend/exporter-sdk/).
