drawtonomy fornisce diversi formati di esportazione. Quello a cui
ricorrere la maggior parte delle volte è **drawtonomy.svg** — un
normale SVG con metadati extra, così puoi riaprire il file e
riprendere da dove avevi lasciato. È anche SVG valido, quindi si
visualizza correttamente in browser, presentazioni e pipeline di
documentazione senza conversione.

Gli altri formati — PNG, JPG, SVG (piatto), PDF, EPS — sono per
casi in cui vuoi un'immagine statica e non hai bisogno di
modificarla di nuovo.

Per l'output dei simulatori di guida (OpenDRIVE / OpenSCENARIO /
Lanelet2), vedi la pagina dedicata
[esportazione ASAM](/it/guides/export-asam/).

## Da dove iniziare: drawtonomy.svg

`drawtonomy.svg` preserva gli ID delle forme, le connessioni
delle corsie, i punti condivisi, i gruppi footprint, lo stile e
le relazioni di *quale-forma-è-sopra*. Lo stesso file è:

- **Modificabile.** Trascinalo di nuovo in drawtonomy e la scena
  ritorna esattamente come l'avevi lasciata — ogni connessione,
  punto condiviso e relazione di sovrapposizione intatti.
- **Visualizzabile.** È SVG valido, quindi GitHub, browser,
  renderer Markdown e strumenti di presentazione lo visualizzano
  correttamente senza conversione.
- **Adatto alla documentazione.** Vettoriale, scala bene,
  dimensione del file ridotta, nessun artefatto di
  rasterizzazione. Rimane nitido a qualsiasi zoom in un README o
  in una figura di articolo.

`drawtonomy.svg` è un default ragionevole per qualsiasi cosa
possa essere modificata di nuovo, condivisa con un collega che
ha drawtonomy o incorporata nella documentazione tecnica.

### Salvare come drawtonomy.svg

1. Apri il menu (in alto a sinistra).
2. Clicca **Export**.
3. Scegli **drawtonomy.svg**.

Il file viene scaricato con un nome basato sul titolo della
scena.

### Riaprire

Trascina il file di nuovo in drawtonomy, o usa **Import** dallo
stesso menu. L'intera scena appare in una nuova scheda con ogni
forma selezionabile. Il pannello degli attributi mostra una
sezione **OVERLAPPING OBJECTS** quando clicchi in un'area in cui
le forme si sovrappongono — la relazione tra, per esempio, un
veicolo e la corsia su cui si trova sopravvive al round-trip.

## Altri formati di immagine

Quando hai bisogno solo di un'immagine piatta — niente modifica,
niente metadati — scegli uno di questi dallo stesso menu Export.

| Formato | Da usare per | Note |
|---|---|---|
| **PNG** | Slide, documenti, pagine web | Raster senza perdita. |
| **JPG** | File più piccoli quando la trasparenza non serve | Raster con perdita. |
| **SVG** (piatto) | Post-elaborazione in Illustrator / Inkscape, incorporamento web | Visivamente identico a drawtonomy.svg, ma i metadati sono rimossi. |
| **PDF** | Stampa, archiviazione, articoli | Vettoriale, supporta la trasparenza. |
| **EPS** | Pipeline di pubblicazione tradizionali | Vettoriale. **Non supporta la trasparenza** — vedi sotto. |

### EPS e trasparenza

EPS non codifica la trasparenza. Una forma con opacità del 60%
verrà esportata a piena opacità. Se la tua scena si basa sulla
trasparenza, esporta in PDF o SVG.
