## Segnalazioni di bug, richieste di funzionalità e domande

➡ **[Apri una issue su GitHub](https://github.com/kosuke55/drawtonomy/issues/new)**

Una breve riproduzione (passi + comportamento atteso vs. effettivo) aiuta
molto per i bug. Anche screenshot o un file `drawtonomy.svg` salvato
dello stato problematico sono ben accetti.
