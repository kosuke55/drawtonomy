## Cambio strumento

| Tasto  | Strumento                          |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (panoramica)         |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Operazioni di modifica

| Tasti | Funzione |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Annulla |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ripeti |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copia |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Incolla |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Taglia |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Elimina forma/e selezionata/e |

## Modificatori durante il disegno

| Modificatore | Effetto |
|---|---|
| <kbd>Shift</kbd> | Disabilita temporaneamente lo [snap](/it/guides/snap/) |
| <kbd>Alt</kbd> + clic | [Condividi un punto esistente](/it/guides/point-sharing/) (Linestring / Polygon / Path) |
| Doppio clic | Entra nella [modifica dei segmenti](/it/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Movimento

| Tasti | Effetto |
|---|---|
| Frecce direzionali | Sposta la selezione di 1 px |
| <kbd>Shift</kbd> + freccia | Sposta la selezione di 10 px |
