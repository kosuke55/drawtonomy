## Forme per scenari di guida

| Forma | Scopo |
|---|---|
| **Linestring** | Linea continua, usata per bordi di corsia, cordoli, segnaletica. |
| **Lane** | Una corsia percorribile con due bordi, una linea centrale e slot di connessione (Successiva / Precedente / Sinistra / Destra). |
| **Vehicle** | Veicolo con template (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | Pedone con template (Walking, Simple). |
| **Path** | Traiettoria usata per frecce, gruppi footprint o percorsi di scenario. Stile freccia o banda. |
| **Polygon** | Area chiusa (parcheggio, zona tratteggiata). |
| **Crosswalk** | Attraversamento pedonale prestilizzato. |
| **TrafficLight** | Semaforo per veicoli o pedoni. |
| **Intersection** | Template di incrocio multi-corsia. |

## Forme di base

| Forma | Scopo |
|---|---|
| **LineArrow** | Freccia a segmento singolo. |
| **Arrow** | Freccia a forma libera. |
| **Text** | Testo semplice o annotato. |
| **Freehand** | Disegnata con tratto in stile penna. |
| **Rectangle** | Rettangolo allineato agli assi. |
| **Ellipse** | Ellisse allineata agli assi. |
| **Image** | PNG / JPG / SVG importati. |

## Template personalizzati

Puoi aggiungere template SVG per veicoli, pedoni, segnaletica
orizzontale e segnali. Il flusso di contribuzione è nella
[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
