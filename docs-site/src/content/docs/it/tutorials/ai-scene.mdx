L'estensione [AI Scene Generator](https://github.com/kosuke55/drawtonomy/tree/main/extensions/ai-scene-generator)
prende un prompt in linguaggio naturale, XML OpenSCENARIO o input
DSL e produce un canvas modificabile.

<Demo src="/videos/ai-scene-natural.mp4" caption="Scenario in linguaggio naturale → scena modificabile sulla tela." maxWidth="900px" />

## 1. Aprire l'AI Scene Generator

1. Clicca **Extensions** in basso a destra della tela.
2. Scegli **AI Scene Generator**.
3. Scegli il tuo provider IA (Anthropic Claude, OpenAI GPT o
   Google Gemini) e incolla la tua chiave API. La chiave rimane
   nel tuo browser.

## 2. Descrivere la scena

Incolla un prompt come:

> Un'autostrada a 3 corsie da sinistra a destra. Una berlina ego
> (blu) nella corsia centrale, un camion (grigio) nella corsia
> destra leggermente in avanti. Mostra una traiettoria
> tratteggiata per il veicolo ego che cambia verso la corsia
> sinistra.

Clicca **Generate**. L'estensione dispone corsie, veicoli e una
forma Path sulla tela.

## 3. Rifinire

Tutto ciò che viene generato è una forma normale. Prova a:

- Selezionare il camion e cambiare il suo template in **Bus**.
- Trascinare la traiettoria del veicolo ego verso una curva
  diversa.
- Aggiungere un pedone sulla corsia di emergenza.

## 4. Oppure partire da OpenSCENARIO

Nello stesso pannello, cambia la modalità di input in
**OpenSCENARIO XML** e incolla un file `.xosc`. L'estensione
dispone gli attori e le traiettorie sulla tela — il modo più
veloce per visualizzare uno scenario esistente.

<Demo src="/videos/ai-scene-dsl.mp4" caption="Un esempio di ASAM OpenSCENARIO DSL posizionato sulla tela." maxWidth="900px" />

## Cosa hai imparato

- La generazione tramite IA è un punto di partenza — ogni forma
  successiva è modificabile come qualsiasi altra cosa sulla
  tela.
- Lo stesso pannello accetta prompt in linguaggio naturale e
  input OpenSCENARIO, così puoi passare tra idea grezza e
  specifica formale senza lasciare l'editor.

Per pattern di prompt che funzionano bene, vedi il
[README dell'AI Scene Generator](https://github.com/kosuke55/drawtonomy/tree/main/extensions/ai-scene-generator).
