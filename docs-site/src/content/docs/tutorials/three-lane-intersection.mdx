By the end of this lesson you will have a four-way intersection with
three lanes per approach, all connected so they move together when you
edit them.

<Demo src="/videos/intersection-demo.mp4" caption="Intersection templates drop a fully-connected junction in one click." />

You should already have done the [Quickstart](/start/quickstart/), or
at least know how to draw a single lane.

## 1. Place an intersection template

1. Press <kbd>I</kbd> to open the **Intersection** tool.
2. Pick the **4-way, 3-lanes-per-approach** template from the
   thumbnail strip.
3. Click anywhere on the canvas to place it.

The intersection arrives pre-connected: the lanes that pass through it
already know which lane is "next" on the other side.

## 2. Extend an approach

1. Press <kbd>N</kbd> for the **Lane** tool.
2. Hover the end of one approach. Snap markers (indigo dots) appear on
   the existing lane endpoints.
3. Click on a snap marker to start a new centerline that picks up
   where the approach ends, then click further out to extend.
4. Press <kbd>Enter</kbd> to finish.

Because you started on an existing lane endpoint, drawtonomy
automatically sets that lane as the **Previous** of the new one.

## 3. Add parallel lanes

Either repeat step 2 for the lanes either side, or use the parallel
shortcut: with the Lane tool active, hold <kbd>Alt</kbd> and click the
existing lane on the side where you want a new one.

<Demo src="/videos/lane-tool-demo.mp4" caption="The Lane tool draws and connects in one motion." />

## 4. Verify connections

1. Press <kbd>V</kbd> for the **Select** tool.
2. Click any lane.
3. The **Attribute Panel** on the right lists **Next**, **Previous**,
   **Left**, and **Right** lanes. Hover an entry to highlight that
   neighbour on the canvas.

If a connection is missing, click **+** in the panel and pick the
neighbouring lane on the canvas.

## 5. Smooth the approaches

For each approach lane, click **Smooth** in the Attribute Panel. The
boundaries are spline-fitted in place, while the centerline is
preserved.

<Demo src="/videos/smooth-lane.mp4" caption="One click on Smooth replaces angular boundaries with curves." />

Read more in [Smoothing lane boundaries](/guides/smooth-lanes/).

## 6. Export

Save the file as `drawtonomy.svg` so you can re-edit it later. If you
want to try the result in a simulator, use **Export for esmini** to
produce an [OpenDRIVE + OpenSCENARIO bundle](/guides/export-asam/).

## What you learned

- Intersection templates are the fastest way to start a junction.
- Snapping to lane endpoints establishes Next / Previous links
  automatically.
- The Attribute Panel is where you inspect and edit lane topology.
