El Generador de Carriles extrae geometría de carretera real de
OpenStreetMap y la convierte en formas de Carril editables
alineadas con el fondo del mapa.

<Demo src="/videos/map-to-lane-demo.mp4" caption="Haz clic en una carretera para un carril, arrastra una región para varios." maxWidth="900px" />

## Activa un fondo de mapa

1. Abre el menú **Fondo** en la parte superior izquierda del
   lienzo.
2. Elige **Satélite** (fotográfico) o **Mapa de carreteras**
   (esquemático).
3. Desplázate y haz zoom hasta el área que quieras.

El mapa se renderiza detrás del lienzo y se mantiene anclado
mientras dibujas.

## Generar un solo carril

1. Pulsa <kbd>N</kbd> para la herramienta Carril.
2. Activa el modo **Generador** en la barra de herramientas.
3. Pasa el cursor sobre una carretera. drawtonomy resalta el
   segmento de carretera OSM coincidente bajo el cursor.
4. Haz clic. El segmento se obtiene y se convierte en una forma
   de Carril.

## Generar todas las carreteras de una región

Con el modo Generador activado:

1. Arrastra un rectángulo sobre el área que quieras capturar.
2. Suelta. Cada carretera dentro del rectángulo se convierte en un
   Carril en un solo lote.

Útil para intersecciones completas, barrios o sitios de prueba.

## Límites recomendados

La obtención y conversión de OSM se ejecuta en el navegador. Para
una edición fluida, mantén la escena resultante por debajo de
unos **500 carriles** — divide un área más grande entre varios
archivos si necesitas más.

## Después de generar

Los carriles generados son formas de Carril normales. Puedes:

- Arrastrar puntos para refinar la geometría.
- Aplicar [Smooth](/es/guides/smooth-lanes/) para reemplazar
  polilíneas densas por splines.
- Establecer [conexiones](/es/guides/lane-connections/) donde el
  generador no las haya inferido automáticamente.
- Colocar vehículos, peatones o trayectorias encima.
