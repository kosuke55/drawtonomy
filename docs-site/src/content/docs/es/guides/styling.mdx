Cada forma tiene su propio estilo. También puedes cambiar los
valores por defecto del editor para que las nuevas formas
empiecen como tú quieras.

<Demo src="/videos/style-demo.mp4" caption="Color, opacidad, ancho y variante de plantilla por forma desde el Panel de Atributos." />

## Estilo por forma

1. Pulsa <kbd>V</kbd> para Seleccionar, luego haz clic en una
   forma.
2. El **Panel de Atributos** a la derecha expone:
   - **Color** (paleta + personalizado)
   - **Opacidad** (0–100%)
   - **Ancho** (para formas tipo línea)
   - **Estilo** (sólido / discontinuo / variante de plantilla)

Selecciona varios para aplicar el mismo cambio a varias formas a
la vez.

## Valores por defecto

Para que cada nuevo carril empiece a, digamos, 60% de opacidad:

1. Abre el menú de **hamburguesa**.
2. Elige **Valores por defecto**.
3. Cambia el valor bajo **Carril**.

Los valores por defecto se aplican a las formas recién creadas.
Las formas existentes no se tocan.

## Paleta de colores
