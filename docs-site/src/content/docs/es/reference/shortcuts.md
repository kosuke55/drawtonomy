## Cambio de herramienta

| Tecla  | Herramienta                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Mano (desplazamiento)                |
| <kbd>V</kbd>    | Seleccionar                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Carril                      |
| <kbd>P</kbd>    | Participantes (Vehículo / Peatón) |
| <kbd>H</kbd>    | Trayectoria                      |
| <kbd>G</kbd>    | Polígono                   |
| <kbd>X</kbd>    | Paso de peatones                 |
| <kbd>I</kbd>    | Intersección              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Texto                      |
| <kbd>D</kbd>    | Dibujo a mano alzada                  |

## Operaciones de edición

| Teclas | Función |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Deshacer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Rehacer |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copiar |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Pegar |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Cortar |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Eliminar forma(s) seleccionada(s) |

## Modificadores al dibujar

| Modificador | Efecto |
|---|---|
| <kbd>Shift</kbd> | Desactivar temporalmente [snap](/es/guides/snap/) |
| <kbd>Alt</kbd> + clic | [Compartir un punto existente](/es/guides/point-sharing/) (Linestring / Polígono / Trayectoria) |
| Doble clic | Entrar en [edición de segmentos](/es/guides/segment-editing/) (Linestring / Carril / Polígono) |

## Movimiento

| Teclas | Efecto |
|---|---|
| Teclas de flecha | Mover la selección 1 px |
| <kbd>Shift</kbd> + flecha | Mover la selección 10 px |
