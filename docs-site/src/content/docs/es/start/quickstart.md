Cinco minutos desde un lienzo en blanco hasta una escena exportada.
Sin instalación.

## 1. Abre la app

Ve a [drawtonomy.com](https://drawtonomy.com). Todo se ejecuta en
el navegador; nada se sube.

## 2. Dibuja un carril

1. Pulsa <kbd>N</kbd>, o haz clic en la herramienta **Carril** en la
   barra de herramientas.
2. Haz clic en el lienzo para colocar el inicio de la línea central,
   haz clic de nuevo para el siguiente vértice y pulsa
   <kbd>Enter</kbd> para terminar.
3. Los bordes izquierdo y derecho aparecen automáticamente.

:::tip
Mantén pulsado <kbd>Shift</kbd> mientras dibujas para omitir el
[snap](/es/guides/snap/) en ese clic.
:::

## 3. Coloca un vehículo

1. Pulsa <kbd>P</kbd> para abrir la herramienta **Participantes**.
2. Elige **Vehículo → Sedán** y haz clic en el carril que acabas de
   dibujar.
3. Arrastra un controlador de esquina para redimensionar, o usa el
   controlador de rotación para alinearlo con el carril.

## 4. Exporta la escena

Abre el menú de exportación y elige un formato:

- **PNG / SVG / PDF** — comparte como una imagen plana.
- **drawtonomy.svg** — guarda cada conexión para que tú (o un
  compañero) puedas reabrir y seguir editando más tarde.
- **Exportar para esmini** — un zip con OpenDRIVE + OpenSCENARIO
  listo para reproducir en
  [esmini](https://github.com/esmini/esmini).

[Exportar tu escena](/es/guides/export/) cubre los formatos en detalle.
