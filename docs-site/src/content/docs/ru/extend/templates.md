Шаблоны — это SVG-файлы плюс запись в манифесте. После добавления
они появляются в меню Participants и в меню фигур редактора рядом со
встроенными шаблонами.

Процесс добавления — в публичном репозитории:

➡ **[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md)**

## Категории

| Папка | Примеры |
|---|---|
| `templates/vehicle/` | Sedan, Bus, Truck, Motorcycle |
| `templates/pedestrian/` | Walking, Simple |
| `templates/road_marking/` | Crosswalk, разметка-стрелки |
| `templates/sign/` | Stop, yield, головки сигналов |
| `templates/other/` | Что угодно ещё |

## Процесс

1. Добавьте свой SVG в нужную папку категории.
2. Зарегистрируйте его в `templates/manifest.json`.
3. Откройте PR. Включите скриншот шаблона, размещённого на холсте.

## Что делает шаблон хорошим

- Нарисован в разумном размере по умолчанию (транспорт около 4–5 м
  для седана).
- Одна меняющая цвет область, помеченная известной заливкой, чтобы
  выбор цвета в панели атрибутов мог её перекрашивать.
- Нет внешних ссылок на шрифты — текст преобразован в пути, если он
  присутствует.
- Разумный размер файла (под ~30 КБ для шаблона размера транспорта).
