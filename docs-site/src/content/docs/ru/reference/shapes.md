## Фигуры сценариев вождения

| Фигура | Назначение |
|---|---|
| **Linestring** | Непрерывная линия, используемая для границ полос, бордюров, разметки. |
| **Lane** | Проезжая полоса с двумя границами, центральной линией и слотами связей (Next / Previous / Left / Right). |
| **Vehicle** | Шаблонное транспортное средство (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | Шаблонный пешеход (Walking, Simple). |
| **Path** | Траектория, используемая для стрелок, групп footprint или путей сценария. Стиль стрелки или ленты. |
| **Polygon** | Замкнутая область (парковка, заштрихованная зона). |
| **Crosswalk** | Предварительно стилизованный пешеходный переход. |
| **TrafficLight** | Сигнал для транспорта или пешеходов. |
| **Intersection** | Шаблон многополосного перекрёстка. |

## Базовые фигуры

| Фигура | Назначение |
|---|---|
| **LineArrow** | Стрелка из одного отрезка. |
| **Arrow** | Свободная стрелка. |
| **Text** | Простой или аннотированный текст. |
| **Freehand** | Нарисовано штрихом, похожим на ручку. |
| **Rectangle** | Прямоугольник, выровненный по осям. |
| **Ellipse** | Эллипс, выровненный по осям. |
| **Image** | Импортированный PNG / JPG / SVG. |

## Пользовательские шаблоны

Вы можете добавлять SVG-шаблоны для транспорта, пешеходов, дорожной
разметки и знаков. Процесс участия описан в
[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
