## Переключение инструментов

| Клавиша | Инструмент |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (панорамирование)    |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Операции редактирования

| Клавиши | Функция |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Отменить |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторить |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Копировать |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Вставить |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Вырезать |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Удалить выбранную фигуру (фигуры) |

## Модификаторы при рисовании

| Модификатор | Эффект |
|---|---|
| <kbd>Shift</kbd> | Временно отключить [привязку](/ru/guides/snap/) |
| <kbd>Alt</kbd> + щелчок | [Разделить существующую точку](/ru/guides/point-sharing/) (Linestring / Polygon / Path) |
| Двойной щелчок | Войти в [редактирование сегментов](/ru/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Перемещение

| Клавиши | Эффект |
|---|---|
| Стрелки | Сдвинуть выделение на 1 px |
| <kbd>Shift</kbd> + стрелка | Сдвинуть выделение на 10 px |
