---
title: Цветовая палитра
description: Цветовые ключи drawtonomy и их HEX-значения.
---

drawtonomy использует палитру в стиле Tailwind / Material:
grey-100 (самый светлый) до grey-900 (самый тёмный), плюс именованные
цвета.

## Оттенки серого

| Ключ | HEX | Замечания |
|---|---|---|
| `grey-100` | `#e6e6e6` | Самый светлый. По умолчанию для Vehicle (Simple). |
| `grey-200` | `#cccccc` | |
| `grey-300` | `#b3b3b3` | По умолчанию для Pedestrian (Walking & Simple). |
| `grey-400` | `#999999` | |
| `grey-500` | `#808080` | Средний серый. |
| `grey-600` | `#666666` | |
| `grey-700` | `#4d4d4d` | |
| `grey-800` | `#333333` | |
| `grey-900` | `#1a1a1a` | Самый тёмный. |

Меньшее число = светлее. Это совпадает с конвенцией Tailwind.

## Значения по умолчанию для шаблонов

| Шаблон | Цвет по умолчанию |
|---|---|
| Pedestrian (Walking) | `grey-300` |
| Pedestrian (Simple) | `grey-300` |
| Vehicle (Simple) | `grey-100` |
| Другие фигуры | `black` |

## Установка цвета программно

Используйте `resolveColor()` из SDK для конвертации ключа в
HEX-значение. Подробности см. в
[API SDK расширений](/ru/extend/extension-sdk/).
