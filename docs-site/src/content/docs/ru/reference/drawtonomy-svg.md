Файл `drawtonomy.svg` — это обычный SVG, дополненный метаданными,
которые записывают состояние, относящееся только к редактору.

## Структура

- Визуальный контент (paths, text, images) — это обычный SVG. Любой
  SVG-просмотрщик корректно его рендерит.
- Блок `<metadata>` в начале документа содержит данные,
  специфичные для drawtonomy:
  - ID фигур и их свойства (template, style и т. д.)
  - слоты связей полос (`next`, `previous`, `left`, `right`)
  - ссылки на общие точки
  - принадлежность к группам footprint
  - z-порядок

## Совместимость

Редактирование `drawtonomy.svg` в универсальном SVG-редакторе
(Illustrator, Inkscape, браузер) удаляет блок метаданных при
сохранении, если вы не сохраните его явно. drawtonomy всё ещё может
открыть результат, но связи и общие точки будут отсутствовать.

Для редактирования с обменом вне drawtonomy используйте SDK
([`@drawtonomy/sdk`](/ru/reference/sdk/)) — он умеет читать и
записывать формат, не проходя через редактор.

## Версионирование

Старые файлы автоматически мигрируются при импорте. Хелпер
`resolveColorKey()` в SDK конвертирует устаревшие цветовые ключи
(например, v1.x `grey-700`) в текущие.
