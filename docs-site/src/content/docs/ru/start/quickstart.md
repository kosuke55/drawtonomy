Пять минут от пустого холста до экспортированной сцены. Без
установки.

## 1. Откройте приложение

Перейдите на [drawtonomy.com](https://drawtonomy.com). Всё работает
в браузере, ничего не загружается на сервер.

## 2. Нарисуйте полосу

1. Нажмите <kbd>N</kbd> или щёлкните инструмент **Lane** на панели
   инструментов.
2. Щёлкните по холсту, чтобы поставить начало центральной линии,
   щёлкните ещё раз для следующей вершины и нажмите <kbd>Enter</kbd>,
   чтобы завершить.
3. Левая и правая границы появляются автоматически.

:::tip
Удерживайте <kbd>Shift</kbd> при рисовании, чтобы обойти
[привязку](/ru/guides/snap/) для этого щелчка.
:::

## 3. Разместите транспортное средство

1. Нажмите <kbd>P</kbd>, чтобы открыть инструмент **Participants**.
2. Выберите **Vehicle → Sedan** и щёлкните по только что
   нарисованной полосе.
3. Потяните угловой маркер для изменения размера или используйте
   маркер вращения, чтобы выровнять автомобиль вдоль полосы.

## 4. Экспортируйте сцену

Откройте меню экспорта и выберите формат:

- **PNG / SVG / PDF** — поделиться плоским изображением.
- **drawtonomy.svg** — сохраняет все связи, чтобы вы (или коллега)
  могли снова открыть и продолжить редактирование.
- **Export for esmini** — ZIP с OpenDRIVE + OpenSCENARIO, готовый
  к воспроизведению в [esmini](https://github.com/esmini/esmini).

[Экспорт сцены](/ru/guides/export/) подробно описывает форматы.
