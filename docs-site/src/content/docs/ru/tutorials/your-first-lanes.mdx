Этот урок повторяет официальное демо инструмента Lane. К концу вы
освоите оба способа создания полос в drawtonomy:

- **Режим Center Line** — нарисуйте центральную линию; левая и
  правая границы генерируются автоматически.
- **Режим Boundary** — выберите две существующие линии-границы, и
  drawtonomy впишет полосу между ними.

Демо рисует две полосы в режиме Center Line, затем переключается в
режим Boundary для третьей полосы, которая заполняет промежуток.

<Demo src="/videos/lane-tool-demo.mp4" caption="Две полосы по центральной линии, затем третья полоса, построенная из существующих границ в режиме Boundary." />

## 1. Выберите инструмент Lane

Откройте [drawtonomy.com](https://drawtonomy.com). Нажмите
<kbd>N</kbd> (или щёлкните иконку полосы на нижней панели).

Правая часть экрана теперь показывает панель создания **Lane** с
выбранным по умолчанию **Center Line**:

![Панель Lane — режим Center Line активен, Lane Width 50 px](/img/frames/lane-tool-panel.png)

Пока оставьте значения по умолчанию.

## 2. Нарисуйте две полосы в режиме Center Line

В режиме Center Line щёлкайте по холсту, чтобы поставить первую
точку центральной линии, щёлкните дальше для следующей и нажмите
<kbd>Enter</kbd>, чтобы завершить. Левая и правая границы появляются
автоматически с использованием значения **Lane Width** (по умолчанию
50 px).

Инструмент Lane остаётся активным после каждой полосы, поэтому
щёлкните где-нибудь ещё, чтобы начать вторую. Поставьте пару точек
справа от первой полосы и нажмите <kbd>Enter</kbd>:

![Две полосы, нарисованные рядом в режиме Center Line](/img/frames/lane-tool-two-lanes.png)

Сейчас две полосы независимы — они не делят границу и ничего не
знают друг о друге.

## 3. Переключитесь в режим Boundary

Щёлкните **Boundary** в той же панели, рядом с **Center Line**, чтобы
переключить режимы создания. В режиме Boundary вы не щёлкаете по
пустому пространству; вы щёлкаете по **существующим линиям-границам**,
и drawtonomy вписывает полосу между ними.

Наведите курсор на **правую границу левой полосы** — drawtonomy
подсвечивает линию индиго, когда курсор достаточно близко — и
щёлкните:

![Режим Boundary — правая граница левой полосы подсвечена и готова к выбору](/img/frames/lane-tool-boundary-mode.png)

Затем щёлкните **левую границу правой полосы**. Новая полоса
заполняет промежуток, используя обе щёлкнутые линии как свои левую
и правую границы.

## 4. Изучите результат

Нажмите <kbd>V</kbd> для инструмента Select и щёлкните новую среднюю
полосу. Правая панель переключается на её атрибуты:

![Панель атрибутов — новая средняя полоса делит границы way/1 и way/2 со своими соседями](/img/frames/lane-attributes.png)

Границы переиспользованы:

- **Lane ID** — `lane/2`, совершенно новая полоса.
- **Left Boundary** — `way/1`, та же линия, которая является правой
  границей левой полосы.
- **Right Boundary** — `way/2`, аналогично, общая с правой полосой.

Поскольку границы общие, перетаскивание точки на любой стороне
двигает обе соседние полосы вместе. На этом построены
[связи полос](/ru/explanation/lane-model/); прочитайте эту страницу
дальше для понимания базовой модели.

Панель также раскрывает **Direction**, **Lane Color**, **Lane
Opacity** и четыре слота связей **Next Lanes / Prev Lanes /
Left Lane / Right Lane**, которые мы пока оставляем пустыми.

## Что вы узнали

- Полосы можно рисовать двумя способами: по центральной линии или
  выбором двух существующих линий-границ.
- Режим Center Line — быстрый вариант для пустого холста; режим
  Boundary вписывает полосу в существующую геометрию без её
  перерисовки.
- Полоса, построенная из существующих границ, делит эти границы со
  своими соседями.
