Это второй короткий урок после
[Ваши первые три полосы](/ru/tutorials/your-first-lanes/). Одна
маленькая привычка: включайте **Smooth Boundary** перед рисованием
изогнутой полосы.

Переключатель находится в панели создания Lane и меняет способ
генерации границ для следующих полос. Существующие полосы не
затрагиваются.

<Demo src="/videos/smooth-lane.mp4" caption="Одна и та же изогнутая центральная линия, нарисованная дважды — один раз с выключенным Smooth Boundary, один раз с включённым." />

## 1. Откройте панель Lane

Нажмите <kbd>N</kbd> для инструмента Lane. Откроется панель справа.
Найдите строку **SMOOTH BOUNDARY** — по умолчанию она **Off**:

![Панель создания Lane — строка SMOOTH BOUNDARY, в данный момент Off](/img/frames/smooth-toggle-off.png)

## 2. Нарисуйте изогнутую полосу с выключенным переключателем

Оставьте переключатель в **Off**. Щёлкайте по холсту, расставляя
точки центральной линии вдоль кривой, и нажмите <kbd>Enter</kbd>,
чтобы завершить.

Границы — это прямые отрезки между последовательными точками,
поэтому полоса получается угловатой:

![Изогнутая полоса, нарисованная с Smooth Boundary off — границы это угловатые ломаные](/img/frames/smooth-off-result.png)

## 3. Включите переключатель и нарисуйте ту же полосу снова

Щёлкните **On** в строке SMOOTH BOUNDARY. Щёлкните аналогичную
центральную линию в другом месте холста и нажмите <kbd>Enter</kbd>.

На этот раз границы аппроксимированы сплайнами, поэтому полоса
изгибается плавно:

![Изогнутая полоса, нарисованная с Smooth Boundary on — границы следуют плавной кривой](/img/frames/smooth-on-result.png)

Бок о бок разница очевидна. Центральные линии одинаковы; изменилось
только правило генерации границ.

## Когда оставить выключенным, когда включать

| | Smooth = Off | Smooth = On |
| --- | --- | --- |
| Внешний вид | Угловатый, гранёный | Плавный |
| Лучше для | Прямые полосы, плечи перекрёстков | Изогнутые дороги, развязки |
| Производительность | Чуть дешевле | Чуть больше геометрии |

Переключатель можно щёлкать сколько угодно. Каждая новая полоса
использует то значение, которое стоит на момент завершения её
рисования.

## Что вы узнали

- Переключатель Smooth Boundary находится в панели создания Lane и
  применяется к следующей полосе, которую вы нарисуете, а не к
  выбранной.
- Геометрия центральной линии одинакова в обоих режимах; отличается
  только отрисовка границ.
