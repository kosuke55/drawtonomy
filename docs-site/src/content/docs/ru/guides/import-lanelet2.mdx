drawtonomy умеет читать карты в формате
[Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)
OSM. Образцы карт доступны из
[документации Autoware](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="Импорт целого файла Lanelet2." />

## Импорт всего файла

1. Откройте меню **File** → **Import**.
2. Выберите файл `.osm`.
3. drawtonomy парсит файл и заполняет холст фигурами Lane вместе с
   их связями.

## Импорт только определённых полос

Для больших карт импорт каждой полосы замедлит редактор. Используйте
вместо этого диалог выбора полос:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="Выделите перетаскиванием только нужные полосы и импортируйте." />

1. Откройте меню **File** → **Import → Select lanes**.
2. drawtonomy показывает превью карты.
3. Щёлкайте или перетаскивайте, чтобы выбрать нужные полосы.
4. Щёлкните **Import selection**.

## Советы по производительности

Держите импортированную сцену под примерно **500 полосами** для
отзывчивого редактора. Для больших областей разделите работу на
несколько файлов или импортируйте только нужный участок.

## После импорта

Импортированные полосы — полноценные фигуры Lane; связи из файла
Lanelet2 сохраняются. Редактируйте, [сглаживайте](/ru/guides/smooth-lanes/)
или [экспортируйте обратно](/ru/guides/export-asam/), не теряя
топологии.
