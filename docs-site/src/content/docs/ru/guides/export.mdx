drawtonomy поставляется с несколькими форматами экспорта. Тот, к
которому стоит обращаться чаще всего — **drawtonomy.svg** — обычный
SVG с дополнительными метаданными, поэтому файл можно открыть снова
и продолжить с того места, где остановились. Это также валидный SVG,
поэтому он корректно отображается в браузерах, презентациях и
документационных пайплайнах без преобразования.

Остальные форматы — PNG, JPG, SVG (плоский), PDF, EPS — для случаев,
когда нужно статическое изображение и повторное редактирование не
требуется.

Для вывода в симулятор вождения (OpenDRIVE / OpenSCENARIO / Lanelet2)
см. отдельную страницу [ASAM-экспорт](/ru/guides/export-asam/).

## С чего начать: drawtonomy.svg

`drawtonomy.svg` сохраняет ID фигур, связи полос, общие точки,
группы footprint, стиль и отношения *какая фигура сверху*. Один и тот
же файл:

- **Повторно редактируемый.** Перетащите его обратно в drawtonomy, и
  сцена возвращается точно в том виде, в котором вы её оставили —
  каждая связь, общая точка и отношение перекрытия в целости.
- **Просматриваемый.** Это валидный SVG, поэтому GitHub, браузеры,
  рендереры Markdown и презентационные инструменты отображают его
  корректно без преобразования.
- **Дружественный к документам.** Векторный, чисто масштабируется,
  малый размер файла, без артефактов растеризации. Остаётся чётким
  при любом масштабе в README или иллюстрации к статье.

`drawtonomy.svg` — разумный вариант по умолчанию для всего, что
может быть отредактировано снова, отправлено коллеге с drawtonomy
или встроено в техническую документацию.

### Сохраните как drawtonomy.svg

1. Откройте меню (вверху слева).
2. Щёлкните **Export**.
3. Выберите **drawtonomy.svg**.

Файл скачивается с именем, основанным на названии сцены.

### Откройте снова

Перетащите файл обратно в drawtonomy или используйте **Import** в
том же меню. Вся сцена появляется в новой вкладке, и каждая фигура
выбираема. Панель атрибутов показывает раздел **OVERLAPPING OBJECTS**,
когда вы щёлкаете по области, где фигуры перекрываются — отношение
между, скажем, транспортом и полосой, на которой он стоит, переживает
обмен.

## Другие форматы изображений

Когда нужна только плоская картинка — без редактирования, без
метаданных — выберите один из этих в том же меню Export.

| Формат | Использовать для | Замечания |
|---|---|---|
| **PNG** | Слайды, документы, веб-страницы | Растровый без потерь. |
| **JPG** | Меньшие файлы, когда прозрачность не нужна | Растровый с потерями. |
| **SVG** (плоский) | Постобработка в Illustrator / Inkscape, веб-встраивание | Визуально идентично drawtonomy.svg, но метаданные удалены. |
| **PDF** | Печать, архив, статьи | Векторный, поддерживает прозрачность. |
| **EPS** | Устаревшие издательские пайплайны | Векторный. **Не поддерживает прозрачность** — см. ниже. |

### EPS и прозрачность

EPS не кодирует прозрачность. Фигура с непрозрачностью 60% будет
экспортирована с полной непрозрачностью. Если ваша сцена опирается
на прозрачность, экспортируйте PDF или SVG.
