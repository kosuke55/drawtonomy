drawtonomy поставляется с шаблонами для акторов и элементов
дорожного движения, нужных в сценариях вождения.

## Транспортные средства

1. Нажмите <kbd>P</kbd>, чтобы открыть **Participants**.
2. Выберите шаблон транспорта (Sedan, Bus, Truck, Motorcycle).
3. Щёлкните по холсту, чтобы разместить. Транспорт появляется в
   размере по умолчанию для шаблона.

Перетащите угловой маркер, чтобы изменить размер. Перетащите маркер
вращения, чтобы выровнять вдоль полосы.

## Пешеходы

В том же меню Participants выберите шаблон пешехода (Walking,
Simple).

## Светофоры

Меню Participants также включает сигналы для транспорта и пешеходов.
Размещайте их на углах перекрёстка. Это статичные фигуры; они не
проигрывают фазы сигнала.

## Пользовательские шаблоны

Можно добавлять собственные SVG-шаблоны и присылать их через PR. См.
[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).

## Заполнение траектории транспортом

Чтобы разместить ряд транспортных средств вдоль траектории (для
диаграмм дистанции или сцен следования за лидером), используйте
[Path Footprint](/ru/guides/path-footprint/).
