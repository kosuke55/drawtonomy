Когда две полосы делят граничную точку, перетаскивание этой точки
двигает обе полосы сразу. Панель атрибутов раскрывает четыре явных
слота связей, чтобы вы также могли подключить Next / Previous /
Left / Right вручную.

## Рисование связанных полос

Видео начинается с пустого холста с открытым инструментом Lane.
Первая полоса — одна изогнутая полоса:

![Одна изогнутая полоса](/img/frames/lane-connection-curve.png)

Затем вторая полоса начинается так, чтобы её начальная граница
оказалась на существующих граничных точках первой полосы. drawtonomy
привязывается к этим точкам и регистрирует новую полосу как
продолжение:

![Добавлена вторая полоса; обе теперь делят границу снизу](/img/frames/lane-connection-split.png)

Полосы теперь делят сегмент границы. Перетащите общую границу на
любой полосе, и обе двигаются вместе. Расходящийся верхний конец
независим с каждой стороны.

## Четыре слота связей

Нажмите <kbd>V</kbd> для Select, щёлкните любую полосу и посмотрите
правую панель. Слоты:

| Слот | Означает |
| --- | --- |
| **Next Lanes** | Полосы, в которые течёт трафик с этой полосы. |
| **Prev Lanes** | Полосы, которые втекают в эту полосу. |
| **Left Lane** | Полоса непосредственно слева, делящая границу. |
| **Right Lane** | Полоса непосредственно справа, делящая границу. |

У каждого слота две кнопки:

- **Create** — создать совершенно новую соседнюю полосу и направить
  слот на неё.
- **Set** — выбрать существующую полосу на холсте, чтобы заполнить
  слот.

Связи двунаправленные. Установка *Next Lanes* полосы A в B также
добавляет B в *Prev Lanes* полосы A; drawtonomy поддерживает
обратную ссылку автоматически.

## Когда связи устанавливаются автоматически

- Рисование новой полосы, начинающейся в существующей граничной
  точке полосы — случай в демо выше. Общей границы достаточно;
  щёлкать Set не нужно.
- Размещение [шаблона перекрёстка](/ru/reference/shapes/) — каждая
  подъездная полоса подключается.

Для всего остального щёлкните **Set** и выберите соседа.
