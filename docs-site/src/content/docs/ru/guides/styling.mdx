Каждая фигура несёт собственный стиль. Также можно изменить
значения по умолчанию для всего редактора, чтобы новые фигуры
начинались так, как вы хотите.

<Demo src="/videos/style-demo.mp4" caption="Цвет, прозрачность, ширина и вариант шаблона для каждой фигуры из панели атрибутов." />

## Стиль для каждой фигуры

1. Нажмите <kbd>V</kbd> для Select, затем щёлкните по фигуре.
2. **Панель атрибутов** справа раскрывает:
   - **Color** (палитра + кастомный)
   - **Opacity** (0–100%)
   - **Width** (для линейных фигур)
   - **Style** (сплошной / пунктир / вариант шаблона)

Множественный выбор, чтобы применить одно изменение к нескольким
фигурам сразу.

## Значения по умолчанию

Чтобы каждая новая полоса начиналась, скажем, с непрозрачностью 60%:

1. Откройте меню **гамбургер**.
2. Выберите **Defaults**.
3. Измените значение под **Lane**.

Значения по умолчанию вступают в силу для вновь создаваемых фигур.
Существующие фигуры не затрагиваются.

## Цветовая палитра

drawtonomy использует палитру в стиле Tailwind (от grey-100 до
grey-900, плюс цвета). Полный список см. в
[Справочнике по цветовой палитре](/ru/reference/color-palette/).
