drawtonomy может экспортировать вашу сцену как ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) и
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`) или собрать оба в ZIP, готовый к воспроизведению в
[esmini](https://github.com/esmini/esmini).

![Сцена drawtonomy, воспроизведённая в esmini после экспорта](/img/asam-esmini.png)

## Экспорт из редактора

1. Нарисуйте сцену (полосы, транспорт, светофоры…).
2. Откройте **File → Export → Export for esmini**.
3. Введите базовое имя по запросу.
4. Скачивается `<name>.zip`, содержащий `<name>.xodr` и
   `<name>.xosc`.

## Воспроизведение

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Отдельные форматы

Если нужен только один из двух:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## Программный экспорт

Экспортёр — часть `@drawtonomy/sdk` и работает без редактора.
Используйте его в CI-пайплайнах, серверной оснастке или
браузерных расширениях:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Полный API и точки расширения см. в
[справочнике Exporter SDK](/ru/extend/exporter-sdk/).
