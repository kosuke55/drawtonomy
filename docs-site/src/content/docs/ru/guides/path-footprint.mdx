*Footprint* (след) — это копия транспортного средства (или другого
шаблона), автоматически размещаемая вдоль Path. Демо начинается с
одного эго-транспорта, рисует Path от него, и траектория сразу
заполняется копиями этого транспорта — тот же шаблон, ориентация
вдоль кривой, равные интервалы.

<Demo src="/videos/footprints-demo.mp4" caption="Эго-транспорт, Path, нарисованная от него, и получившаяся цепочка следов." />

## Подготовка

Разместите транспорт где-нибудь на холсте инструментом Vehicle, затем
нажмите <kbd>H</kbd> для инструмента Path. Правая панель показывает
настройки Path:

![Панель инструмента Path — Color, Opacity 90%, Style Solid, Width 5px, Arrow Head 20px, Smooth включён](/img/frames/footprints-path-panel.png)

Показанные значения по умолчанию — сплошной зелёный, ширина 5 px,
сглаживание, со стрелкой 20 px — это то, что использует демо.

## Рисование траектории

Щёлкните по транспорту, чтобы начать траекторию. Первая точка
прицепляется к якорю транспорта. Щёлкайте дальше, чтобы продолжить
траекторию; стрелка появляется на последней поставленной точке.
Нажмите <kbd>Enter</kbd>, чтобы завершить.

Как только траектория готова, drawtonomy раскладывает копии
исходного транспорта вдоль неё:

![Path нарисована; следы транспорта появляются вдоль с равными интервалами](/img/frames/footprints-along-path.png)

Каждая копия повёрнута, чтобы соответствовать касательной к траектории
в её позиции, поэтому цепочка естественно следует за поворотами.

## Стиль и шаблон остаются связанными

Следы делят стиль с исходным транспортом: измените цвет,
прозрачность или шаблон источника, и каждый след последует. Не нужно
вручную редактировать каждую копию, чтобы держать диаграмму манёвра
визуально согласованной.

Следующий кадр демо скрывает саму траекторию, оставляя только
следы — полезно для экспортных кадров, когда вы не хотите, чтобы
базовая траектория загромождала диаграмму:

![Только следы, без нарисованной траектории](/img/frames/footprints-result.png)

## Что можно настроить

- **Spacing** — расстояние между следами.
- **Anchor offset** — сдвиньте опорную точку вдоль направления
  движения (например, base link или передний бампер вместо центра).
- **Smooth** — флажок в панели Path делает саму траекторию плавно
  изогнутой между точками; ориентация следов следует.
- **Color / Opacity / Size** — применяются ко всем следам сразу
  через исходный транспорт.
