Нажмите <kbd>N</kbd> для инструмента **Lane**. Справа открывается
панель и остаётся видимой, пока инструмент активен. В верхней части
панели — переключатель **CREATION MODE**:

![Панель Lane — CREATION MODE имеет кнопки Center Line и Boundary; выбран Center Line; Lane Width 50 px](/img/frames/lane-tool-panel.png)

Два режима делают разные вещи; выбирайте тот, который подходит вашей
ситуации.

<Demo src="/videos/lane-tool-demo.mp4" caption="Две полосы, нарисованные в режиме Center Line, и третья, вставленная в режиме Boundary." />

## Режим Center Line

Вы рисуете центральную линию; drawtonomy генерирует левую и правую
границы из значения **Lane Width**. Используйте, когда начинаете с
нуля.

1. Щёлкните по холсту, чтобы поставить первую точку центральной
   линии.
2. Щёлкните ещё раз для следующей и так далее.
3. Нажмите <kbd>Enter</kbd> (или дважды щёлкните по последней
   точке), чтобы завершить.

Инструмент Lane остаётся активным, поэтому щёлкайте в другом месте,
чтобы начать новую полосу. Две полосы, нарисованные таким способом:

![Две полосы, нарисованные по центральным линиям](/img/frames/lane-tool-two-lanes.png)

Можно менять Color, Opacity или Lane Width в панели между полосами —
новое значение применяется к следующей полосе, а не к выбранной.

## Режим Boundary

Щёлкните **Boundary** в верхней части панели, чтобы переключить
режимы. В режиме Boundary вы не щёлкаете по пустому пространству;
вы щёлкаете по двум существующим линиям-границам, и drawtonomy
делает полосу, использующую их как левую и правую границы.

Наведите на линию — drawtonomy подсвечивает её индиго, когда курсор
достаточно близко — и щёлкните:

![Режим Boundary — существующая правая граница подсвечена и готова к выбору](/img/frames/lane-tool-boundary-mode.png)

Щёлкните вторую линию, и между ними появится новая полоса. Новая
полоса делит обе границы со всем, что их использует, поэтому
перемещение точки границы обновляет каждую полосу, которая от неё
зависит.

Используйте режим Boundary, когда у вас уже есть геометрия
(нарисованная вручную, импортированная из Lanelet2 или сгенерированная
Lane Generator), и вы хотите вписать полосы между ней.

## Изучение полосы

Нажмите <kbd>V</kbd> для Select, затем щёлкните полосу. Панель
переключается на атрибуты полосы:

![Панель атрибутов Lane — Lane ID, общие ID границ, Direction, четыре слота связей](/img/frames/lane-attributes.png)

Что показано:

- **Lane ID** и ID **Left Boundary** / **Right Boundary** линий
  (например, `way/1`, `way/2`). Две полосы, делящие линию,
  отображают здесь один и тот же ID.
- **Lane Color**, **Lane Opacity**, **Direction (Reverse)** —
  визуальные и топологические настройки самой полосы.
- **Next Lanes / Prev Lanes / Left Lane / Right Lane** — четыре
  слота связей, каждый с **Create** (создать новую соседнюю полосу)
  и **Set** (указать на существующую). См.
  [Управление связями полос](/ru/guides/lane-connections/).
