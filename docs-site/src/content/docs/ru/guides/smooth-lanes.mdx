drawtonomy может генерировать аппроксимированные сплайнами границы
полос вместо угловатых ломаных. Переключатель находится в панели
создания Lane и применяется к полосам, которые вы рисуете далее; он
не сглаживает существующую полосу задним числом.

<Demo src="/videos/smooth-lane.mp4" caption="Полоса, нарисованная с Smooth Boundary off (слева, угловатая) и on (справа, плавная)." />

## Где находится переключатель

Нажмите <kbd>N</kbd> для инструмента Lane. Правая панель содержит
строку **SMOOTH BOUNDARY** с кнопками **On** и **Off**:

![Панель создания Lane — переключатель SMOOTH BOUNDARY подсвечен, в данный момент Off](/img/frames/smooth-toggle-off.png)

По умолчанию **Off**. Переключите на On, прежде чем начать щёлкать
центральную линию.

## Сравнение

Два скриншота ниже нарисованы с одной и той же центральной линией.
Изменился только переключатель:

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![Угловатая кривая, нарисованная с выключенным сглаживанием](/img/frames/smooth-off-result.png) | ![Плавная кривая, нарисованная с включённым сглаживанием](/img/frames/smooth-on-result.png) |

С выключенным переключателем каждая пара щелчков центральной линии
становится прямым отрезком границы. С включённым та же центральная
линия аппроксимируется кривой.

## Переключение в процессе сессии

Можете щёлкать переключатель когда угодно. Новые полосы подхватывают
текущее значение в следующий раз, когда вы щёлкаете. Существующие
полосы сохраняют тот стиль границ, с которым были нарисованы.
