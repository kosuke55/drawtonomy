*Общая точка* — это одна вершина, на которую ссылаются несколько
фигур. Передвиньте её один раз, и каждая фигура, которая на неё
ссылается, последует. Используйте, чтобы держать соседние границы
полос, углы полигонов и стыки траекторий зафиксированными вместе.

<Demo src="/videos/share-demo.mp4" caption="Удерживайте Alt + щелчок, чтобы разделить существующую точку с новой фигурой." />

## Создайте общую точку при рисовании

1. Выберите инструмент Linestring (<kbd>L</kbd>), Polygon
   (<kbd>G</kbd>) или Path (<kbd>H</kbd>).
2. Удерживайте <kbd>Alt</kbd> (Option на macOS).
3. Щёлкните существующую вершину другой фигуры.

Новая фигура получает вершину, *общую* с существующей — а не просто
привязанную к тем же координатам.

## Превратите существующую вершину в общую

1. Дважды щёлкните по фигуре, чтобы войти в
   [редактирование сегментов](/ru/guides/segment-editing/).
2. Удерживайте <kbd>Alt</kbd> и перетащите вершину на существующую.

## Визуальная подсказка

Общие точки рендерятся как удвоенный маркер в режиме редактирования
сегментов. Просто привязанные точки рендерятся как одиночный маркер.
