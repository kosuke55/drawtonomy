## 도구 전환

| 키  | 도구                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (패닝)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## 편집 작업

| 키 | 기능 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | 실행 취소 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 다시 실행 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | 복사 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | 붙여넣기 |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | 잘라내기 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 선택된 도형 삭제 |

## 그리는 도중의 보조 키

| 보조 키 | 효과 |
|---|---|
| <kbd>Shift</kbd> | 일시적으로 [스냅](/ko/guides/snap/) 비활성화 |
| <kbd>Alt</kbd> + 클릭 | [기존 점 공유](/ko/guides/point-sharing/) (Linestring / Polygon / Path) |
| 더블클릭 | [세그먼트 편집](/ko/guides/segment-editing/) 진입 (Linestring / Lane / Polygon) |

## 이동

| 키 | 효과 |
|---|---|
| 화살표 키 | 선택을 1 px 이동 |
| <kbd>Shift</kbd> + 화살표 | 선택을 10 px 이동 |
