튜토리얼은 짧고 실습 위주의 학습 자료입니다. 각 튜토리얼은 하나의 작업을 처음부터 끝까지 다루므로, 따라 하면서 에디터에 익숙해질 수 있습니다.

이미 무엇을 하려는지 알고 있고 단계만 필요하다면, [How-to 가이드](/ko/guides/)가 더 적합합니다.

## 학습 목록

- [빠른 시작](/ko/start/quickstart/) — 5분 안에 첫 차선과 차량을 그려 봅니다.
- [첫 세 개의 차선 그리기](/ko/tutorials/your-first-lanes/) — Lane 도구의 두 가지 생성 모드(중앙선, 경계).
- [부드러운 차선 경계](/ko/tutorials/smooth-lanes/) — 곡선을 그리기 전에 Smooth Boundary 켜기.
- [지도에서 실제 도로를 따라 그리기](/ko/tutorials/road-from-map/) — 위성 이미지 위에 도로를 따라 그리며, 단축키로 사용할 수 있는 원클릭 생성기도 함께 다룹니다.
- [AI로 장면을 생성한 뒤 직접 다듬기](/ko/tutorials/ai-scene/) — 자연어로 시나리오를 설명하고 결과를 편집해 보세요.
