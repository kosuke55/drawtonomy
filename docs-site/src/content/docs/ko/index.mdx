## drawtonomy란?

drawtonomy는 **자율주행 시나리오를 위한 화이트보드**입니다 — 논문에 들어가는 그림, 설계 리뷰 전에 그리는 슬라이드, 팀원에게 코너 케이스를 설명하기 위해 회의 중에 그리는 다이어그램, OpenSCENARIO 파일을 작성하기 전에 미리 스케치하는 장면 등을 위한 도구입니다.

URL을 열고 무한 캔버스에 차선과 교차로를 그리고, 차량·보행자·신호등·횡단보도·노면 표시를 배치한 뒤 저장하거나 내보내면 됩니다. 설치할 것도, 계정도, 업로드되는 파일도 없습니다.

이 도구가 존재하는 이유는 단순합니다. 일반적인 그림 도구나 슬라이드 도구는 차선이 무엇인지 알지 못하기 때문에, 무언가가 움직일 때마다 도로 형상을 다시 만들어야 합니다. drawtonomy는 차선, 교차로 등 자율주행 시나리오 도메인의 어휘 자체를 기본 도형으로 다루므로, 반복 작업을 거치는 동안에도 그림이 정확하게 유지됩니다.

## 사람들이 이런 용도로 사용합니다

	<Card title="논문과 학위 논문 그림" icon="document">

	</Card>
	<Card title="설계 토론용 다이어그램" icon="comment-alt">

	</Card>
	<Card title="시나리오 작성 전 스케치" icon="seti:graphql">

	</Card>

## 일반 그림 도구보다 빠른 이유

<CardGrid>
	<Card title="자율주행 도메인 도형" icon="seti:default">

	<Card title="토폴로지를 인식하는 차선" icon="seti:graphql">

	</Card>
	<Card title="무한 캔버스, 위성 이미지 배경" icon="seti:html">
		임의로 큰 레이아웃을 자유롭게 패닝·줌할 수 있습니다. 위성 또는 도로 지도 배경을 깔고 실제 위치를 따라 그릴 수 있습니다. 스냅과 공유 점 기능이 형상을 정렬해 주므로 수동 보정이 필요 없습니다.
	</Card>
	<Card title="무료, 브라우저 전용" icon="rocket">
		설치, 계정, 업로드가 모두 없습니다. 저장한 drawtonomy.svg를 나중에 다시 열면 모든 연결과 겹침 관계까지 그대로 복원됩니다.
	</Card>
</CardGrid>

## 시뮬레이션·매핑 워크플로우와 연결

화이트보드 자체가 핵심이고, 아래 항목들은 그려진 다이어그램이 이후 워크플로우로 흘러가는 방식을 보여 줍니다.

<CardGrid>
	<Card title="논문·슬라이드용 재편집 가능 SVG" icon="document">
		`drawtonomy.svg`는 브라우저, GitHub, 슬라이드에서 그대로 미리보기되는 표준 SVG이며, 모든 연결을 유지한 채 drawtonomy에서 다시 열립니다. 문서와 연구 논문 그림의 기본 형식입니다.
	</Card>
	<Card title="Lanelet2 왕복" icon="seti:json">
		Autoware 샘플 지도를 포함한 Lanelet2 OSM 지도를 편집하기 위해 열고 다시 OSM으로 내보낼 수 있습니다. 기존 HD 맵에 변경 사항을 스케치할 때 유용합니다.
	</Card>
	<Card title="ASAM OpenDRIVE / OpenSCENARIO" icon="seti:db">
		OpenDRIVE 1.8과 OpenSCENARIO 1.3을 내보낼 수 있습니다 — 시뮬레이터에서 장면을 재생하고 싶다면 [esmini](https://github.com/esmini/esmini) 즉시 실행 가능 zip으로 함께 묶을 수 있습니다.
	</Card>
	<Card title="AI Scene Generator" icon="comment-alt">
		자연어로 시나리오를 설명하거나 OpenSCENARIO XML을 붙여넣으면 편집 가능한 캔버스를 받을 수 있습니다. 출력은 일반적인 drawtonomy 장면이므로, 다른 장면처럼 자유롭게 다듬을 수 있습니다.
	</Card>
</CardGrid>
