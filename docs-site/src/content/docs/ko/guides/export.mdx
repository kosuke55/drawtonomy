drawtonomy는 여러 내보내기 형식을 제공합니다. 대부분의 경우 가장 먼저 떠올려야 할 것은 **drawtonomy.svg**입니다 — 추가 메타데이터를 포함한 일반 SVG로, 파일을 다시 열어 작업을 이어갈 수 있습니다. 동시에 유효한 SVG이므로 변환 없이 브라우저, 슬라이드, 문서 파이프라인에서 올바르게 미리보기됩니다.

다른 형식 — PNG, JPG, SVG(일반), PDF, EPS — 은 정적 이미지가 필요하고 다시 편집할 필요가 없을 때를 위한 것입니다.

자율주행 시뮬레이터 출력(OpenDRIVE / OpenSCENARIO / Lanelet2)은 [ASAM 내보내기](/ko/guides/export-asam/) 페이지를 참고하세요.

## 어디서 시작할까: drawtonomy.svg

`drawtonomy.svg`는 도형 ID, 차선 연결, 공유 점, 풋프린트 그룹, 스타일, 그리고 *어떤 도형이 위에 있는지* 관계까지 보존합니다. 같은 파일이:

- **다시 편집 가능합니다.** drawtonomy로 다시 드래그하면 모든 연결, 공유 점, 겹침 관계가 그대로 살아 있는 채 정확히 그 상태로 복원됩니다.
- **미리보기가 가능합니다.** 유효한 SVG이므로 GitHub, 브라우저, Markdown 렌더러, 슬라이드 도구에서 변환 없이 올바르게 표시됩니다.
- **문서 친화적입니다.** 벡터, 깔끔한 스케일링, 작은 파일 크기, 래스터화 아티팩트 없음. README나 논문 그림 안에서 어떤 줌에서도 선명하게 유지됩니다.

`drawtonomy.svg`는 다시 편집할 가능성이 있거나, drawtonomy를 가진 팀원과 공유하거나, 기술 문서에 삽입할 모든 자료의 합리적인 기본값입니다.

### drawtonomy.svg로 저장

1. (좌측 상단) 메뉴를 엽니다.
2. **Export**를 클릭합니다.
3. **drawtonomy.svg**를 선택합니다.

장면 제목을 기반으로 한 이름으로 파일이 다운로드됩니다.

### 다시 열기

파일을 drawtonomy로 다시 드래그하거나, 같은 메뉴의 **Import**를 사용하세요. 모든 도형이 선택 가능한 상태로 새 탭에 장면이 나타납니다. 도형이 겹치는 영역을 클릭하면 Attribute Panel에 **OVERLAPPING OBJECTS** 섹션이 나타나는데, 이는 예를 들어 차량과 그 차량이 놓인 차선의 관계가 왕복 변환에도 살아남는다는 뜻입니다.

## 다른 이미지 형식

편집이나 메타데이터 없이 단순한 이미지만 필요하다면 같은 Export 메뉴에서 다음 중 하나를 선택하세요.

| 형식 | 사용처 | 비고 |
|---|---|---|
| **PNG** | 슬라이드, 문서, 웹 페이지 | 무손실 래스터. |
| **JPG** | 투명도가 필요 없을 때 더 작은 파일 | 손실 래스터. |
| **SVG**(일반) | Illustrator/Inkscape 후처리, 웹 임베드 | drawtonomy.svg와 시각적으로 동일하지만 메타데이터가 제거됨. |
| **PDF** | 인쇄, 보관, 논문 | 벡터, 투명도 지원. |
| **EPS** | 레거시 출판 워크플로우 | 벡터. **투명도 지원 안 함** — 아래 설명 참고. |

### EPS와 투명도

EPS는 투명도를 인코딩하지 않습니다. 투명도 60%인 도형은 완전 불투명으로 내보내집니다. 장면이 투명도에 의존한다면 PDF 또는 SVG로 내보내세요.
