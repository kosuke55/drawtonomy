모든 도형은 자신만의 스타일을 가집니다. 또한 에디터 전체의 기본값을 변경해 새 도형이 원하는 모습으로 시작하도록 설정할 수도 있습니다.

<Demo src="/videos/style-demo.mp4" caption="Attribute Panel에서 도형별 색상, 투명도, 너비, 템플릿 변형 변경." />

## 도형별 스타일

1. <kbd>V</kbd>를 눌러 Select로 전환한 뒤 도형을 클릭합니다.
2. 오른쪽 **Attribute Panel**에 다음이 표시됩니다.
   - **Color** (팔레트 + 사용자 정의)
   - **Opacity** (0–100%)
   - **Width** (선 형태의 도형용)
   - **Style** (solid / dashed / 템플릿 변형)

다중 선택하면 같은 변경을 여러 도형에 한 번에 적용할 수 있습니다.

## 기본값

새 차선이 항상 60% 투명도로 시작하도록 만들고 싶다면:

1. **햄버거** 메뉴를 엽니다.
2. **Defaults**를 선택합니다.
3. **Lane** 항목 아래의 값을 변경합니다.

기본값은 새로 생성되는 도형에 적용됩니다. 기존 도형은 변경되지 않습니다.

## 색상 팔레트

drawtonomy는 Tailwind 스타일의 팔레트(grey-100~grey-900과 명명된 색상)를 사용합니다. 전체 목록은 [색상 팔레트 레퍼런스](/ko/reference/color-palette/)를 참고하세요.
