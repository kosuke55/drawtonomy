Lane Generator는 OpenStreetMap에서 실제 도로 형상을 가져와 지도 배경에 정렬된 편집 가능한 Lane 도형으로 변환합니다.

<Demo src="/videos/map-to-lane-demo.mp4" caption="도로를 클릭하면 차선 하나, 영역을 드래그하면 여러 개." maxWidth="900px" />

## 지도 배경 켜기

1. 캔버스 좌측 상단의 **Background** 메뉴를 엽니다.
2. **Satellite**(사진) 또는 **Roadmap**(도식)을 선택합니다.
3. 원하는 영역으로 패닝하고 줌합니다.

지도가 캔버스 뒤에 렌더링되며 그리기 작업 중에도 고정 상태로 유지됩니다.

## 차선 하나만 생성하기

1. <kbd>N</kbd>을 눌러 Lane 도구를 활성화합니다.
2. 툴바에서 **Generator** 모드를 켭니다.
3. 도로 위로 마우스를 올리면 drawtonomy가 커서 아래의 매칭된 OSM 도로 구간을 강조합니다.
4. 클릭합니다. 해당 구간이 가져와져 Lane 도형으로 변환됩니다.

## 영역 안의 모든 도로 생성하기

Generator 모드가 켜진 상태에서:

1. 캡처할 영역에 사각형을 드래그합니다.
2. 마우스를 놓으면 사각형 안의 모든 도로가 한 번에 Lane이 됩니다.

전체 교차로, 동네, 테스트 사이트에 유용합니다.

## 권장 한도

OSM 가져오기와 변환은 브라우저에서 실행됩니다. 빠른 편집을 위해 결과 장면을 약 **500개 이하의 차선**으로 유지하고, 더 큰 영역이 필요하다면 여러 파일로 나누세요.

## 생성 이후

생성된 차선은 일반적인 Lane 도형입니다. 다음을 할 수 있습니다.

- 점을 드래그해 형상 다듬기.
- [부드럽게 만들기](/ko/guides/smooth-lanes/)를 적용해 빽빽한 폴리라인을 스플라인으로 교체.
- 생성기가 자동으로 추론하지 못한 [연결](/ko/guides/lane-connections/) 설정.
- 위에 차량, 보행자, 경로 배치.
