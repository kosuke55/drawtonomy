drawtonomy는 차선 경계를 각진 폴리라인이 아니라 스플라인으로 피팅해 생성할 수 있습니다. 이 토글은 Lane 생성 패널에 있고, 다음에 그릴 차선에 적용됩니다. 기존 차선의 경계를 사후에 부드럽게 바꾸지는 않습니다.

<Demo src="/videos/smooth-lane.mp4" caption="Smooth Boundary 끔(왼쪽, 각짐)과 켬(오른쪽, 부드러움)으로 그린 차선." />

## 토글의 위치

<kbd>N</kbd>을 눌러 Lane 도구를 활성화합니다. 오른쪽 패널에 **On**과 **Off** 버튼이 있는 **SMOOTH BOUNDARY** 행이 포함되어 있습니다.

![Lane 생성 패널 — SMOOTH BOUNDARY 토글이 강조되어 있고 현재 Off](/img/frames/smooth-toggle-off.png)

기본값은 **Off**입니다. 중앙선을 클릭하기 전에 켜세요.

## 비교

아래 두 스크린샷은 같은 중앙선으로 그린 결과입니다. 토글 값만 달라졌습니다.

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![Smoothing 끄고 그린 각진 곡선](/img/frames/smooth-off-result.png) | ![Smoothing 켜고 그린 부드러운 곡선](/img/frames/smooth-on-result.png) |

토글이 꺼져 있으면 인접한 두 중앙선 클릭이 직선 경계 구간이 됩니다. 켜져 있으면 같은 중앙선이 곡선으로 피팅됩니다.

## 작업 중에 전환하기

토글은 언제든 전환할 수 있습니다. 새 차선은 다음 클릭 시점의 토글 값을 가지고 만들어집니다. 기존 차선은 만들 때의 경계 스타일을 그대로 유지합니다.
