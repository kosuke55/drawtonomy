## Sürüş senaryosu şekilleri

| Şekil | Amaç |
|---|---|
| **Linestring** | Şerit sınırları, kaldırımlar, işaretlemeler için kullanılan sürekli çizgi. |
| **Şerit (Lane)** | İki sınır, bir merkez çizgi ve bağlantı yuvalarına (Sonraki / Önceki / Sol / Sağ) sahip sürülebilir bir şerit. |
| **Araç (Vehicle)** | Şablonlu araç (Sedan, Bus, Truck, Motorcycle). |
| **Yaya (Pedestrian)** | Şablonlu yaya (Walking, Simple). |
| **Yol (Path)** | Oklar, ayak izi grupları veya senaryo yolları için kullanılan yörünge. Ok veya bant stili. |
| **Polygon** | Kapalı alan (otopark, taralı bölge). |
| **Yaya Geçidi (Crosswalk)** | Önceden stilize edilmiş yaya geçişi. |
| **Trafik Işığı (TrafficLight)** | Araç veya yaya sinyali. |
| **Kavşak (Intersection)** | Çok şeritli kavşak şablonu. |

## Temel şekiller

| Şekil | Amaç |
|---|---|
| **LineArrow** | Tek segmentli ok. |
| **Arrow** | Serbest formlu ok. |
| **Text** | Düz veya açıklamalı metin. |
| **Freehand** | Kalem benzeri bir vuruşla çizilmiş. |
| **Rectangle** | Eksene hizalanmış dikdörtgen. |
| **Ellipse** | Eksene hizalanmış elips. |
| **Image** | İçe aktarılan PNG / JPG / SVG. |
