## Araç değiştirme

| Tuş  | Araç                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | El (kaydırma)              |
| <kbd>V</kbd>    | Seçim                      |
| <kbd>L</kbd>    | Linestring                 |
| <kbd>N</kbd>    | Şerit                      |
| <kbd>P</kbd>    | Katılımcılar (Araç / Yaya) |
| <kbd>H</kbd>    | Yol                        |
| <kbd>G</kbd>    | Polygon                    |
| <kbd>X</kbd>    | Yaya Geçidi                |
| <kbd>I</kbd>    | Kavşak                     |
| <kbd>W</kbd>    | LineArrow                  |
| <kbd>T</kbd>    | Metin                      |
| <kbd>D</kbd>    | Serbest çizim              |

## Düzenleme işlemleri

| Tuşlar | İşlev |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Geri Al |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Yinele |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Kopyala |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Yapıştır |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Kes |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Seçili şekilleri sil |

## Çizim sırasında değiştiriciler

| Değiştirici | Etki |
|---|---|
| <kbd>Shift</kbd> | [Snap](/tr/guides/snap/)'i geçici olarak devre dışı bırak |
| <kbd>Alt</kbd> + tıklama | [Mevcut bir noktayı paylaş](/tr/guides/point-sharing/) (Linestring / Polygon / Path) |
| Çift tıklama | [Segment düzenleme](/tr/guides/segment-editing/)'ye gir (Linestring / Şerit / Polygon) |

## Hareket

| Tuşlar | Etki |
|---|---|
| Ok tuşları | Seçimi 1 px hareket ettir |
| <kbd>Shift</kbd> + ok | Seçimi 10 px hareket ettir |
