drawtonomy, sahnenizi ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) ve
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`) olarak dışa aktarabilir veya her ikisini
[esmini](https://github.com/esmini/esmini) oynatması için hazır
bir zip olarak paketleyebilir.

![Dışa aktarımdan sonra esmini'de oynatılan bir drawtonomy sahnesi](/img/asam-esmini.png)

## Düzenleyiciden dışa aktarma

1. Sahnenizi çizin (şeritler, araçlar, trafik ışıkları…).
2. **Dosya → Dışa Aktar → esmini için dışa aktar**'ı açın.
3. İstendiğinde bir temel ad girin.
4. `<ad>.xodr` ve `<ad>.xosc` içeren bir `<ad>.zip` indirilir.

## Oynatma

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Bireysel formatlar

İkisinden yalnızca birine ihtiyacınız varsa:

- **Dosya → Dışa Aktar → OpenDRIVE (.xodr)**
- **Dosya → Dışa Aktar → OpenSCENARIO (.xosc)**

## Programatik dışa aktarma

Dışa aktarıcı `@drawtonomy/sdk`'nın bir parçasıdır ve düzenleyici
olmadan çalışır. Onu CI işlem hatlarında, sunucu tarafı araçlarda
veya tarayıcı uzantılarında kullanın:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Tam API ve uzantı noktaları için
[Dışa Aktarıcı SDK referansı](/tr/extend/exporter-sdk/) sayfasına
bakın.
