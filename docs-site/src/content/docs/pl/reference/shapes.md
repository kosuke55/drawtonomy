## Kształty scenariusza jazdy

| Kształt | Cel |
|---|---|
| **Łamana** | Ciągła linia, używana do granic pasów, krawężników, oznaczeń. |
| **Pas** | Pas jezdny z dwoma granicami, osią i slotami połączeń (Następny / Poprzedni / Lewy / Prawy). |
| **Pojazd** | Pojazd z szablonu (Sedan, Autobus, Ciężarówka, Motocykl). |
| **Pieszy** | Pieszy z szablonu (Idący, Prosty). |
| **Trasa** | Trajektoria używana do strzałek, grup śladów lub tras scenariuszy. Styl strzałki lub pasma. |
| **Wielokąt** | Zamknięty obszar (parking, strefa zakreskowana). |
| **Przejście dla pieszych** | Wstępnie ostylowane przejście dla pieszych. |
| **Sygnalizacja** | Sygnalizator pojazdowy lub pieszy. |
| **Skrzyżowanie** | Szablon węzła wielopasmowego. |

## Kształty podstawowe

| Kształt | Cel |
|---|---|
| **Strzałka liniowa** | Strzałka jednosegmentowa. |
| **Strzałka** | Strzałka dowolnokształtna. |
| **Tekst** | Zwykły lub adnotowany tekst. |
| **Odręczny** | Narysowany pociągnięciem podobnym do pióra. |
| **Prostokąt** | Prostokąt wyrównany do osi. |
| **Elipsa** | Elipsa wyrównana do osi. |
| **Obraz** | Zaimportowany PNG / JPG / SVG. |

## Niestandardowe szablony

Możesz dodać szablony SVG dla pojazdów, pieszych, oznakowania
poziomego i znaków. Przepływ wnoszenia znajduje się w
[Przewodniku Szablonów](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
