## Przełączanie narzędzi

| Klawisz  | Narzędzie                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Ręka (przesuwanie)                |
| <kbd>V</kbd>    | Wybierz                    |
| <kbd>L</kbd>    | Łamana                |
| <kbd>N</kbd>    | Pas                      |
| <kbd>P</kbd>    | Uczestnicy (Pojazd / Pieszy) |
| <kbd>H</kbd>    | Trasa                      |
| <kbd>G</kbd>    | Wielokąt                   |
| <kbd>X</kbd>    | Przejście dla pieszych                 |
| <kbd>I</kbd>    | Skrzyżowanie              |
| <kbd>W</kbd>    | Strzałka liniowa                 |
| <kbd>T</kbd>    | Tekst                      |
| <kbd>D</kbd>    | Odręczny                  |

## Operacje edycji

| Klawisze | Funkcja |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Cofnij |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ponów |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Kopiuj |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Wklej |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Wytnij |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Usuń wybrane kształty |

## Modyfikatory podczas rysowania

| Modyfikator | Efekt |
|---|---|
| <kbd>Shift</kbd> | Tymczasowo wyłącz [przyciąganie](/pl/guides/snap/) |
| <kbd>Alt</kbd> + kliknięcie | [Współdziel istniejący punkt](/pl/guides/point-sharing/) (Łamana / Wielokąt / Trasa) |
| Kliknij dwukrotnie | Wejdź w [edycję segmentów](/pl/guides/segment-editing/) (Łamana / Pas / Wielokąt) |

## Ruch

| Klawisze | Efekt |
|---|---|
| Strzałki | Przesuń wybór o 1 px |
| <kbd>Shift</kbd> + strzałka | Przesuń wybór o 10 px |
