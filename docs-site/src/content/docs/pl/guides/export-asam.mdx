drawtonomy może eksportować scenę jako ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) i
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`) lub spakować oba jako zip gotowy do odtwarzania w
[esmini](https://github.com/esmini/esmini).

![Scena drawtonomy odtwarzana w esmini po eksporcie](/img/asam-esmini.png)

## Eksport z edytora

1. Narysuj scenę (pasy, pojazdy, sygnalizacja świetlna…).
2. Otwórz **Plik → Eksport → Eksport dla esmini**.
3. Wprowadź nazwę bazową, gdy zostaniesz o nią zapytany.
4. Pobiera się `<nazwa>.zip` zawierający `<nazwa>.xodr` i
   `<nazwa>.xosc`.

## Odtwórz

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Pojedyncze formaty

Jeśli potrzebujesz tylko jednego z dwóch:

- **Plik → Eksport → OpenDRIVE (.xodr)**
- **Plik → Eksport → OpenSCENARIO (.xosc)**

## Eksport programistyczny

Eksporter jest częścią `@drawtonomy/sdk` i działa bez edytora. Użyj go
w potokach CI, narzędziach po stronie serwera lub rozszerzeniach
przeglądarki:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Pełne API i punkty rozszerzenia znajdują się w
[materiałach referencyjnych Exporter SDK](/pl/extend/exporter-sdk/).
