Elke vorm heeft zijn eigen stijl. U kunt ook de editor-brede
standaardwaarden wijzigen zodat nieuwe vormen op de gewenste
manier beginnen.

<Demo src="/videos/style-demo.mp4" caption="Per-vorm kleur, opaciteit, breedte en sjabloonvariant via het Attribuutpaneel." />

## Stijl per vorm

1. Druk op <kbd>V</kbd> voor Select en klik op een vorm.
2. Het **Attribuutpaneel** rechts toont:
   - **Color** (palet + aangepast)
   - **Opacity** (0–100%)
   - **Width** (voor lijnachtige vormen)
   - **Style** (solid / dashed / sjabloonvariant)

Multiselect om dezelfde wijziging op meerdere vormen tegelijk toe
te passen.

## Standaardwaarden

Om elke nieuwe rijstrook bijvoorbeeld op 60% opaciteit te laten
beginnen:

1. Open het **hamburger**-menu.
2. Kies **Defaults**.
3. Wijzig de waarde onder **Lane**.

Standaardwaarden gelden voor nieuw gemaakte vormen. Bestaande
vormen worden niet aangepast.
