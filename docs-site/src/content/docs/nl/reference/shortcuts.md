## Tool wisselen

| Toets | Tool |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (pannen)                |
| <kbd>V</kbd>    | Selecteren                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Voertuig / Voetganger) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Bewerkbewerkingen

| Toetsen | Functie |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Ongedaan maken |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Opnieuw uitvoeren |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Kopiëren |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Plakken |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Knippen |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Geselecteerde vorm(en) verwijderen |

## Modifiers tijdens het tekenen

| Modifier | Effect |
|---|---|
| <kbd>Shift</kbd> | [Snap](/nl/guides/snap/) tijdelijk uitschakelen |
| <kbd>Alt</kbd> + klik | [Een bestaand punt delen](/nl/guides/point-sharing/) (Linestring / Polygon / Path) |
| Dubbelklik | [Segmentbewerking](/nl/guides/segment-editing/) openen (Linestring / Lane / Polygon) |

## Beweging

| Toetsen | Effect |
|---|---|
| Pijltoetsen | Selectie 1 px verplaatsen |
| <kbd>Shift</kbd> + pijl | Selectie 10 px verplaatsen |
