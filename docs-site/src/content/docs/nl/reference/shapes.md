## Rijscenariovormen

| Vorm | Doel |
|---|---|
| **Linestring** | Doorlopende lijn, gebruikt voor rijstrookgrenzen, stoepranden, markeringen. |
| **Lane** | Een berijdbare rijstrook met twee grenzen, een hartlijn en verbindingsvelden (Volgende / Vorige / Links / Rechts). |
| **Vehicle** | Voertuig op basis van sjabloon (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | Voetganger op basis van sjabloon (Walking, Simple). |
| **Path** | Traject voor pijlen, footprintgroepen of scenariopaden. Pijl- of bandstijl. |
| **Polygon** | Gesloten gebied (parkeerplaats, gearceerde zone). |
| **Crosswalk** | Vooraf opgemaakte voetgangersoversteekplaats. |
| **TrafficLight** | Voertuig- of voetgangerssignaal. |
| **Intersection** | Sjabloon voor kruispunt met meerdere rijstroken. |

## Basisvormen

| Vorm | Doel |
|---|---|
| **LineArrow** | Eensegments-pijl. |
| **Arrow** | Vrijevormpijl. |
| **Text** | Gewone of geannoteerde tekst. |
| **Freehand** | Getekend met een penachtige streek. |
| **Rectangle** | As-uitgelijnde rechthoek. |
| **Ellipse** | As-uitgelijnde ellips. |
| **Image** | Geïmporteerde PNG / JPG / SVG. |

## Aangepaste sjablonen

U kunt SVG-sjablonen toevoegen voor voertuigen, voetgangers,
wegmarkeringen en borden. De bijdrageprocedure staat in de
[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).
