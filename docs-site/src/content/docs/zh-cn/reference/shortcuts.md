## 工具切换

| 键  | 工具                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand(平移)                |
| <kbd>V</kbd>    | Select(选择)              |
| <kbd>L</kbd>    | Linestring(折线)          |
| <kbd>N</kbd>    | Lane(车道)                |
| <kbd>P</kbd>    | Participants(车辆 / 行人) |
| <kbd>H</kbd>    | Path(路径)                |
| <kbd>G</kbd>    | Polygon(多边形)           |
| <kbd>X</kbd>    | Crosswalk(人行横道)       |
| <kbd>I</kbd>    | Intersection(路口)        |
| <kbd>W</kbd>    | LineArrow(箭头线)         |
| <kbd>T</kbd>    | Text(文本)                |
| <kbd>D</kbd>    | Freehand(自由绘制)        |

## 编辑操作

| 按键 | 功能 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | 撤销 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 重做 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | 复制 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | 粘贴 |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | 剪切 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 删除选中图形 |

## 绘制时的修饰键

| 修饰键 | 效果 |
|---|---|
| <kbd>Shift</kbd> | 临时关闭 [自动吸附](/zh-cn/guides/snap/) |
| <kbd>Alt</kbd> + 点击 | [共享一个已有点](/zh-cn/guides/point-sharing/)(Linestring / Polygon / Path) |
| 双击 | 进入 [段编辑](/zh-cn/guides/segment-editing/)(Linestring / Lane / Polygon) |

## 移动

| 按键 | 效果 |
|---|---|
| 方向键 | 选区移动 1 px |
| <kbd>Shift</kbd> + 方向键 | 选区移动 10 px |
