吸附默认开启,在所有工具中都生效。光标靠近已有的点或边缘时,
drawtonomy 会自动锁定,并亮起一个靛蓝色指示器。

<Demo src="/videos/snap-demo.mp4" caption="先画一条 linestring 作为目标;第二条 linestring 吸附上去,然后是车辆和矩形依次吸附到目标特征。" />

## 跨图形类型生效

演示中三种不同工具都对同类目标进行了吸附。

### Linestring 吸附到 Linestring

从一条竖直 linestring 出发,第二条画到拐角刚好落在第一条的顶端。
得到的是一个共享同一点的直角——而不是仅在像素上重叠。

![两条 linestring,第二条吸附到第一条形成一个角](/img/frames/snap-linestring.png)

### 车辆吸附到车道

切换到车辆工具,把车放到车道上,车辆会吸附到车道中心线,
并按车道方向自动对齐。

![一辆车放在一条水平车道上,吸附到中心线](/img/frames/snap-vehicle.png)

### 矩形吸附到车辆 / 画布上的点

矩形工具也具备同样的吸附行为。虚线指示器表示拐角正在被拉向哪个目标。

![在车辆附近绘制矩形,虚线表示吸附目标](/img/frames/snap-rectangle.png)

## 临时关闭吸附

点击或拖动时按住 <kbd>Shift</kbd>,可对当前操作单次跳过吸附;
松开 <kbd>Shift</kbd> 后吸附恢复。

当你想要一个点靠近、但不完全落在某个已有目标上时,这种做法最合适。
