段编辑(segment editing)允许你在任意两个相邻顶点之间调整图形,
新增或删除一个顶点——不必从头重画图形。

<Demo src="/videos/segment-demo.mp4" caption="双击进入段编辑模式,然后拖动一个点,或在某段上点击来新增点。" />

## 进入段编辑模式

1. 按 <kbd>V</kbd> 切到选择工具。
2. 双击 Linestring、Lane 或 Polygon。
3. 图形进入点编辑模式:每个顶点都变成可拖动的靛蓝手柄。

## 移动一个点

点击并拖动顶点。如果该点与其他图形共享(参见
[共享点](/zh-cn/guides/point-sharing/)),所有持有它的图形都会一起移动。

对车道而言,拖动边界点会同时更新共享该边界的两条车道——
请见 [车道连接模型](/zh-cn/explanation/lane-model/)。

## 新增一个点

在某段(两个已有点之间的连线)上的任何位置点击,就会在点击位置
插入一个新顶点。

这是把直线段引入弯曲的最快方式:加一个点,然后拖动它。

## 移除一个点

选中顶点(它会变为实心靛蓝),按 <kbd>Delete</kbd> 或
<kbd>Backspace</kbd>。

## 退出段编辑

按 <kbd>Esc</kbd>、点击图形外部,或选择其他工具。
图形会回到普通选择模式。

## 另请参阅

- [让车道边界变平滑](/zh-cn/guides/smooth-lanes/) — 当你新增了大量点
  之后,可以用它来整理几何。
- [吸附到已有几何](/zh-cn/guides/snap/) — 把点拖到吸附目标上保持对齐。
