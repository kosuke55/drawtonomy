Lane Generator 会从 OpenStreetMap 拉取真实道路几何,
转换成与地图背景对齐的可编辑车道。

<Demo src="/videos/map-to-lane-demo.mp4" caption="点击道路转换单条;拖出区域批量转换其中所有道路。" maxWidth="900px" />

## 打开地图背景

1. 在画布左上角打开 **Background** 菜单。
2. 选择 **Satellite**(卫星照片)或 **Roadmap**(示意图)。
3. 平移并缩放到目标区域。

地图渲染在画布之下,绘制时会保持锚定不动。

## 生成单条车道

1. 按 <kbd>N</kbd> 切到车道工具。
2. 在工具栏中启用 **Generator** 模式。
3. 把鼠标移到一条道路上。drawtonomy 会高亮光标下匹配到的 OSM 路段。
4. 点击,这一段会被抓取并转换为一条车道。

## 批量生成区域内所有道路

启用 Generator 模式后:

1. 在目标区域上拖出一个矩形。
2. 松开鼠标,矩形内的所有道路会一次性变成车道。

适合整个路口、街区或测试场地。

## 推荐限制

OSM 抓取与转换都在浏览器中运行。为了流畅编辑,
建议生成后的场景控制在大约 **500 条车道**以内——
区域更大请拆分到多个文件。

## 生成之后

生成的车道是普通的 Lane 图形。你可以:

- 拖动顶点微调几何。
- 用 [让车道边界变平滑](/zh-cn/guides/smooth-lanes/) 把密集折线
  替换为样条曲线。
- 在生成器没有自动推断出连接的地方,手工
  [设置连接](/zh-cn/guides/lane-connections/)。
- 在上面放置车辆、行人或路径。
