每个图形都有自己的样式。你也可以修改全编辑器范围的默认值,
让新建图形按你想要的方式开始。

<Demo src="/videos/style-demo.mp4" caption="通过属性面板调整每个图形的颜色、不透明度、宽度和模板变体。" />

## 单图形样式

1. 按 <kbd>V</kbd> 切到选择工具,点击一个图形。
2. 右侧的 **属性面板** 会显示:
   - **Color(颜色)**(调色板 + 自定义)
   - **Opacity(不透明度)**(0–100%)
   - **Width(宽度)**(对线状图形)
   - **Style(样式)**(实线 / 虚线 / 模板变体)

多选图形可以一次性把同一变更应用到多个图形上。

## 默认值

如果想让每条新车道默认 60% 不透明度:

1. 打开 **汉堡** 菜单。
2. 选 **Defaults**。
3. 在 **Lane** 下面修改对应值。

默认值只影响新创建的图形,已有图形不会被改动。

## 调色板

drawtonomy 使用类似 Tailwind 的调色板(grey-100 到 grey-900,
另加几种命名颜色)。完整列表请见
[颜色调色板参考](/zh-cn/reference/color-palette/)。
