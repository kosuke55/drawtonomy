drawtonomy 可将场景导出为 ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`)与
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`),也可以打包成可直接在
[esmini](https://github.com/esmini/esmini) 中回放的 zip。

![一个 drawtonomy 场景导出后在 esmini 中回放](/img/asam-esmini.png)

## 在编辑器中导出

1. 画好场景(车道、车辆、信号灯……)。
2. 打开 **File → Export → Export for esmini**。
3. 当出现提示时输入一个基础名称。
4. 一个 `<name>.zip` 会被下载,其中包含 `<name>.xodr` 与
   `<name>.xosc`。

## 回放

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## 单独导出

如果只需要其中一种:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## 程序化导出

导出器是 `@drawtonomy/sdk` 的一部分,可以脱离编辑器运行。
适用于 CI 流水线、服务端工具,或浏览器扩展:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

完整 API 与扩展点请见
[导出器 SDK 参考](/zh-cn/extend/exporter-sdk/)。

## 输出版本

| 格式 | 版本 |
|---|---|
| OpenDRIVE | 1.8 |
| OpenSCENARIO | 1.3 |
