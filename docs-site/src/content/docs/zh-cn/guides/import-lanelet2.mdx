drawtonomy 能读取
[Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)
的 OSM 格式地图。示例地图可从
[Autoware 文档](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map)
获取。

<Demo src="/videos/lanelet-import-demo.mp4" caption="导入完整的 Lanelet2 文件。" />

## 导入整份文件

1. 打开 **File** 菜单 → **Import**。
2. 选择 `.osm` 文件。
3. drawtonomy 会解析文件,把车道和连接关系填充到画布上。

## 仅导入指定车道

地图较大时,导入所有车道会拖慢编辑器,可以使用车道选择对话框:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="拖拽选中你关心的车道,然后导入。" />

1. 打开 **File** 菜单 → **Import → Select lanes**。
2. drawtonomy 会显示一张预览地图。
3. 点击或拖拽选择需要导入的车道。
4. 点击 **Import selection**。

## 性能建议

为了让编辑器流畅,建议导入后的场景控制在大约 **500 条车道**以内。
区域更大时,可以拆分成多个文件,或者只导入需要的区域。

## 导入之后

导入的车道是完整保真的 Lane 图形,Lanelet2 文件中的连接关系都会保留。
你可以编辑、[让边界变平滑](/zh-cn/guides/smooth-lanes/),或
[导出回 Lanelet2](/zh-cn/guides/export-asam/),拓扑不会丢失。
