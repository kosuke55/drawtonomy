*共享点(Shared Point)* 是被多个图形共同引用的同一个顶点。
移动一次,所有引用它的图形都会跟着动。可以用它把相邻的车道边界、
多边形顶点和路径接头牢牢锁定在一起。

<Demo src="/videos/share-demo.mp4" caption="按住 Alt + 点击,把一个新图形与已有点共享。" />

## 绘制时创建共享点

1. 选 Linestring(<kbd>L</kbd>)、Polygon(<kbd>G</kbd>)
   或 Path(<kbd>H</kbd>)工具。
2. 按住 <kbd>Alt</kbd>(macOS 上为 Option)。
3. 点击另一图形上已有的某个顶点。

新图形上会出现一个与已有顶点*共享*的顶点——而不仅是吸附到相同坐标。

## 把已有顶点转为共享点

1. 双击一个图形进入 [段编辑](/zh-cn/guides/segment-editing/) 模式。
2. 按住 <kbd>Alt</kbd>,把一个顶点拖到另一个已有顶点上。

## 视觉提示

共享点在段编辑模式下显示为双层手柄;
普通的吸附点只显示单层手柄。
