[AI 场景生成器](https://github.com/kosuke55/drawtonomy/tree/main/extensions/ai-scene-generator)
扩展接受自然语言提示、OpenSCENARIO XML 或 DSL 输入,
并输出一张可编辑的画布。

<Demo src="/videos/ai-scene-natural.mp4" caption="自然语言场景 → 画布上的可编辑场景。" maxWidth="900px" />

## 1. 打开 AI 场景生成器

1. 点击画布右下角的 **Extensions(扩展)**。
2. 选择 **AI Scene Generator**。
3. 选好 AI 提供商(Anthropic Claude、OpenAI GPT 或 Google
   Gemini),粘贴你的 API key。Key 仅保存在你的浏览器中。

## 2. 描述场景

粘贴一段提示,例如:

> 一条由左向右延伸的三车道高速公路。一辆 ego 蓝色轿车位于
> 中间车道,一辆灰色卡车在右侧车道、稍微靠前。
> 显示一条虚线路径,表示 ego 车辆变道到左侧车道。

点击 **Generate**。扩展会在画布上布置好车道、车辆和一条
路径(Path)图形。

## 3. 微调

生成出来的所有内容都是普通图形。可以试试:

- 选中卡车,把它的模板换成 **Bus**。
- 拖动 ego 车的路径,改成另一条曲线。
- 在路肩上添加一名行人。

## 4. 或者从 OpenSCENARIO 开始

在同一面板中把输入模式切到 **OpenSCENARIO XML**,粘贴一份
`.xosc` 文件。扩展会在画布上布置好其中的 actors 与轨迹——
这是可视化已有场景最快的途径。

<Demo src="/videos/ai-scene-dsl.mp4" caption="一份 ASAM OpenSCENARIO DSL 示例被布置到画布上。" maxWidth="900px" />

## 你学到了什么

- AI 生成只是起点——之后画布上的每一个图形都可以像普通图形一样编辑。
- 同一面板既支持自然语言提示,也支持 OpenSCENARIO 输入,
  让你能在"模糊想法"和"正式规范"之间自由切换,而不必离开编辑器。

如果想了解效果较好的提示模式,请见
[AI Scene Generator README](https://github.com/kosuke55/drawtonomy/tree/main/extensions/ai-scene-generator)。
