教程是一组简短、动手做的课程。每节课都会带你从头到尾完成一个完整任务,
跟着做就能熟悉编辑器。

如果你已经知道想做什么、只缺步骤,
[操作指南](/zh-cn/guides/) 通常更合适。

## 课程列表

- [快速入门](/zh-cn/start/quickstart/) — 5 分钟画出第一条车道并放置车辆。
- [绘制你的前三条车道](/zh-cn/tutorials/your-first-lanes/) —
  车道工具的两种创建模式(中心线 Center Line 与边界 Boundary)。
- [让车道边界变平滑](/zh-cn/tutorials/smooth-lanes/) —
  绘制曲线之前打开 Smooth Boundary。
- [从地图重建一条真实道路](/zh-cn/tutorials/road-from-map/) —
  在卫星图背景上描出道路,顺便介绍一键生成器作为快捷方式。
- [用 AI 生成场景再手工微调](/zh-cn/tutorials/ai-scene/) —
  用自然语言描述场景,然后编辑生成结果。
