本课跟着官方"车道工具"演示走。完成时,你将体验过 drawtonomy
创建车道的两种方式:

- **中心线模式(Center Line)** — 画出中心线,左右边界自动生成。
- **边界模式(Boundary)** — 选择两条已有的边界折线,
  drawtonomy 会在它们之间嵌入一条车道。

演示先用中心线模式画两条车道,然后切换到边界模式,
插入第三条车道把缺口补上。

<Demo src="/videos/lane-tool-demo.mp4" caption="先用中心线模式画两条车道,再用边界模式从已有边界拼出第三条车道。" />

## 1. 选择车道工具

打开 [drawtonomy.com](https://drawtonomy.com)。按 <kbd>N</kbd>
(或点击底部工具栏的车道图标)。

屏幕右侧会出现 **车道(Lane)** 创建面板,
默认选中 **中心线(Center Line)**:

![车道面板 — 当前为中心线模式,车道宽度 50 px](/img/frames/lane-tool-panel.png)

暂时保持默认值即可。

## 2. 用中心线模式画两条车道

在中心线模式下,点击画布放下第一个中心线点;再次点击放下下一个;
按 <kbd>Enter</kbd> 结束。左右边界会按照 **车道宽度(Lane Width)**
(默认 50 px)自动生成。

每画完一条车道,车道工具仍然处于激活状态,所以可以再点击别处开始
第二条车道。在第一条车道右侧再点几下,按 <kbd>Enter</kbd>:

![两条独立车道并排画在中心线模式下](/img/frames/lane-tool-two-lanes.png)

此时这两条车道是相互独立的——没有共享的边界,也彼此不知道对方存在。

## 3. 切换到边界模式

在面板中点击 **边界(Boundary)**(就在 **中心线** 旁边)切换创建模式。
边界模式下不再点击空白处,而是点击**已有的边界折线**,
drawtonomy 会在它们之间放入一条新车道。

把鼠标移到 **左侧车道的右边界** 上——靠近时 drawtonomy 会用靛蓝色高亮
这条折线——然后点击:

![边界模式 — 左侧车道的右边界被高亮,准备被选中](/img/frames/lane-tool-boundary-mode.png)

接着点击 **右侧车道的左边界**。一条新车道就嵌入了缺口,
两次点击的折线分别成为它的左右边界。

## 4. 查看结果

按 <kbd>V</kbd> 切到选择工具,点击中间这条新车道。
右侧面板会切换到它的属性视图:

![属性面板 — 新中间车道与邻居共享 way/1 与 way/2 边界](/img/frames/lane-attributes.png)

边界已经被复用:

- **Lane ID** — `lane/2`,一条全新车道。
- **Left Boundary** — `way/1`,与左车道的右边界是同一条折线。
- **Right Boundary** — `way/2`,同样与右车道共享。

由于边界共享,拖动任意一侧的某个点,会让两条相邻车道一起移动。
这是 [车道连接](/zh-cn/explanation/lane-model/) 的基础;接下来读那篇文章
就能了解底层模型。

属性面板还会显示 **方向(Direction)**、**车道颜色(Lane Color)**、
**车道不透明度(Lane Opacity)**,以及 **Next Lanes / Prev Lanes /
Left Lane / Right Lane** 四个连接槽,本节暂时留空。

## 你学到了什么

- 车道有两种画法:从中心线开始,或选择两条已有的边界折线。
- 中心线模式适合从空白画布起步;边界模式不需要重画几何,
  就能在已有几何之间插入车道。
- 通过已有边界创建的车道,会自动与邻居共享这些边界。
