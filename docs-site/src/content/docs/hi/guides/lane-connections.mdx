video Lane टूल open के साथ एक खाली कैनवस से शुरू होता है।
पहली लेन एक single curving लेन है:

![एक single curving लेन](/img/frames/lane-connection-curve.png)

फिर एक दूसरी लेन शुरू की जाती है ताकि उसकी starting बाउंड्री
पहली लेन के मौजूदा बाउंड्री पॉइंट पर लैंड करे। drawtonomy उन
पॉइंट पर snap करता है और नई लेन को एक continuation के रूप में
register करता है:

लेन अब एक बाउंड्री segment साझा करती हैं। किसी भी लेन पर
साझा बाउंड्री खींचें और दोनों एक साथ हिलती हैं। डाइवर्जिंग
ऊपरी end हर तरफ स्वतंत्र है।

## चार कनेक्शन slots

Select के लिए <kbd>V</kbd> दबाएं, किसी भी लेन पर क्लिक करें,
और दायां पैनल देखें। Slots हैं:

| Slot | अर्थ |
| --- | --- |
| **Next Lanes** | वे लेन जिनमें इस लेन से ट्रैफिक flow करता है। |
| **Prev Lanes** | वे लेन जो इस लेन में flow करती हैं। |
| **Left Lane** | तुरंत बाईं तरफ की लेन, एक बाउंड्री साझा करती हुई। |
| **Right Lane** | तुरंत दाईं तरफ की लेन, एक बाउंड्री साझा करती हुई। |

प्रत्येक slot में दो बटन हैं:

- **Create** — एक बिल्कुल नई पड़ोसी लेन बनाएं और slot को उस पर
  point करें।
- **Set** — slot भरने के लिए कैनवस पर एक मौजूदा लेन चुनें।

कनेक्शन bidirectional हैं। Lane A का *Next Lanes* B पर सेट
करना B के *Prev Lanes* में A भी जोड़ता है; drawtonomy उल्टा
link स्वचालित रूप से बनाए रखता है।

## जब कनेक्शन स्वचालित रूप से होते हैं

- एक नई लेन बनाना जो किसी मौजूदा लेन के बाउंड्री पॉइंट पर
  शुरू होती है — ऊपर डेमो में मामला। साझा बाउंड्री पर्याप्त
  है; आपको Set क्लिक करने की आवश्यकता नहीं है।
- एक [चौराहा टेम्पलेट](/hi/reference/shapes/) रखना — हर approach
  लेन wire up हो जाती है।

बाकी सब के लिए, **Set** क्लिक करें और पड़ोसी चुनें।
