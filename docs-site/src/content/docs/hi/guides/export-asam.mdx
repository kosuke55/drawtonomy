drawtonomy आपके दृश्य को ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) और
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`) के रूप में एक्सपोर्ट कर सकता है, या दोनों को
[esmini](https://github.com/esmini/esmini) playback के लिए
तैयार एक zip के रूप में bundle कर सकता है।

![एक्सपोर्ट के बाद esmini में playback होने वाला drawtonomy दृश्य](/img/asam-esmini.png)

## एडिटर से एक्सपोर्ट

1. अपना दृश्य बनाएं (लेन, वाहन, ट्रैफिक लाइट…)।
2. **File → Export → Export for esmini** खोलें।
3. prompt पर एक base name दर्ज करें।
4. `<name>.zip` जिसमें `<name>.xodr` और `<name>.xosc` हैं
   download होती है।

## इसे playback करें

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Individual फ़ॉर्मैट

यदि आपको दोनों में से केवल एक चाहिए:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## Programmatic एक्सपोर्ट

एक्सपोर्टर `@drawtonomy/sdk` का हिस्सा है और एडिटर के बिना
चलता है। इसे CI pipelines, server-side tooling, या ब्राउज़र
एक्सटेंशन में उपयोग करें:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

पूर्ण API और extension points के लिए,
[Exporter SDK reference](/hi/extend/exporter-sdk/) देखें।
