## Toggle कहां है

Lane टूल के लिए <kbd>N</kbd> दबाएं। दायां पैनल **On** और
**Off** बटन के साथ एक **SMOOTH BOUNDARY** पंक्ति शामिल करता है:

![Lane निर्माण पैनल — SMOOTH BOUNDARY toggle हाइलाइट है, वर्तमान में Off](/img/frames/smooth-toggle-off.png)

डिफ़ॉल्ट **Off** है। Centerline पर क्लिक करना शुरू करने से
पहले इसे on करें।

## तुलना करें

नीचे दो स्क्रीनशॉट समान centerline के साथ बनाए गए थे। केवल
toggle बदला है:

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![smoothing off के साथ बनाया गया angular curve](/img/frames/smooth-off-result.png) | ![smoothing on के साथ बनाया गया smooth curve](/img/frames/smooth-on-result.png) |

Toggle off के साथ, centerline clicks का प्रत्येक pair एक सीधा
बाउंड्री segment बनता है। इसके on होने पर, वही centerline एक
curve पर fitted होता है।

## Mid-session स्विच करना

आप जब चाहें toggle flip कर सकते हैं। नई लेन अगली बार जब आप
क्लिक करते हैं तब वर्तमान मान pick up करती हैं। मौजूदा लेन वो
बाउंड्री शैली रखती हैं जिसके साथ उन्हें बनाया गया था।
