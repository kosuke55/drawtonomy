प्रत्येक shape अपनी शैली रखता है। आप editor-wide डिफ़ॉल्ट भी
बदल सकते हैं ताकि नई shapes आप जैसे चाहते हैं वैसे शुरू हों।

<Demo src="/videos/style-demo.mp4" caption="Attribute Panel से per-shape रंग, opacity, चौड़ाई, और टेम्पलेट variant।" />

## Per-shape शैली

1. Select के लिए <kbd>V</kbd> दबाएं, फिर एक shape पर क्लिक करें।
2. दाईं ओर **Attribute Panel** यह expose करता है:
   - **Color** (palette + custom)
   - **Opacity** (0–100%)
   - **Width** (line-like shapes के लिए)
   - **Style** (solid / dashed / template variant)

एक साथ कई shapes पर एक ही बदलाव लागू करने के लिए multi-select करें।

## डिफ़ॉल्ट

हर नई लेन को, मान लीजिए, 60% opacity पर शुरू करने के लिए:

1. **hamburger** मेनू खोलें।
2. **Defaults** चुनें।
3. **Lane** के तहत मान बदलें।

डिफ़ॉल्ट नई बनाई गई shapes के लिए प्रभावी होते हैं। मौजूदा
shapes को नहीं छुआ जाता।
