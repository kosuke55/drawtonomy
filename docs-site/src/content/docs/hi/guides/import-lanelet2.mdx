drawtonomy [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)
OSM-format मैप पढ़ सकता है। Sample maps
[Autoware documentation](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map)
से उपलब्ध हैं।

<Demo src="/videos/lanelet-import-demo.mp4" caption="एक पूरी Lanelet2 फ़ाइल इम्पोर्ट करना।" />

## पूरी फ़ाइल इम्पोर्ट करें

1. **File** मेनू → **Import** खोलें।
2. `.osm` फ़ाइल चुनें।
3. drawtonomy फ़ाइल को parse करता है और कैनवस को Lane shapes
   और उनके कनेक्शन के साथ populate करता है।

## केवल विशिष्ट लेन इम्पोर्ट करें

बड़े मैप के लिए, हर लेन इम्पोर्ट करना एडिटर को धीमा कर देगा।
इसके बजाय lane-selection dialog का उपयोग करें:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="केवल वे लेन drag-select करें जिनकी आपको परवाह है, फिर इम्पोर्ट करें।" />

1. **File** मेनू → **Import → Select lanes** खोलें।
2. drawtonomy एक preview मैप दिखाता है।
3. आप जो लेन चाहते हैं उन्हें चुनने के लिए क्लिक या drag करें।
4. **Import selection** पर क्लिक करें।

## Performance tips

एक responsive एडिटर के लिए इम्पोर्ट किए गए दृश्य को लगभग
**500 लेन** से कम रखें। बड़े क्षेत्रों के लिए, अपने काम को कई
फ़ाइलों में बांटें, या केवल वह क्षेत्र इम्पोर्ट करें जो आपको
चाहिए।

## इम्पोर्ट के बाद

इम्पोर्ट की गई लेन full-fidelity Lane shapes हैं; Lanelet2
फ़ाइल से कनेक्शन preserved हैं।
[स्मूथ करें](/hi/guides/smooth-lanes/), या
[वापस एक्सपोर्ट करें](/hi/guides/export-asam/) topology खोए बिना।
