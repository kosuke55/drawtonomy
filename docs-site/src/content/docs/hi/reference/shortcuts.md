## टूल स्विचिंग

| Key  | टूल                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (pan)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Edit operations

| Keys | Function |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Copy |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Paste |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Cut |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | चयनित shape(s) हटाएं |

## ड्रॉइंग करते समय Modifiers

| Modifier | प्रभाव |
|---|---|
| <kbd>Shift</kbd> | अस्थायी रूप से [snap](/hi/guides/snap/) disable करें |
| <kbd>Alt</kbd> + click | [एक मौजूदा पॉइंट साझा करें](/hi/guides/point-sharing/) (Linestring / Polygon / Path) |
| Double-click | [segment editing](/hi/guides/segment-editing/) में प्रवेश करें (Linestring / Lane / Polygon) |

## Movement

| Keys | प्रभाव |
|---|---|
| Arrow keys | चयन को 1 px हिलाएं |
| <kbd>Shift</kbd> + arrow | चयन को 10 px हिलाएं |
