חמש דקות מקנבס ריק לסצנה מיוצאת. ללא התקנה.

## 1. פתיחת האפליקציה

כנסו ל-[drawtonomy.com](https://drawtonomy.com). הכל רץ
בדפדפן; שום דבר לא מועלה.

## 2. ציור נתיב

1. לחצו <kbd>N</kbd>, או לחצו על כלי ה-**Lane** בסרגל הכלים.
2. לחצו על הקנבס למיקום תחילת קו האמצע, לחצו
   שוב לקודקוד הבא, ולחצו <kbd>Enter</kbd> לסיום.
3. הגבולות השמאלי והימני מופיעים אוטומטית.

:::tip
החזיקו <kbd>Shift</kbd> בזמן הציור כדי לעקוף [הצמדה](/he/guides/snap/)
לאותה לחיצה.
:::

## 3. הצבת רכב

1. לחצו <kbd>P</kbd> לפתיחת כלי ה-**Participants**.
2. בחרו **Vehicle → Sedan** ולחצו על הנתיב שזה עתה ציירתם.
3. גררו ידית פינתית לשינוי גודל, או השתמשו בידית הסיבוב
   כדי ליישר אותו עם הנתיב.

## 4. ייצוא הסצנה

פתחו את תפריט הייצוא ובחרו פורמט:

- **PNG / SVG / PDF** — שיתוף כתמונה שטוחה.
- **drawtonomy.svg** — שומר את כל החיבורים כך שאתם (או חבר צוות)
  תוכלו לפתוח מחדש ולהמשיך לערוך אחר כך.
- **Export for esmini** — zip עם OpenDRIVE + OpenSCENARIO מוכן
  להפעלה ב-[esmini](https://github.com/esmini/esmini).

[ייצוא הסצנה שלכם](/he/guides/export/) מכסה את הפורמטים בפירוט.
