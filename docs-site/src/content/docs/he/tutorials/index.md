המדריכים הם שיעורים קצרים ומעשיים. כל אחד מהם מעביר
משימה שלמה מתחילתה ועד סופה, כך שתוכלו לקלוט את העורך
תוך כדי מעקב.

אם אתם כבר יודעים מה אתם רוצים וצריכים רק את השלבים,
[מדריכי ההדרכה](/he/guides/) מתאימים לכם בדרך כלל יותר.

## שיעורים

- [התחלה מהירה](/he/start/quickstart/) — הנתיב והרכב הראשונים שלכם תוך
  חמש דקות.
- [שלושת הנתיבים הראשונים שלכם](/he/tutorials/your-first-lanes/) — שני
  מצבי היצירה של כלי הנתיב (Center Line ו-Boundary).
- [גבולות נתיב חלקים](/he/tutorials/smooth-lanes/) — הפעלת
  Smooth Boundary לפני ציור עקומות.
- [שחזור כביש אמיתי ממפה](/he/tutorials/road-from-map/) —
  תיוג כביש על רקע לוויין, עם הסבר על המחולל בלחיצה אחת
  כקיצור.
- [יצירת סצנה עם AI ושכלול ידני](/he/tutorials/ai-scene/) —
  תיאור תרחיש בשפה טבעית ועריכת התוצאה.
