קובץ `drawtonomy.svg` הוא SVG רגיל מועשר במטא-דאטה
שמתעד את מצב העורך בלבד.

## מבנה

- התוכן הויזואלי (paths, text, images) הוא SVG פשוט. כל מציג
  SVG מציג אותו נכון.
- בלוק `<metadata>` בראש המסמך מחזיק את
  הנתונים הספציפיים ל-drawtonomy:
  - IDs של צורות ומאפיינים לכל צורה (תבנית, סגנון וכו')
  - חריצי חיבור נתיב (`next`, `previous`, `left`, `right`)
  - הפניות לנקודות משותפות
  - השתייכות לקבוצת footprint
  - z-order

## תאימות

עריכת `drawtonomy.svg` בעורך SVG גנרי (Illustrator,
Inkscape, הדפדפן) מסירה את בלוק המטא-דאטה בשמירה אלא אם
שמרתם עליו במפורש. drawtonomy עדיין יכול לפתוח את
התוצאה, אבל החיבורים והנקודות המשותפות יהיו חסרים.

לעריכות ניתנות להלוך-ושוב מחוץ ל-drawtonomy, השתמשו ב-SDK
([`@drawtonomy/sdk`](/he/reference/sdk/)) — הוא יכול לקרוא ולכתוב את
הפורמט בלי לעבור דרך העורך.

## ניהול גרסאות

קבצים ישנים מהוגרים אוטומטית בייבוא. עוזר ה-
`resolveColorKey()` ב-SDK ממיר מפתחות צבע ישנים
(לדוגמה, `grey-700` של v1.x) לאלה הנוכחיים.
