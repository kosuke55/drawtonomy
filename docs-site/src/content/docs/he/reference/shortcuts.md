## החלפת כלים

| מקש | כלי |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | יד (הזזה) |
| <kbd>V</kbd>    | בחירה |
| <kbd>L</kbd>    | Linestring |
| <kbd>N</kbd>    | Lane |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path |
| <kbd>G</kbd>    | Polygon |
| <kbd>X</kbd>    | Crosswalk |
| <kbd>I</kbd>    | Intersection |
| <kbd>W</kbd>    | LineArrow |
| <kbd>T</kbd>    | Text |
| <kbd>D</kbd>    | Freehand |

## פעולות עריכה

| מקשים | פונקציה |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | ביטול |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | חזרה |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | העתקה |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | הדבקה |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | גזירה |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | מחיקת צורה(ות) מסומנות |

## משפיעים בזמן ציור

| מקש | אפקט |
|---|---|
| <kbd>Shift</kbd> | השבתה זמנית של [הצמדה](/he/guides/snap/) |
| <kbd>Alt</kbd> + לחיצה | [שיתוף נקודה קיימת](/he/guides/point-sharing/) (Linestring / Polygon / Path) |
| לחיצה כפולה | כניסה ל-[עריכת מקטעים](/he/guides/segment-editing/) (Linestring / Lane / Polygon) |

## תנועה

| מקשים | אפקט |
|---|---|
| מקשי חצים | הזזת הבחירה ב-1 פיקסל |
