## צורות תרחיש נהיגה

| צורה | מטרה |
|---|---|
| **Linestring** | קו רציף, בשימוש לגבולות נתיב, אבני שפה, סימונים. |
| **Lane** | נתיב נסיעה עם שני גבולות, קו אמצע וחריצי חיבור (Next / Previous / Left / Right). |
| **Vehicle** | רכב מתבנית (Sedan, Bus, Truck, Motorcycle). |
| **Pedestrian** | הולך רגל מתבנית (Walking, Simple). |
| **Path** | מסלול בשימוש לחצים, קבוצות footprint או מסלולי תרחיש. סגנון חץ או רצועה. |
| **Polygon** | אזור סגור (חניון, אזור מסומן). |
| **Crosswalk** | מעבר חצייה מעוצב מראש. |
| **TrafficLight** | סיגנל לרכב או הולך רגל. |
| **Intersection** | תבנית צומת רב-נתיבי. |

## צורות בסיסיות

| צורה | מטרה |
|---|---|
| **LineArrow** | חץ במקטע יחיד. |
| **Arrow** | חץ בצורה חופשית. |
| **Text** | טקסט פשוט או מובלט. |
| **Freehand** | מצויר במכחול דמוי-עט. |
| **Rectangle** | מלבן מיושר-לצירים. |
| **Ellipse** | אליפסה מיושרת-לצירים. |
| **Image** | PNG / JPG / SVG מיובא. |
