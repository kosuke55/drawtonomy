drawtonomy יכול לייצא את הסצנה שלכם כ-ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) ו-
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`), או לארוז את שניהם כ-zip מוכן להפעלה
ב-[esmini](https://github.com/esmini/esmini).

![סצנת drawtonomy מוצגת ב-esmini אחרי ייצוא](/img/asam-esmini.png)

## ייצוא מהעורך

1. ציירו את הסצנה (נתיבים, רכבים, רמזורים…).
2. פתחו **File → Export → Export for esmini**.
3. הזינו שם בסיס כשתתבקשו.
4. קובץ `<name>.zip` המכיל `<name>.xodr` ו-`<name>.xosc`
   יורד.

## הפעלה

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## פורמטים בודדים

אם אתם צריכים רק אחד מהשניים:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## ייצוא פרוגרמטי

המייצא הוא חלק מ-`@drawtonomy/sdk` ורץ ללא העורך.
השתמשו בו בצינורות CI, בכלים בצד שרת או בהרחבות
דפדפן:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

ל-API המלא ולנקודות הרחבה, ראו את
[עיון ה-SDK של המייצא](/he/extend/exporter-sdk/).
