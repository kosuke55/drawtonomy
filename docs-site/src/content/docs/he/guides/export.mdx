drawtonomy מגיע עם כמה פורמטי ייצוא. זה שתפנו אליו
רוב הזמן הוא **drawtonomy.svg** — SVG רגיל עם מטא-דאטה
נוסף, כך שתוכלו לפתוח את הקובץ ולהמשיך מאיפה שעצרתם.
זהו גם SVG חוקי, כך שמוצג נכון בדפדפנים, מצגות
וצינורות תיעוד ללא המרה.

הפורמטים האחרים — PNG, JPG, SVG (שטוח), PDF, EPS — מיועדים
למקרים שבהם אתם רוצים תמונה סטטית ולא צריכים לערוך
אותה מחדש.

לפלט סימולטור נהיגה (OpenDRIVE / OpenSCENARIO / Lanelet2),
ראו את עמוד [ייצוא ASAM](/he/guides/export-asam/) הייעודי.

## איפה להתחיל: drawtonomy.svg

`drawtonomy.svg` שומר IDs של צורות, חיבורי נתיבים, נקודות
משותפות, קבוצות footprint, סגנון ויחסי *מי-על-גבי-מה*.
אותו קובץ:

- **בר-עריכה.** גררו אותו חזרה ל-drawtonomy והסצנה
  חוזרת בדיוק כפי שהשארתם — כל חיבור, נקודה משותפת
  ויחס חפיפה שלמים.
- **מצוגתי.** זה SVG חוקי, כך ש-GitHub, דפדפנים, מציגי
  Markdown וכלי מצגות מציגים אותו נכון ללא המרה.
- **ידידותי לתיעוד.** וקטורי, מתרחב נקי, גודל קובץ קטן,
  ללא ארטיפקטים של ראסטריזציה. נשאר חד בכל הגדלה
  ב-README או באיור מאמר.

`drawtonomy.svg` הוא ברירת מחדל סבירה לכל מה שעשוי
להיערך שוב, להישתף עם חבר צוות שיש לו drawtonomy או
להשתבץ בתיעוד טכני.

### שמירה כ-drawtonomy.svg

1. פתחו את התפריט (שמאל-עליון).
2. לחצו על **Export**.
3. בחרו **drawtonomy.svg**.

הקובץ יורד בשם המבוסס על כותרת הסצנה.

### פתיחה מחדש

גררו את הקובץ חזרה ל-drawtonomy, או השתמשו ב-**Import** באותו
תפריט. הסצנה כולה מופיעה בלשונית חדשה כשכל צורה
ניתנת לבחירה. פאנל המאפיינים מציג חלק **OVERLAPPING OBJECTS**
כשאתם לוחצים באזור שבו צורות חופפות — היחס בין, נניח,
רכב לבין הנתיב שעליו הוא יושב שורד את ההלוך-ושוב.

## פורמטי תמונה אחרים

כשאתם צריכים רק תמונה שטוחה — ללא עריכה, ללא מטא-דאטה —
בחרו אחד מאלה מאותו תפריט Export.

| פורמט | להשתמש בו ב | הערות |
|---|---|---|
| **PNG** | מצגות, מסמכים, אתרים | ראסטר ללא הפסד. |
| **JPG** | קבצים קטנים יותר כשלא צריך שקיפות | ראסטר עם הפסד. |
| **SVG** (שטוח) | עיבוד נוסף ב-Illustrator / Inkscape, שיבוץ באתרים | ויזואלית זהה ל-drawtonomy.svg, אבל המטא-דאטה מוסר. |
| **PDF** | הדפסה, ארכוב, מאמרים | וקטורי, תומך בשקיפות. |
| **EPS** | צינורות פרסום ישנים | וקטורי. **לא תומך בשקיפות** — ראו למטה. |

### EPS ושקיפות

EPS לא מקודד שקיפות. צורה עם שקיפות 60% תיוצא
בשקיפות מלאה. אם הסצנה שלכם מסתמכת על שקיפות,
ייצאו PDF או SVG במקום.
