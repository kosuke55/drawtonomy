drawtonomy יכול לקרוא מפות בפורמט OSM של [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2).
מפות לדוגמה זמינות מ-
[תיעוד Autoware](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="ייבוא קובץ Lanelet2 שלם." />

## ייבוא הקובץ כולו

1. פתחו את תפריט **File** ← **Import**.
2. בחרו את קובץ ה-`.osm`.
3. drawtonomy מנתח את הקובץ ומאכלס את הקנבס בצורות Lane
   ובחיבוריהן.

## ייבוא רק נתיבים מסוימים

למפות גדולות, ייבוא כל נתיב יאט את העורך.
השתמשו במקום זאת בדיאלוג בחירת נתיבים:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="גררו-בחרו רק את הנתיבים שמעניינים אתכם, ואז ייבאו." />

1. פתחו את תפריט **File** ← **Import → Select lanes**.
2. drawtonomy מציג מפת תצוגה מקדימה.
3. לחצו או גררו לבחירת הנתיבים שתרצו.
4. לחצו **Import selection**.

## טיפים לביצועים

שמרו על הסצנה המיובאת מתחת ל-**500 נתיבים** בערך לעורך
רספונסיבי. לאזורים גדולים יותר, פצלו את העבודה בין
מספר קבצים, או ייבאו רק את האזור הנדרש.

## אחרי הייבוא

נתיבים מיובאים הם צורות Lane בנאמנות מלאה; החיבורים מקובץ
ה-Lanelet2 נשמרים. ערכו, [החליקו](/he/guides/smooth-lanes/),
או [ייצאו חזרה](/he/guides/export-asam/) בלי לאבד טופולוגיה.
