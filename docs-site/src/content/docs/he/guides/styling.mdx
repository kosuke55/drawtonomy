לכל צורה יש סגנון משלה. אתם יכולים גם לשנות את
ברירות המחדל של העורך כך שצורות חדשות יתחילו כפי
שאתם רוצים.

<Demo src="/videos/style-demo.mp4" caption="צבע, שקיפות, רוחב ווריאנט תבנית לכל צורה מפאנל המאפיינים." />

## סגנון לכל צורה

1. לחצו <kbd>V</kbd> ל-Select, ואז לחצו על צורה.
2. **פאנל המאפיינים** מימין חושף:
   - **Color** (פלטה + מותאם אישית)
   - **Opacity** (0–100%)
   - **Width** (לצורות דמויות-קו)
   - **Style** (מלא / מקווקו / וריאנט תבנית)

בחירה מרובה כדי להחיל את אותו שינוי על מספר צורות בבת אחת.

## ברירות מחדל

כדי שכל נתיב חדש יתחיל ב-, נניח, שקיפות 60%:

1. פתחו את תפריט ה-**hamburger**.
2. בחרו **Defaults**.
3. שנו את הערך תחת **Lane**.

ברירות מחדל נכנסות לתוקף עבור צורות שנוצרו לאחרונה.
צורות קיימות לא מושפעות.

## פלטת צבעים

drawtonomy משתמש בפלטה בסגנון Tailwind (grey-100 עד
grey-900, פלוס צבעים). לרשימה המלאה, ראו
[עיון פלטת הצבעים](/he/reference/color-palette/).
