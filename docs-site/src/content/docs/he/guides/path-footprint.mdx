*Footprint* הוא עותק של רכב (או תבנית אחרת) שממוקם
אוטומטית לאורך Path. ההדגמה מתחילה עם רכב ego אחד,
מציירת Path ממנו, והמסלול מתמלא מיד בעותקים
של אותו רכב — אותה תבנית, מכוונים לאורך העקומה,
במרווחים שווים.

<Demo src="/videos/footprints-demo.mp4" caption="רכב ego, Path שמצויר ממנו, ושובל ה-footprint שמתקבל." />

## הכנה

הציבו רכב בכל מקום על הקנבס עם כלי הרכב, ואז
לחצו <kbd>H</kbd> לכלי ה-Path. הפאנל מימין מציג הגדרות
Path:

![פאנל כלי Path — Color, Opacity 90%, Style Solid, Width 5px, Arrow Head 20px, Smooth מסומן](/img/frames/footprints-path-panel.png)

ברירות המחדל המוצגות — ירוק מלא, רוחב 5 פיקסלים, חלק, עם
ראש חץ של 20 פיקסלים — הן מה שההדגמה משתמשת בו.

## ציור המסלול

לחצו על הרכב כדי להתחיל את המסלול. הנקודה הראשונה
ננעלת על עוגן הרכב. לחצו על נקודות נוספות להמשכת
המסלול; ראש החץ מופיע בנקודה האחרונה שהשמטתם. לחצו
<kbd>Enter</kbd> לסיום.

ברגע שהמסלול מסתיים, drawtonomy פורס עותק של הרכב
המקורי לאורכו:

![ה-Path מצויר; footprints של הרכב מופיעים לאורכו במרווחים שווים](/img/frames/footprints-along-path.png)

כל עותק מסובב להתאים למשיק המסלול במיקומו, כך
שהשובל עוקב אחרי עקומות באופן טבעי.

## סגנון ותבנית נשארים מקושרים

footprints חולקים סגנון עם הרכב המקורי שלהם: שנו את
הצבע, השקיפות או התבנית של המקור, וכל footprint עוקב.
אתם לא צריכים לערוך ידנית כל עותק כדי לשמור על
דיאגרמת תמרון עקבית ויזואלית.

מסגרת ההדגמה הבאה מסתירה את המסלול עצמו כך שרק ה-
footprints נשארים — שימושי לצילומי ייצוא כשאתם לא רוצים
שהמסלול שמתחת יעמיס על הדיאגרמה:

![footprints לבד, ללא המסלול המצויר](/img/frames/footprints-result.png)

## מה אתם יכולים לכוון

- **Spacing** — מרחק בין footprints.
- **Anchor offset** — החליקו את נקודת הייחוס לאורך כיוון
  הנסיעה (לדוגמה, base link או פגוש קדמי במקום
  המרכז).
- **Smooth** — תיבת הסימון בפאנל ה-Path הופכת את המסלול
  עצמו לעקומה חלקה בין נקודות; אוריינטציית footprint עוקבת.
- **Color / Opacity / Size** — מיושמים על כל footprint בבת אחת
  דרך הרכב המקורי.
