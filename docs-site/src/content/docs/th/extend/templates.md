เทมเพลตคือไฟล์ SVG บวกกับรายการใน manifest เมื่อร่วมแล้ว
จะปรากฏในเมนู Participants และเมนูรูปทรงของโปรแกรมแก้ไข
เคียงข้างเทมเพลตในตัว

ขั้นตอนการมีส่วนร่วมอยู่ในรีโป public:

➡ **[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md)**

## หมวดหมู่

| โฟลเดอร์ | ตัวอย่าง |
|---|---|
| `templates/vehicle/` | Sedan, Bus, Truck, Motorcycle |
| `templates/pedestrian/` | Walking, Simple |
| `templates/road_marking/` | ทางม้าลาย เครื่องหมายลูกศร |
| `templates/sign/` | ป้ายหยุด ป้ายเสียทาง หัวสัญญาณ |
| `templates/other/` | อื่น ๆ |

## ขั้นตอน

1. เพิ่ม SVG ของคุณในโฟลเดอร์หมวดหมู่ที่เหมาะสม
2. ลงทะเบียนใน `templates/manifest.json`
3. เปิด PR แนบภาพหน้าจอของเทมเพลตที่วางบนผืนผ้าใบ

## เทมเพลตที่ดีคืออะไร

- วาดในขนาดเริ่มต้นที่สมเหตุสมผล (ยานพาหนะประมาณ 4–5 ม.
  สำหรับ sedan)
- มีบริเวณที่เปลี่ยนสีได้บริเวณเดียวที่ทำเครื่องหมายด้วย
  fill ที่ทราบ เพื่อให้ตัวเลือกสีของ Attribute Panel เปลี่ยน
  สีได้
- ไม่อ้างอิงฟอนต์ภายนอก — ข้อความจะถูกแปลงเป็น path ถ้ามี
- ขนาดไฟล์สมเหตุสมผล (ต่ำกว่า ~30 KB สำหรับเทมเพลตขนาด
  ยานพาหนะ)
