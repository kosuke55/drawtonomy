## drawtonomy คืออะไร?

drawtonomy เป็น **ไวท์บอร์ดสำหรับสถานการณ์ขับขี่** — ไม่ว่าจะเป็น
ภาพประกอบในเปเปอร์ สไลด์ที่ร่างก่อนการพิจารณาดีไซน์
แผนภาพที่วาดระหว่างพูดคุยทางโทรศัพท์ขณะอธิบายกรณีพิเศษ (corner case)
ให้ทีมฟัง หรือฉากที่ร่างก่อนเขียนไฟล์ OpenSCENARIO

เปิด URL วาดเลนและทางแยกบนผืนผ้าใบไม่จำกัดขอบ ใส่ยานพาหนะ
คนเดินเท้า สัญญาณไฟจราจร ทางม้าลาย และเครื่องหมายบนถนน
จากนั้นบันทึกหรือส่งออก ไม่ต้องติดตั้ง ไม่ต้องสร้างบัญชี
และไม่มีการอัปโหลดข้อมูล

เหตุผลที่ดำรงอยู่ของเครื่องมือนี้: เครื่องมือวาดทั่วไปและโปรแกรมสไลด์
ไม่รู้จักว่าเลนคืออะไร จึงต้องวาดรูปทรงถนนใหม่ทุกครั้งที่มีการเปลี่ยนแปลง
drawtonomy จัดการเลน ทางแยก และคำศัพท์อื่น ๆ ในวงการสถานการณ์ขับขี่
ในฐานะรูปทรงสำเร็จรูป ภาพจึงคงความถูกต้องไว้ระหว่างการปรับแก้
