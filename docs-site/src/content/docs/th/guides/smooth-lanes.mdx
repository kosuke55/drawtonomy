drawtonomy สร้างขอบเขตเลนที่ฟิตด้วย spline แทนที่จะเป็นเส้นหัก
ได้ สวิตช์อยู่ในพาเนลสร้าง Lane และมีผลกับเลนที่จะวาดต่อไป
ไม่ทำให้เลนที่มีอยู่โค้งเรียบย้อนหลัง

<Demo src="/videos/smooth-lane.mp4" caption="เลนวาดด้วย Smooth Boundary ปิด (ซ้าย เป็นเส้นหัก) และเปิด (ขวา โค้งเรียบ)" />

## ตำแหน่งของสวิตช์

กด <kbd>N</kbd> สำหรับเครื่องมือ Lane พาเนลด้านขวามีแถว
**SMOOTH BOUNDARY** พร้อมปุ่ม **On** และ **Off**:

![พาเนลสร้าง Lane — ไฮไลต์สวิตช์ SMOOTH BOUNDARY ปัจจุบันคือ Off](/img/frames/smooth-toggle-off.png)

ค่าเริ่มต้นคือ **Off** เปิดสวิตช์ก่อนที่จะเริ่มคลิกเส้นกึ่งกลาง

## เปรียบเทียบ

ภาพหน้าจอสองภาพด้านล่างวาดด้วยเส้นกึ่งกลางเดียวกัน สิ่งเดียว
ที่เปลี่ยนคือสวิตช์:

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![เส้นโค้งหักวาดเมื่อปิด smoothing](/img/frames/smooth-off-result.png) | ![เส้นโค้งเรียบวาดเมื่อเปิด smoothing](/img/frames/smooth-on-result.png) |

เมื่อปิดสวิตช์ การคลิกเส้นกึ่งกลางคู่กันแต่ละคู่จะกลายเป็น
เซกเมนต์ขอบเขตเส้นตรง เมื่อเปิดสวิตช์ เส้นกึ่งกลางเดียวกัน
จะถูกฟิตเป็นเส้นโค้ง

## สลับกลางเซสชัน

สลับสวิตช์ได้ตลอดเวลา เลนใหม่จะรับค่าปัจจุบันในครั้งถัดไป
ที่คลิก เลนที่มีอยู่ยังคงสไตล์ขอบเขตที่วาดไว้
