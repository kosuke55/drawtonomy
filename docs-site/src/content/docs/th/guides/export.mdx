drawtonomy มีรูปแบบส่งออกหลายแบบ ตัวเลือกที่ใช้บ่อยที่สุดคือ
**drawtonomy.svg** — SVG ปกติพร้อมเมทาดาทาเพิ่มเติม จึงเปิดไฟล์
และทำงานต่อจากที่หยุดได้ และเป็น SVG ที่ถูกต้อง จึงแสดง
ตัวอย่างถูกต้องในเบราว์เซอร์ โปรแกรมสไลด์ และสายการจัดการ
เอกสารโดยไม่ต้องแปลง

รูปแบบอื่น — PNG, JPG, SVG (แบน), PDF, EPS — ใช้สำหรับกรณี
ที่ต้องการภาพแบบสถิตและไม่ต้องแก้ไขซ้ำ

สำหรับเอาต์พุตตัวจำลองการขับขี่ (OpenDRIVE / OpenSCENARIO /
Lanelet2) ดูหน้า [การส่งออก ASAM](/th/guides/export-asam/) โดยเฉพาะ

## เริ่มต้นที่: drawtonomy.svg

`drawtonomy.svg` เก็บ ID ของรูปทรง การเชื่อมต่อเลน จุดร่วม
กลุ่ม footprint สไตล์ และความสัมพันธ์ *รูปทรงใดอยู่ด้านบน*
ไฟล์เดียวกันยัง:

- **แก้ไขซ้ำได้** ลากกลับเข้า drawtonomy แล้วฉากกลับมาเหมือน
  ที่ทิ้งไว้ — การเชื่อมต่อ จุดร่วม และความสัมพันธ์การซ้อนทับ
  ทุกอย่างยังคงอยู่
- **แสดงตัวอย่างได้** เป็น SVG ที่ถูกต้อง GitHub เบราว์เซอร์
  ตัวเรนเดอร์ Markdown และเครื่องมือสไลด์จึงแสดงได้ถูกต้อง
  โดยไม่ต้องแปลง
- **เหมาะกับเอกสาร** เวกเตอร์ ขยายขนาดได้สะอาด ขนาดไฟล์เล็ก
  ไม่มีรอยรัสเตอร์ คมชัดทุกระดับการซูมใน README หรือภาพในเปเปอร์

`drawtonomy.svg` เป็นค่าเริ่มต้นที่สมเหตุสมผลสำหรับสิ่งที่
อาจถูกแก้ไขอีก แชร์กับเพื่อนร่วมทีมที่มี drawtonomy หรือ
ฝังในเอกสารทางเทคนิค

### บันทึกเป็น drawtonomy.svg

1. เปิดเมนู (มุมซ้ายบน)
2. คลิก **Export**
3. เลือก **drawtonomy.svg**

ไฟล์จะดาวน์โหลดด้วยชื่อตามชื่อฉาก

### เปิดอีกครั้ง

ลากไฟล์กลับเข้า drawtonomy หรือใช้ **Import** ในเมนูเดียวกัน
ฉากทั้งหมดจะปรากฏในแท็บใหม่ พร้อมรูปทรงทุกชิ้นที่เลือกได้
แผง Attribute Panel จะแสดงส่วน **OVERLAPPING OBJECTS** เมื่อ
คลิกในพื้นที่ที่รูปทรงซ้อนทับ — ความสัมพันธ์ระหว่างยานพาหนะ
และเลนที่อยู่บน เป็นต้น ยังคงอยู่หลังการ round-trip

## รูปแบบภาพอื่น

เมื่อต้องการภาพแบนเท่านั้น — ไม่แก้ไข ไม่มีเมทาดาทา — เลือก
รูปแบบใดรูปแบบหนึ่งจากเมนู Export เดียวกัน

| รูปแบบ | ใช้สำหรับ | หมายเหตุ |
|---|---|---|
| **PNG** | สไลด์ เอกสาร เว็บเพจ | รัสเตอร์แบบไร้สูญเสีย |
| **JPG** | ไฟล์เล็กลงเมื่อไม่ต้องการความโปร่งใส | รัสเตอร์แบบสูญเสียข้อมูล |
| **SVG** (แบน) | กระบวนการต่อใน Illustrator / Inkscape การฝังในเว็บ | เหมือน drawtonomy.svg ในเชิงภาพ แต่เมทาดาทาถูกตัดออก |
| **PDF** | งานพิมพ์ การจัดเก็บถาวร เปเปอร์ | เวกเตอร์ รองรับความโปร่งใส |
| **EPS** | สายการเผยแพร่แบบดั้งเดิม | เวกเตอร์ **ไม่รองรับความโปร่งใส** — ดูด้านล่าง |

### EPS และความโปร่งใส

EPS ไม่เข้ารหัสความโปร่งใส รูปทรงที่มีความทึบ 60% จะส่งออก
ที่ความทึบเต็ม หากฉากต้องอาศัยความโปร่งใส ส่งออกเป็น PDF
หรือ SVG แทน
