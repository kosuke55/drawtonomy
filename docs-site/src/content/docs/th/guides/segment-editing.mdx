การแก้ไขเซกเมนต์ช่วยให้ปรับรูปทรงระหว่างจุดยอดสองจุดที่ติดกัน
เพิ่มจุดยอดใหม่ หรือลบจุด — โดยไม่ต้องวาดรูปทรงใหม่ตั้งแต่ต้น

## เข้าสู่โหมดแก้ไขเซกเมนต์

1. กด <kbd>V</kbd> สำหรับเครื่องมือ Select
2. ดับเบิลคลิก Linestring, Lane หรือ Polygon
3. รูปทรงจะเข้าโหมดแก้ไขจุด: จุดยอดแต่ละจุดกลายเป็นแฮนเดิล
   สีอินดิโกที่ลากได้

## ขยับจุด

คลิกแล้วลากจุดยอด หากจุดถูกใช้ร่วมกับรูปทรงอื่น (ดู
[Point Sharing](/th/guides/point-sharing/)) ทุกรูปทรงที่ถือ
จุดนั้นจะขยับไปด้วยกัน

สำหรับเลน การลากจุดขอบเขตจะอัปเดตเลนทั้งสองที่ใช้ขอบเขตร่วม —
ดู [โมเดลการเชื่อมต่อเลน](/th/explanation/lane-model/)

## เพิ่มจุด

คลิกที่ใดก็ได้บนเซกเมนต์ (เส้นระหว่างจุดที่มีอยู่สองจุด)
จุดยอดใหม่จะถูกแทรกที่ตำแหน่งที่คลิก

นี่เป็นวิธีที่เร็วที่สุดในการเพิ่มความโค้งให้ส่วนที่เคยเป็น
เส้นตรง: เพิ่มจุดแล้วลาก

## ลบจุด

เลือกจุดยอด (จะกลายเป็นสีอินดิโกทึบ) แล้วกด
<kbd>Delete</kbd> หรือ <kbd>Backspace</kbd>

## ออกจากการแก้ไขเซกเมนต์

กด <kbd>Esc</kbd> คลิกนอกรูปทรง หรือเลือกเครื่องมืออื่น
รูปทรงจะกลับสู่โหมด Select ปกติ
