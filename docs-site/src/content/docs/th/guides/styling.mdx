ทุกรูปทรงมีสไตล์ของตนเอง เปลี่ยนค่าเริ่มต้นทั่วทั้งโปรแกรม
แก้ไขได้ด้วย เพื่อให้รูปทรงใหม่เริ่มต้นในแบบที่ต้องการ

<Demo src="/videos/style-demo.mp4" caption="สี ความทึบ ความกว้าง และตัวเลือกเทมเพลตต่อรูปทรงจาก Attribute Panel" />

## สไตล์ต่อรูปทรง

1. กด <kbd>V</kbd> เพื่อ Select แล้วคลิกรูปทรง
2. **Attribute Panel** ทางขวาแสดง:
   - **Color** (จานสี + กำหนดเอง)
   - **Opacity** (0–100%)
   - **Width** (สำหรับรูปทรงที่เป็นเส้น)
   - **Style** (solid / dashed / ตัวเลือกเทมเพลต)

เลือกหลายชิ้นเพื่อใช้การเปลี่ยนแปลงเดียวกันกับหลายรูปทรงพร้อมกัน

## ค่าเริ่มต้น

หากต้องการให้เลนใหม่ทุกเส้นเริ่มต้นที่ความทึบ 60% เช่น:

1. เปิดเมนู **hamburger**
2. เลือก **Defaults**
3. เปลี่ยนค่าใต้ **Lane**

ค่าเริ่มต้นมีผลกับรูปทรงที่สร้างใหม่ ไม่กระทบรูปทรงที่มีอยู่
