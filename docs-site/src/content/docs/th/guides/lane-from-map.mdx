Lane Generator ดึงรูปทรงถนนจริงจาก OpenStreetMap แล้วเปลี่ยน
เป็นรูปทรง Lane ที่แก้ไขได้และจัดวางตรงกับพื้นหลังแผนที่

<Demo src="/videos/map-to-lane-demo.mp4" caption="คลิกถนนสำหรับหนึ่งเลน ลากพื้นที่สำหรับหลายเลน" maxWidth="900px" />

## เปิดพื้นหลังแผนที่

1. เปิดเมนู **Background** ที่มุมซ้ายบนของผืนผ้าใบ
2. เลือก **Satellite** (ภาพถ่าย) หรือ **Roadmap** (แผนผัง)
3. แพนและซูมไปยังพื้นที่ที่ต้องการ

แผนที่จะเรนเดอร์ด้านหลังผืนผ้าใบและคงตำแหน่งขณะที่วาด

## สร้างเลนเดียว

1. กด <kbd>N</kbd> สำหรับเครื่องมือ Lane
2. เปิดโหมด **Generator** ในแถบเครื่องมือ
3. ลอยเมาส์ไปที่ถนน drawtonomy ไฮไลต์เซกเมนต์ถนน OSM ที่ตรง
   กับใต้เคอร์เซอร์
4. คลิก เซกเมนต์จะถูกดึงและแปลงเป็นรูปทรง Lane

## สร้างทุกถนนในพื้นที่

เมื่อเปิดโหมด Generator:

1. ลากสี่เหลี่ยมครอบพื้นที่ที่ต้องการ
2. ปล่อย ถนนทุกเส้นภายในสี่เหลี่ยมจะกลายเป็น Lane ในชุดเดียว

มีประโยชน์สำหรับทางแยกทั้งทางแยก ย่าน หรือพื้นที่ทดสอบ

## ขีดจำกัดที่แนะนำ

การดึงและแปลง OSM ทำงานในเบราว์เซอร์ เพื่อการแก้ไขที่ลื่นไหล
เก็บฉากผลลัพธ์ไม่เกินประมาณ **500 เลน** — แบ่งพื้นที่ใหญ่
ออกเป็นไฟล์หลายไฟล์หากต้องการมากกว่านี้

## หลังการสร้าง

เลนที่สร้างเป็นรูปทรง Lane ปกติ สามารถ:

- ลากจุดเพื่อปรับรูปทรง
- ใช้ [Smooth](/th/guides/smooth-lanes/) เพื่อแทนเส้นหักที่หนาแน่น
  ด้วย spline
- ตั้ง [การเชื่อมต่อ](/th/guides/lane-connections/) ตรงที่ตัวสร้าง
  ไม่ได้อนุมานโดยอัตโนมัติ
- วางยานพาหนะ คนเดินเท้า หรือเส้นทางทับ
