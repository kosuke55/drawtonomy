*footprint* คือสำเนาของยานพาหนะ (หรือเทมเพลตอื่น) ที่วาง
ตามเส้นทางโดยอัตโนมัติ เดโมเริ่มจากรถ ego หนึ่งคัน วาด Path
จากรถนั้น แล้วเส้นทางจะเต็มไปด้วยสำเนาของรถนั้นทันที — เทมเพลต
เดียวกัน หันตามแนวโค้ง และห่างเท่ากัน

<Demo src="/videos/footprints-demo.mp4" caption="รถ ego, Path ที่วาดจากรถ และรอย footprint ที่เกิดขึ้น" />

## เตรียมการ

วางยานพาหนะที่ใดก็ได้บนผืนผ้าใบด้วยเครื่องมือ Vehicle จากนั้น
กด <kbd>H</kbd> สำหรับเครื่องมือ Path พาเนลด้านขวาแสดง
การตั้งค่า Path:

![พาเนลเครื่องมือ Path — Color, Opacity 90%, Style Solid, Width 5px, Arrow Head 20px, Smooth ติ๊กไว้](/img/frames/footprints-path-panel.png)

ค่าเริ่มต้นที่แสดง — สีเขียวทึบ กว้าง 5 px โค้งเรียบ พร้อม
หัวลูกศร 20 px — คือสิ่งที่เดโมใช้

## วาดเส้นทาง

คลิกที่ยานพาหนะเพื่อเริ่มเส้นทาง จุดแรกจะ latch เข้ากับ
จุดยึดของยานพาหนะ คลิกจุดถัดไปเพื่อขยายเส้นทาง หัวลูกศรจะ
ปรากฏที่จุดสุดท้ายที่วาง กด <kbd>Enter</kbd> เพื่อเสร็จสิ้น

ทันทีที่เส้นทางเสร็จ drawtonomy จะวางสำเนายานพาหนะต้นทาง
ตามเส้นทาง:

![วาด Path เสร็จแล้ว footprint ของยานพาหนะปรากฏตามเส้นทางโดยห่างเท่ากัน](/img/frames/footprints-along-path.png)

แต่ละสำเนาจะหมุนให้ตรงกับเส้นสัมผัสของเส้นทางที่ตำแหน่งนั้น
รอย footprint จึงตามแนวโค้งได้อย่างเป็นธรรมชาติ

## สไตล์และเทมเพลตเชื่อมโยงกัน

footprint ใช้สไตล์เดียวกับยานพาหนะต้นทาง: เปลี่ยนสี ความทึบ
หรือเทมเพลตของต้นทาง แล้วทุก footprint ตามไปด้วย ไม่ต้อง
แก้ไขแต่ละสำเนาด้วยมือเพื่อให้แผนภาพการหลบหลีกดูสอดคล้องกัน

เฟรมเดโมถัดไปซ่อนเส้นทางเอง เหลือเพียง footprint — มีประโยชน์
สำหรับภาพส่งออกที่ไม่ต้องการให้เส้นทางพื้นรกแผนภาพ:

![footprint อย่างเดียว ไม่มีเส้นทางวาด](/img/frames/footprints-result.png)

## สิ่งที่ปรับได้

- **ระยะห่าง** — ระยะระหว่าง footprint
- **ออฟเซ็ตจุดยึด** — เลื่อนจุดอ้างอิงตามทิศทางการเคลื่อนที่
  (เช่น base link หรือกันชนหน้าแทนจุดกึ่งกลาง)
- **Smooth** — เช็กบ็อกซ์ในพาเนล Path ทำให้เส้นทางโค้งเรียบ
  ระหว่างจุด การหันของ footprint จะตามด้วย
- **Color / Opacity / Size** — มีผลกับทุก footprint พร้อมกัน
  ผ่านยานพาหนะต้นทาง
