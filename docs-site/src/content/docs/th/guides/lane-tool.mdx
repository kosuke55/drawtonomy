และคงอยู่ตลอดที่เครื่องมือทำงาน ส่วนบนของพาเนลคือสวิตช์
**CREATION MODE**:

![พาเนล Lane — CREATION MODE มีปุ่ม Center Line และ Boundary; เลือก Center Line อยู่; Lane Width 50 px](/img/frames/lane-tool-panel.png)

ทั้งสองโหมดทำงานแตกต่างกัน เลือกโหมดที่ตรงกับสถานการณ์

<Demo src="/videos/lane-tool-demo.mp4" caption="สองเลนวาดในโหมด Center Line จากนั้นเลนที่สามแทรกในโหมด Boundary" />

## โหมด Center Line

วาดเส้นกึ่งกลาง drawtonomy จะสร้างขอบเขตซ้ายและขวาจาก
ค่า **Lane Width** ใช้เมื่อเริ่มจากศูนย์

1. คลิกบนผืนผ้าใบเพื่อวางจุดเส้นกึ่งกลางจุดแรก
2. คลิกอีกครั้งเพื่อวางจุดถัดไป ทำซ้ำเรื่อย ๆ
3. กด <kbd>Enter</kbd> (หรือดับเบิลคลิกจุดสุดท้าย) เพื่อเสร็จสิ้น

เครื่องมือ Lane ยังทำงานต่อ คลิกที่อื่นเพื่อเริ่มเลนใหม่
สองเลนที่วาดด้วยวิธีนี้:

![สองเลนวาดจากเส้นกึ่งกลาง](/img/frames/lane-tool-two-lanes.png)

เปลี่ยน Color, Opacity หรือ Lane Width ในพาเนลระหว่างเลน
ได้ — ค่าใหม่จะมีผลกับเลนถัดไปที่จะวาด ไม่ใช่เลนที่เลือก

## โหมด Boundary

คลิก **Boundary** ที่ส่วนบนของพาเนลเพื่อเปลี่ยนโหมด ในโหมด
Boundary จะไม่คลิกพื้นที่ว่าง แต่คลิกเส้นขอบเขตที่มีอยู่
สองเส้น drawtonomy จะสร้างเลนที่ใช้เส้นทั้งสองเป็นขอบเขต
ซ้ายและขวา

ลอยเมาส์ไปที่เส้น — drawtonomy ไฮไลต์เส้นเป็นสีอินดิโกเมื่อ
เคอร์เซอร์ใกล้พอ — แล้วคลิก:

![โหมด Boundary — ขอบเขตขวาที่มีอยู่ไฮไลต์ พร้อมถูกเลือก](/img/frames/lane-tool-boundary-mode.png)

คลิกเส้นที่สองและเลนใหม่จะปรากฏระหว่างทั้งสอง เลนใหม่
จะใช้ขอบเขตทั้งสองร่วมกับสิ่งอื่นที่ใช้เส้นเดียวกันอยู่
การขยับจุดขอบเขตจะอัปเดตทุกเลนที่ขึ้นกับจุดนั้น

ใช้โหมด Boundary เมื่อมีรูปทรงอยู่แล้ว (วาดด้วยมือ นำเข้าจาก
Lanelet2 หรือสร้างจาก Lane Generator) และต้องการให้เลนเข้า
พอดีระหว่างเส้นเหล่านั้น

## การตรวจสอบเลน

กด <kbd>V</kbd> เพื่อ Select แล้วคลิกเลน พาเนลจะเปลี่ยนเป็น
คุณสมบัติของเลน:

![Lane Attribute Panel — Lane ID, ID ขอบเขตที่ใช้ร่วม, Direction, ช่องเชื่อมต่อสี่ช่อง](/img/frames/lane-attributes.png)

สิ่งที่แสดง:

- **Lane ID** และ ID ของเส้น **Left Boundary** /
  **Right Boundary** (เช่น `way/1`, `way/2`) สองเลนที่ใช้
  เส้นเดียวกันจะแสดง ID เดียวกันที่นี่
- **Lane Color**, **Lane Opacity**, **Direction (Reverse)** —
  ค่าทางภาพและโทโพโลยีของเลนเอง
- **Next Lanes / Prev Lanes / Left Lane / Right Lane** —
  ช่องเชื่อมต่อสี่ช่อง แต่ละช่องมี **Create** (สร้างเลน
  ข้างเคียงใหม่) และ **Set** (ชี้ไปที่เลนที่มีอยู่) ดู
  [จัดการการเชื่อมต่อเลน](/th/guides/lane-connections/)
