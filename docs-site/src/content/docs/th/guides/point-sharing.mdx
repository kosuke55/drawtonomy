*จุดร่วม* คือจุดยอดเดียวที่ถูกอ้างอิงโดยรูปทรงหลายชิ้น
ขยับครั้งเดียวแล้วทุกรูปทรงที่อ้างอิงจะตามไปด้วย ใช้เพื่อ
ยึดขอบเขตเลนที่ติดกัน มุมพอลิกอน และข้อต่อเส้นทางให้อยู่
ด้วยกันเสมอ

<Demo src="/videos/share-demo.mp4" caption="กด Alt + คลิกเพื่อใช้จุดที่มีอยู่ร่วมกับรูปทรงใหม่" />

## สร้างจุดร่วมขณะวาด

1. เลือกเครื่องมือ Linestring (<kbd>L</kbd>), Polygon
   (<kbd>G</kbd>) หรือ Path (<kbd>H</kbd>)
2. กด <kbd>Alt</kbd> ค้างไว้ (Option บน macOS)
3. คลิกจุดยอดที่มีอยู่ของรูปทรงอื่น

รูปทรงใหม่จะมีจุดยอดที่ *ใช้ร่วม* กับรูปทรงที่มีอยู่ — ไม่ใช่
แค่ snap ไปยังพิกัดเดียวกัน

## แปลงจุดยอดที่มีอยู่เป็นจุดร่วม

1. ดับเบิลคลิกรูปทรงเพื่อเข้า
   [การแก้ไขเซกเมนต์](/th/guides/segment-editing/)
2. กด <kbd>Alt</kbd> ค้างไว้แล้วลากจุดยอดไปยังจุดที่มีอยู่

## สัญลักษณ์เชิงภาพ

จุดร่วมแสดงเป็นแฮนเดิลคู่ในโหมดแก้ไขเซกเมนต์ จุด snap
ธรรมดาแสดงเป็นแฮนเดิลเดี่ยว
