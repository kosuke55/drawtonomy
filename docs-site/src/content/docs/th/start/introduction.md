drawtonomy คือไวท์บอร์ดสำหรับสถานการณ์ขับขี่ ไม่ว่าจะเป็น
ภาพประกอบในเปเปอร์ สไลด์ที่ร่างก่อนการพิจารณาดีไซน์
แผนภาพที่วาดระหว่างพูดคุยทางโทรศัพท์ขณะอธิบายกรณีพิเศษให้ทีม
หรือฉากที่ร่างก่อนเขียนไฟล์ OpenSCENARIO

เลน ทางแยก ยานพาหนะ คนเดินเท้า สัญญาณไฟจราจร เครื่องหมาย
บนถนน และทางม้าลายเป็นรูปทรงสำเร็จรูป เลนเข้าใจโทโพโลยี —
มีการเชื่อมต่อ Next / Previous / Left / Right — ทำให้แผนภาพ
เป็นเครือข่ายที่แก้ไขได้ ไม่ใช่ภาพที่ต้องวาดใหม่ทุกครั้งที่
รูปทรงถนนเปลี่ยน

แอปอยู่ที่ [drawtonomy.com](https://drawtonomy.com) ส่วน SDK
ส่วนขยาย และซอร์สของเอกสารชุดนี้อยู่บน
[GitHub](https://github.com/kosuke55/drawtonomy)

## กรณีการใช้งาน

- **ภาพประกอบสำหรับเปเปอร์ วิทยานิพนธ์ และรายงานทางเทคนิค**
  ผลลัพธ์เวกเตอร์ (`drawtonomy.svg`, PDF, EPS) ที่ฝังในเอกสาร
  LaTeX, Markdown และสไลด์ได้สะอาด
- **สไลด์และการนำเสนอ** แผนภาพการเปลี่ยนเลน ทางแยก กรณี
  ที่ถูกบดบัง และสถานการณ์ขับขี่อื่น ๆ ที่วาดเสร็จในไม่กี่
  วินาทีแทนที่จะเป็นนาทีต่อรูปทรง
- **การหารือดีไซน์และอัลกอริทึม** พื้นที่ร่างที่ใช้ร่วมกันสำหรับ
  พูดคุยพฤติกรรมการขับขี่ กรณีขอบ และข้อพิจารณาด้านความปลอดภัย
  กับเพื่อนร่วมทีม
- **การสร้างสถานการณ์** ร่างฉากก่อนเขียน OpenSCENARIO XML
  หรือนำเข้าไฟล์ `.xosc` ที่มีอยู่และแก้ไขในรูปแบบภาพ
- **การกำกับข้อมูลแผนที่และ ROS** ลากเส้นเลนทับภาพถ่ายดาวเทียม
  แก้ไขแผนที่ Lanelet2 OSM หรือกำกับข้อมูล occupancy grid ของ
  ROS ด้วยเส้นทางและสิ่งกีดขวาง

## เหมาะสำหรับใคร

- **วิศวกรรถยนต์ขับเคลื่อนอัตโนมัติและ ADAS** ที่วาดแผนภาพสำหรับ
  เอกสารภายใน การพิจารณาดีไซน์ และรายงานเหตุการณ์
- **นักวิจัยและนักศึกษา AV** ที่ผลิตภาพประกอบสำหรับเปเปอร์
  วิทยานิพนธ์ และการบรรยายในการประชุม
- **ผู้สร้างสถานการณ์** ที่ทำงานกับตัวจำลองอย่าง
  [esmini](https://github.com/esmini/esmini), CARLA หรือ
  เครื่องมือภายในองค์กร
- **ผู้ใช้แผนที่ HD และ Lanelet2** ที่ร่างการเปลี่ยนแปลงบน
  เครือข่ายถนนที่มีอยู่
- **ทีม ROS และหุ่นยนต์** ที่วาดทับ occupancy grid ที่สร้างจาก
  nav2, Cartographer หรือ Gmapping
- **ครูฝึกขับรถและนักการศึกษา** ที่ผลิตแผนภาพสำหรับสื่อการสอน
- **ผู้สร้างเครื่องมือ** ที่ขยายโปรแกรมแก้ไขด้วยตัวส่งออก
  ตัวนำเข้า หรือฟีเจอร์ที่ใช้ AI ผ่าน
  [extension SDK](/th/extend/) ใหม่
