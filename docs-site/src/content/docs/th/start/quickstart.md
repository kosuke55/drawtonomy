ห้านาทีจากผืนผ้าใบเปล่าไปจนถึงฉากที่ส่งออกได้ ไม่ต้องติดตั้ง

## 1. เปิดแอป

ไปที่ [drawtonomy.com](https://drawtonomy.com) ทุกอย่างทำงาน
ในเบราว์เซอร์ ไม่มีการอัปโหลดข้อมูล

## 2. วาดเลน

1. กด <kbd>N</kbd> หรือคลิกเครื่องมือ **Lane** ในแถบเครื่องมือ
2. คลิกบนผืนผ้าใบเพื่อวางจุดเริ่มต้นของเส้นกึ่งกลาง คลิกอีกครั้ง
   สำหรับจุดยอดถัดไป แล้วกด <kbd>Enter</kbd> เพื่อเสร็จสิ้น
3. ขอบเขตซ้ายและขวาจะปรากฏโดยอัตโนมัติ

:::tip
กด <kbd>Shift</kbd> ค้างไว้ขณะวาดเพื่อข้าม [snap](/th/guides/snap/)
สำหรับการคลิกครั้งนั้น
:::

## 3. วางยานพาหนะ

1. กด <kbd>P</kbd> เพื่อเปิดเครื่องมือ **Participants**
2. เลือก **Vehicle → Sedan** แล้วคลิกบนเลนที่เพิ่งวาด
3. ลากแฮนเดิลที่มุมเพื่อปรับขนาด หรือใช้แฮนเดิลหมุนเพื่อจัดวาง
   ให้ตรงกับเลน

## 4. ส่งออกฉาก

เปิดเมนูส่งออกแล้วเลือกรูปแบบ:

- **PNG / SVG / PDF** — แชร์เป็นภาพแบน
- **drawtonomy.svg** — บันทึกทุกการเชื่อมต่อ เพื่อให้คุณ
  (หรือเพื่อนร่วมทีม) เปิดและแก้ไขต่อในภายหลังได้
- **Export for esmini** — ไฟล์ zip ที่มี OpenDRIVE +
  OpenSCENARIO พร้อมเล่นใน [esmini](https://github.com/esmini/esmini)

[ส่งออกฉาก](/th/guides/export/) อธิบายแต่ละรูปแบบโดยละเอียด
