เปิด **Smooth Boundary** ก่อนวาดเลนที่โค้ง

สำหรับเลนที่จะวาดต่อไป ไม่กระทบเลนที่มีอยู่

## 1. เปิดพาเนล Lane

กด <kbd>N</kbd> สำหรับเครื่องมือ Lane พาเนลด้านขวาจะเปิด
หาแถว **SMOOTH BOUNDARY** — ค่าเริ่มต้นคือ **Off**:

![พาเนลสร้าง Lane — แถว SMOOTH BOUNDARY ปัจจุบันตั้งค่าเป็น Off](/img/frames/smooth-toggle-off.png)

## 2. วาดเลนที่โค้งโดยปิดสวิตช์

ปล่อยสวิตช์ที่ **Off** คลิกบนผืนผ้าใบเพื่อวางจุดเส้นกึ่งกลาง
ตามแนวโค้ง แล้วกด <kbd>Enter</kbd> เพื่อเสร็จสิ้น

ขอบเขตเป็นเส้นตรงระหว่างจุดที่ติดกัน เลนจึงออกมาเป็นเส้นหัก:

![เลนที่โค้งวาดด้วย Smooth Boundary ปิด — ขอบเขตเป็นเส้นหัก](/img/frames/smooth-off-result.png)

## 3. เปิดสวิตช์แล้ววาดเลนเดียวกันอีกครั้ง

คลิก **On** ในแถว SMOOTH BOUNDARY คลิกเส้นกึ่งกลางที่คล้าย
กันที่อื่นบนผืนผ้าใบแล้วกด <kbd>Enter</kbd>

คราวนี้ขอบเขตจะถูกฟิตด้วย spline เลนจึงโค้งเรียบ:

![เลนที่โค้งวาดด้วย Smooth Boundary เปิด — ขอบเขตตามเส้นโค้งเรียบ](/img/frames/smooth-on-result.png)

เมื่อวางคู่กัน ความแตกต่างชัดเจน เส้นกึ่งกลางเหมือนกัน
เปลี่ยนเฉพาะกฎการสร้างขอบเขต

## เมื่อใดควรปิด เมื่อใดควรเปิด

| | Smooth = Off | Smooth = On |
| --- | --- | --- |
| ลักษณะ | หัก เป็นเหลี่ยม | โค้ง |
| เหมาะกับ | เลนตรง ขาทางแยก | ถนนโค้ง ทางลาด |
| ประสิทธิภาพ | ใช้ทรัพยากรน้อยกว่าเล็กน้อย | รูปทรงเพิ่มขึ้นเล็กน้อย |

สลับสวิตช์ได้บ่อยตามต้องการ เลนใหม่แต่ละเลนใช้ค่าใดก็ตาม
ที่ตั้งไว้เมื่อวาดเสร็จ

## สิ่งที่ได้เรียนรู้

- สวิตช์ Smooth Boundary อยู่ในพาเนลสร้าง Lane และมีผลกับ
  เลนที่จะวาดต่อไป ไม่ใช่เลนที่เลือก
- รูปทรงเส้นกึ่งกลางเหมือนกันทั้งสองโหมด เปลี่ยนเฉพาะ
  การเรนเดอร์ขอบเขต
