บทเรียนเป็นบทเรียนสั้น ๆ แบบลงมือทำ แต่ละบทพาผ่านงานหนึ่ง ๆ
จากต้นจนจบ เพื่อให้คุณเรียนรู้โปรแกรมแก้ไขโดยทำตาม

หากรู้แล้วว่าต้องการทำอะไรและต้องการเพียงขั้นตอน
[คู่มือวิธีทำ](/th/guides/) มักเหมาะกว่า

## บทเรียน

- [เริ่มต้นแบบรวดเร็ว](/th/start/quickstart/) — เลนและยานพาหนะ
  แรกของคุณในห้านาที
- [สามเลนแรก](/th/tutorials/your-first-lanes/) — โหมดสร้างสองโหมด
  ของเครื่องมือ Lane (Center Line และ Boundary)
- [ขอบเขตเลนแบบโค้งเรียบ](/th/tutorials/smooth-lanes/) — เปิด
  Smooth Boundary ก่อนวาดเส้นโค้ง
- [จำลองถนนจริงจากแผนที่](/th/tutorials/road-from-map/) — ลากตาม
  ถนนบนภาพถ่ายดาวเทียม พร้อมเครื่องมือสร้างคลิกเดียวเป็นทางลัด
- [สร้างฉากด้วย AI แล้วปรับด้วยมือ](/th/tutorials/ai-scene/) —
  อธิบายสถานการณ์ด้วยภาษาธรรมชาติและแก้ไขผลลัพธ์
