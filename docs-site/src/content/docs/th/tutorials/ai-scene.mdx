รับอินพุตภาษาธรรมชาติ OpenSCENARIO XML หรือ DSL แล้วสร้าง
ผืนผ้าใบที่แก้ไขได้

<Demo src="/videos/ai-scene-natural.mp4" caption="สถานการณ์ภาษาธรรมชาติ → ฉากที่แก้ไขได้บนผืนผ้าใบ" maxWidth="900px" />

## 1. เปิด AI Scene Generator

1. คลิก **Extensions** ที่มุมขวาล่างของผืนผ้าใบ
2. เลือก **AI Scene Generator**
3. เลือกผู้ให้บริการ AI (Anthropic Claude, OpenAI GPT หรือ
   Google Gemini) แล้ววาง API key ของคุณ คีย์จะถูกเก็บไว้ใน
   เบราว์เซอร์เท่านั้น

## 2. อธิบายฉาก

วางพรอมต์ในลักษณะนี้:

> ทางหลวง 3 เลนวิ่งจากซ้ายไปขวา รถ ego sedan (สีน้ำเงิน) อยู่ใน
> เลนกลาง รถบรรทุก (สีเทา) อยู่ในเลนขวาเยื้องไปข้างหน้าเล็กน้อย
> แสดงเส้นทางแบบประสำหรับรถ ego ที่กำลังเปลี่ยนเลนไปทางซ้าย

คลิก **Generate** ส่วนขยายจะวางเลน ยานพาหนะ และรูปทรง Path
ลงบนผืนผ้าใบ

## 3. ปรับแต่ง

ทุกอย่างที่สร้างขึ้นเป็นรูปทรงปกติ ลองทำดังนี้:

- เลือกรถบรรทุกแล้วเปลี่ยนเทมเพลตเป็น **Bus**
- ลากเส้นทางของรถ ego ไปยังเส้นโค้งอื่น
- เพิ่มคนเดินเท้าบนไหล่ทาง

## 4. หรือเริ่มจาก OpenSCENARIO

ในพาเนลเดียวกัน เปลี่ยนโหมดอินพุตเป็น **OpenSCENARIO XML**
แล้ววางไฟล์ `.xosc` ส่วนขยายจะวางตัวแสดงและวิถีบนผืนผ้าใบ —
วิธีที่เร็วที่สุดในการทำให้สถานการณ์ที่มีอยู่กลายเป็นภาพ

<Demo src="/videos/ai-scene-dsl.mp4" caption="ตัวอย่าง ASAM OpenSCENARIO DSL ที่วางบนผืนผ้าใบ" maxWidth="900px" />

## สิ่งที่ได้เรียนรู้

- การสร้างด้วย AI เป็นจุดเริ่มต้น — ทุกรูปทรงหลังจากนั้น
  แก้ไขได้เหมือนรูปทรงทั่วไปบนผืนผ้าใบ
- พาเนลเดียวกันรับทั้งพรอมต์ภาษาธรรมชาติและอินพุต OpenSCENARIO
  จึงสลับระหว่างความคิดคร่าว ๆ และข้อกำหนดทางการได้โดยไม่ต้อง
  ออกจากโปรแกรมแก้ไข
