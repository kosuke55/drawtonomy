## การสลับเครื่องมือ

| คีย์ | เครื่องมือ |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (แพน)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## การแก้ไข

| คีย์ | ฟังก์ชัน |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | เลิกทำ |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | ทำซ้ำ |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | คัดลอก |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | วาง |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | ตัด |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | ลบรูปทรงที่เลือก |

## ตัวปรับขณะวาด

| ตัวปรับ | ผล |
|---|---|
| <kbd>Shift</kbd> | ปิด [snap](/th/guides/snap/) ชั่วคราว |
| <kbd>Alt</kbd> + คลิก | [ใช้จุดที่มีอยู่ร่วม](/th/guides/point-sharing/) (Linestring / Polygon / Path) |
| ดับเบิลคลิก | เข้า [การแก้ไขเซกเมนต์](/th/guides/segment-editing/) (Linestring / Lane / Polygon) |

## การเคลื่อนย้าย

| คีย์ | ผล |
|---|---|
| ปุ่มลูกศร | เลื่อนการเลือกทีละ 1 px |
| <kbd>Shift</kbd> + ลูกศร | เลื่อนการเลือกทีละ 10 px |
