## What is drawtonomy?

drawtonomy is a browser-based whiteboard built for driving scenarios.
Place lanes, vehicles, pedestrians, traffic lights, and intersections, then export
to image formats, [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2),
or [ASAM OpenDRIVE / OpenSCENARIO](/guides/export-asam/) bundles ready for
[esmini](https://github.com/esmini/esmini).

It is used for autonomous-driving development, traffic planning, and
driving education.
