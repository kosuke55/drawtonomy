チュートリアルは短いハンズオン形式のレッスンです。各レッスンは 1 つのタスクをエンドツーエンドで進めていくので、実際に手を動かしながらエディタを覚えられます。

すでにやりたいことが決まっていて手順だけ知りたい場合は、[ハウツーガイド](/ja/guides/) のほうが向いています。

## レッスン

- [クイックスタート](/ja/start/quickstart/) — 5 分で最初のレーンと車両を配置。
- [最初の 3 本のレーン](/ja/tutorials/your-first-lanes/) — Lane ツールの 2 つの作成モード（Center Line と Boundary）を体験。
- [滑らかなレーン境界](/ja/tutorials/smooth-lanes/) — 曲線を描く前に Smooth Boundary を有効化する。
- [地図から実在の道路を再現する](/ja/tutorials/road-from-map/) — 衛星画像背景の上に道路をトレース。ワンクリックジェネレータも近道として紹介。
- [AI でシーンを生成し手作業で仕上げる](/ja/tutorials/ai-scene/) — 自然言語でシナリオを記述して結果を編集。
