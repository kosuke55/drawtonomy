## バグ報告・機能リクエスト・ご質問

➡ **[GitHub で Issue を作成する](https://github.com/kosuke55/drawtonomy/issues/new)**

バグ報告では、再現手順（実行ステップ＋期待される動作と実際の動作）を簡潔に書いていただけると大変助かります。
スクリーンショットや、不具合発生時に保存した `drawtonomy.svg` ファイルの添付も歓迎します。
