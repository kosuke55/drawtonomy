すべての図形は固有のスタイルを持ちます。エディタ全体のデフォルトを変更して、新しい図形が望む形で生成されるようにすることもできます。

<Demo src="/videos/style-demo.mp4" caption="属性パネルから図形ごとに色、不透明度、太さ、テンプレートバリアントを変更。" />

## 図形ごとのスタイル

1. <kbd>V</kbd> キーで Select に切り替え、図形をクリックします。
2. 右側の **属性パネル** に次の項目が表示されます:
   - **Color**（パレット + カスタム）
   - **Opacity**（0 ～ 100%）
   - **Width**（線状の図形向け）
   - **Style**（ソリッド / ダッシュ / テンプレートバリアント）

複数選択すれば、同じ変更を複数の図形に一括適用できます。

## デフォルト

例えば、新しいレーンの不透明度を常に 60% にするには:

1. **ハンバーガー** メニューを開きます。
2. **Defaults** を選びます。
3. **Lane** の値を変更します。

デフォルトは新しく作成される図形にのみ適用されます。既存の図形は変更されません。

## カラーパレット

drawtonomy は Tailwind 風のパレット（grey-100 ～ grey-900 と各カラー）を採用しています。完全なリストは [カラーパレットリファレンス](/ja/reference/color-palette/) を参照してください。
