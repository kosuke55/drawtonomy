セグメント編集を使えば、図形をゼロから描き直さずに、隣接する 2 頂点間の調整、新しい頂点の追加、頂点の削除ができます。

<Demo src="/videos/segment-demo.mp4" caption="ダブルクリックでセグメント編集モードに入り、点をドラッグするかセグメントをクリックして点を追加。" />

## セグメント編集モードに入る

1. <kbd>V</kbd> キーで Select ツールに切り替えます。
2. Linestring、レーン、ポリゴンをダブルクリックします。
3. 図形が点編集モードに切り替わり、各頂点がドラッグ可能な藍色のハンドルになります。

## 点を移動する

頂点をクリックしてドラッグします。点が他の図形と共有されている場合（[点共有](/ja/guides/point-sharing/) を参照）、その点を持つすべての図形が一緒に動きます。

レーンの場合、境界点をドラッグするとその境界を共有する両方のレーンが更新されます — 詳細は [レーン接続モデル](/ja/explanation/lane-model/) を参照。

## 点を追加する

セグメント上（既存の 2 点を結ぶ線上）の任意の場所をクリックします。クリック位置に新しい頂点が挿入されます。

直線部分にカーブを導入する最速の方法は、点を追加してドラッグすることです。

## 点を削除する

頂点を選択（藍色で塗りつぶし表示になります）して <kbd>Delete</kbd> または <kbd>Backspace</kbd> を押します。

## セグメント編集を抜ける

<kbd>Esc</kbd> を押すか、図形の外をクリックするか、別のツールを選びます。図形は通常の選択モードに戻ります。
