drawtonomy は角ばったポリラインの代わりに、スプライン補間されたレーン境界を生成できます。トグルは Lane 作成パネルにあり、これから描くレーンに適用されます — 既存のレーンを後から滑らかにすることはありません。

<Demo src="/videos/smooth-lane.mp4" caption="同じレーンを Smooth Boundary OFF（左、角ばっている）と ON（右、滑らか）で描いた比較。" />

## トグルの場所

<kbd>N</kbd> キーで Lane ツールを起動します。右側のパネルに **SMOOTH BOUNDARY** 行があり、**On** と **Off** ボタンが並んでいます。

![Lane 作成パネル — SMOOTH BOUNDARY トグルがハイライト、現在は Off](/img/frames/smooth-toggle-off.png)

デフォルトは **Off** です。センターラインをクリックし始める前に ON に切り替えてください。

## 比較

下のスクリーンショットは同じセンターラインで描いたものです。違いはトグルだけです。

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![Smooth OFF で描いた角ばった曲線](/img/frames/smooth-off-result.png) | ![Smooth ON で描いた滑らかな曲線](/img/frames/smooth-on-result.png) |

OFF のときは、各センターラインクリック間の境界が直線セグメントになります。ON のときは、同じセンターラインが曲線にフィッティングされます。

## セッション中に切り替える

トグルはいつでも切り替えられます。新しいレーンは次にクリックしたときの値を採用します。既存のレーンは描画時の境界スタイルを保持し続けます。
