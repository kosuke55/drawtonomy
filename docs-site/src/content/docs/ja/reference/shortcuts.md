## ツール切り替え

| キー  | ツール                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand（パン）             |
| <kbd>V</kbd>    | Select（選択）           |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants（車両 / 歩行者） |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## 編集操作

| キー | 機能 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | 元に戻す（Undo） |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | やり直す（Redo） |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | コピー |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | 貼り付け |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | 切り取り |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 選択中の図形を削除 |

## 描画中の修飾キー

| 修飾キー | 効果 |
|---|---|
| <kbd>Shift</kbd> | [スナップ](/ja/guides/snap/) を一時的に無効化 |
| <kbd>Alt</kbd> + クリック | [既存の点を共有](/ja/guides/point-sharing/)（Linestring / Polygon / Path） |
| ダブルクリック | [セグメント編集](/ja/guides/segment-editing/) に入る（Linestring / Lane / Polygon） |

## 移動

| キー | 効果 |
|---|---|
| 矢印キー | 選択を 1 px 移動 |
| <kbd>Shift</kbd> + 矢印キー | 選択を 10 px 移動 |
