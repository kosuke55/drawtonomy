Dies ist die zweite kurze Lektion nach
[Ihre ersten drei Fahrspuren](/de/tutorials/your-first-lanes/). Eine
kleine Gewohnheit: Schalten Sie **Smooth Boundary** ein, bevor Sie
eine kurvige Fahrspur zeichnen.

Der Toggle befindet sich im Lane-Erstellungspanel und ändert, wie die
Ränder für die als Nächstes gezeichneten Fahrspuren erzeugt werden.
Bestehende Fahrspuren bleiben unangetastet.

<Demo src="/videos/smooth-lane.mp4" caption="Dieselbe kurvige Mittellinie zweimal gezeichnet — einmal mit ausgeschaltetem Smooth Boundary, einmal mit eingeschaltetem." />

## 1. Lane-Panel öffnen

Drücken Sie <kbd>N</kbd> für das Lane-Werkzeug. Das rechte Panel
öffnet sich. Suchen Sie die Zeile **SMOOTH BOUNDARY** — der Standard
ist **Off**:

![Lane-Erstellungspanel — Zeile SMOOTH BOUNDARY, derzeit auf Off gesetzt](/img/frames/smooth-toggle-off.png)

## 2. Eine kurvige Fahrspur mit ausgeschaltetem Toggle zeichnen

Lassen Sie den Toggle auf **Off**. Klicken Sie auf den Canvas, um
Mittellinienpunkte entlang einer Kurve zu setzen, und drücken Sie
<kbd>Enter</kbd> zum Abschluss.

Die Ränder sind gerade Segmente zwischen aufeinanderfolgenden Punkten,
sodass die Fahrspur eckig ausfällt:

![Mit ausgeschaltetem Smooth Boundary gezeichnete kurvige Fahrspur — Ränder sind eckige Polylinien](/img/frames/smooth-off-result.png)

## 3. Toggle einschalten und dieselbe Fahrspur erneut zeichnen

Klicken Sie in der Zeile SMOOTH BOUNDARY auf **On**. Klicken Sie eine
ähnliche Mittellinie an einer anderen Stelle des Canvas und drücken
Sie <kbd>Enter</kbd>.

Diesmal werden die Ränder per Spline angepasst, sodass die Fahrspur
gleichmäßig kurvt:

![Mit eingeschaltetem Smooth Boundary gezeichnete kurvige Fahrspur — Ränder folgen einer glatten Kurve](/img/frames/smooth-on-result.png)

Nebeneinander ist der Unterschied offensichtlich. Die Mittellinien
sind identisch; nur die Regel zur Randerzeugung hat sich geändert.

## Wann ausgeschaltet lassen, wann einschalten

| | Smooth = Off | Smooth = On |
| --- | --- | --- |
| Optik | Eckig, facettiert | Geschwungen |
| Geeignet für | Gerade Fahrspuren, Kreuzungsschenkel | Kurvige Straßen, Auffahrten |
| Performance | Etwas günstiger | Etwas mehr Geometrie |

Sie können den Toggle so oft wechseln, wie Sie möchten. Jede neue
Fahrspur übernimmt den Wert, der beim Abschluss des Zeichnens gesetzt
ist.

## Was Sie gelernt haben

- Der Toggle Smooth Boundary lebt im Lane-Erstellungspanel und gilt
  für die nächste gezeichnete Fahrspur, nicht für die ausgewählte.
- Die Mittellinien-Geometrie ist in beiden Modi identisch; nur die
  Rand-Darstellung unterscheidet sich.
