Fünf Minuten vom leeren Canvas bis zur exportierten Szene. Keine
Installation.

## 1. App öffnen

Rufen Sie [drawtonomy.com](https://drawtonomy.com) auf. Alles läuft
im Browser; nichts wird hochgeladen.

## 2. Eine Fahrspur zeichnen

1. Drücken Sie <kbd>N</kbd> oder klicken Sie in der Werkzeugleiste
   auf das **Lane**-Werkzeug.
2. Klicken Sie auf den Canvas, um den Anfang der Mittellinie zu
   setzen, klicken Sie erneut für den nächsten Stützpunkt und drücken
   Sie <kbd>Enter</kbd>, um abzuschließen.
3. Der linke und rechte Rand erscheinen automatisch.

:::tip
Halten Sie <kbd>Shift</kbd> beim Zeichnen, um [Snap](/de/guides/snap/)
für diesen Klick zu umgehen.
:::

## 3. Ein Fahrzeug platzieren

1. Drücken Sie <kbd>P</kbd>, um das Werkzeug **Participants** zu
   öffnen.
2. Wählen Sie **Vehicle → Sedan** und klicken Sie auf die Fahrspur,
   die Sie gerade gezeichnet haben.
3. Ziehen Sie an einem Eckanfasser, um die Größe zu ändern, oder
   verwenden Sie den Rotationsanfasser, um es an der Fahrspur
   auszurichten.

## 4. Die Szene exportieren

Öffnen Sie das Export-Menü und wählen Sie ein Format:

- **PNG / SVG / PDF** — als flaches Bild teilen.
- **drawtonomy.svg** — speichert jede Verbindung, sodass Sie (oder
  Teamkollegen) die Datei später erneut öffnen und weiterbearbeiten
  können.
- **Export für esmini** — ein ZIP mit OpenDRIVE + OpenSCENARIO,
  bereit zum Abspielen in
  [esmini](https://github.com/esmini/esmini).

[Szene exportieren](/de/guides/export/) behandelt die Formate im
Detail.
