## Werkzeugwechsel

| Taste  | Werkzeug                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (Schwenken)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Bearbeitungsoperationen

| Tasten | Funktion |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Rückgängig |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Wiederherstellen |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Kopieren |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Einfügen |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Ausschneiden |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Ausgewählte Form(en) löschen |

## Modifikatoren beim Zeichnen

| Modifikator | Wirkung |
|---|---|
| <kbd>Shift</kbd> | [Snap](/de/guides/snap/) vorübergehend deaktivieren |
| <kbd>Alt</kbd> + Klick | [Vorhandenen Punkt teilen](/de/guides/point-sharing/) (Linestring / Polygon / Path) |
| Doppelklick | [Segmentbearbeitung](/de/guides/segment-editing/) öffnen (Linestring / Lane / Polygon) |

## Bewegung

| Tasten | Wirkung |
|---|---|
| Pfeiltasten | Auswahl um 1 px verschieben |
| <kbd>Shift</kbd> + Pfeil | Auswahl um 10 px verschieben |
