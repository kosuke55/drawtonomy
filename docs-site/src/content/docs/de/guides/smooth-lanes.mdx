drawtonomy kann Spurränder als Spline statt als eckige Polylinien
erzeugen. Der Toggle befindet sich im Lane-Erstellungspanel und gilt
für die als Nächstes gezeichneten Fahrspuren; eine bestehende Spur
wird nicht rückwirkend geglättet.

<Demo src="/videos/smooth-lane.mp4" caption="Eine Fahrspur mit ausgeschaltetem Smooth Boundary (links, eckig) und mit eingeschaltetem (rechts, glatt)." />

## Wo der Toggle sitzt

Drücken Sie <kbd>N</kbd> für das Lane-Werkzeug. Das rechte Panel
enthält eine Zeile **SMOOTH BOUNDARY** mit den Buttons **On** und
**Off**:

![Lane-Erstellungspanel — Toggle SMOOTH BOUNDARY hervorgehoben, derzeit auf Off](/img/frames/smooth-toggle-off.png)

Standard ist **Off**. Schalten Sie ihn ein, bevor Sie die
Mittellinie zu klicken beginnen.

## Vergleich

Die beiden Screenshots unten wurden mit derselben Mittellinie
gezeichnet. Geändert hat sich nur der Toggle:

| Smooth Boundary = Off | Smooth Boundary = On |
| --- | --- |
| ![Eckige Kurve mit ausgeschaltetem Smoothing gezeichnet](/img/frames/smooth-off-result.png) | ![Glatte Kurve mit eingeschaltetem Smoothing gezeichnet](/img/frames/smooth-on-result.png) |

Mit ausgeschaltetem Toggle wird jedes Paar von
Mittellinien-Klicks zu einem geraden Randsegment. Mit
eingeschaltetem Toggle wird dieselbe Mittellinie an eine Kurve
angepasst.

## Mitten in einer Sitzung umschalten

Sie können den Toggle jederzeit umschalten. Neue Fahrspuren
übernehmen den aktuellen Wert beim nächsten Klick. Bestehende
Fahrspuren behalten den Randstil, mit dem sie gezeichnet wurden.
