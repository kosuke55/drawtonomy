Der Lane Generator zieht reale Straßengeometrie aus OpenStreetMap
und wandelt sie in editierbare Lane-Formen um, die zum
Kartenhintergrund ausgerichtet sind.

<Demo src="/videos/map-to-lane-demo.mp4" caption="Klicken Sie auf eine Straße für eine Spur, ziehen Sie eine Region auf für viele." maxWidth="900px" />

## Kartenhintergrund einschalten

1. Öffnen Sie das Menü **Background** oben links auf dem Canvas.
2. Wählen Sie **Satellite** (fotografisch) oder **Roadmap**
   (schematisch).
3. Schwenken und zoomen Sie zum gewünschten Bereich.

Die Karte wird hinter dem Canvas gezeichnet und bleibt beim
Zeichnen verankert.

## Eine einzelne Fahrspur erzeugen

1. Drücken Sie <kbd>N</kbd> für das Lane-Werkzeug.
2. Aktivieren Sie in der Werkzeugleiste den Modus **Generator**.
3. Bewegen Sie den Mauszeiger über eine Straße. drawtonomy hebt
   das gefundene OSM-Straßensegment unter dem Cursor hervor.
4. Klicken Sie. Das Segment wird abgerufen und in eine Lane-Form
   umgewandelt.

## Jede Straße in einer Region erzeugen

Mit eingeschaltetem Generator-Modus:

1. Ziehen Sie ein Rechteck über den gewünschten Bereich.
2. Lassen Sie los. Jede Straße innerhalb des Rechtecks wird in
   einem Durchgang in eine Lane umgewandelt.

Nützlich für ganze Kreuzungen, Stadtviertel oder Testgelände.

## Empfohlene Grenzen

Der OSM-Abruf und die Konvertierung laufen im Browser. Für
reaktionsfähiges Bearbeiten halten Sie die resultierende Szene
unter etwa **500 Fahrspuren** — teilen Sie einen größeren Bereich
auf mehrere Dateien auf, falls Sie mehr brauchen.

## Nach der Erzeugung

Erzeugte Fahrspuren sind ganz normale Lane-Formen. Sie können:

- Punkte ziehen, um die Geometrie zu verfeinern.
- [Smooth](/de/guides/smooth-lanes/) anwenden, um dichte Polylinien
  durch Splines zu ersetzen.
- [Verbindungen](/de/guides/lane-connections/) setzen, wo der
  Generator sie nicht automatisch ableiten konnte.
- Fahrzeuge, Fußgänger oder Pfade darüber legen.
