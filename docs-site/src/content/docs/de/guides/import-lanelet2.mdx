drawtonomy kann
[Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)-Karten
im OSM-Format lesen. Beispielkarten finden Sie in der
[Autoware-Dokumentation](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="Eine vollständige Lanelet2-Datei wird importiert." />

## Die ganze Datei importieren

1. Öffnen Sie das Menü **File** → **Import**.
2. Wählen Sie die `.osm`-Datei.
3. drawtonomy parst die Datei und füllt den Canvas mit Lane-Formen
   samt ihrer Verbindungen.

## Nur bestimmte Fahrspuren importieren

Bei großen Karten verlangsamt der Import jeder Spur den Editor.
Verwenden Sie stattdessen den Auswahldialog:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="Per Drag-Auswahl nur die gewünschten Fahrspuren wählen, dann importieren." />

1. Öffnen Sie das Menü **File** → **Import → Select lanes**.
2. drawtonomy zeigt eine Vorschaukarte.
3. Klicken oder ziehen Sie, um die gewünschten Fahrspuren
   auszuwählen.
4. Klicken Sie auf **Import selection**.

## Performance-Tipps

Halten Sie die importierte Szene unter etwa **500 Fahrspuren** für
einen reaktionsfähigen Editor. Bei größeren Bereichen teilen Sie
Ihre Arbeit auf mehrere Dateien auf oder importieren nur die
benötigte Region.

## Nach dem Import

Importierte Fahrspuren sind vollwertige Lane-Formen; die
Verbindungen aus der Lanelet2-Datei bleiben erhalten. Bearbeiten,
[glätten](/de/guides/smooth-lanes/) oder
[zurück exportieren](/de/guides/export-asam/) — ohne Topologieverlust.
