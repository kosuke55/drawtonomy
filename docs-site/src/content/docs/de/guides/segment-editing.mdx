Die Segmentbearbeitung erlaubt Ihnen, Formen zwischen zwei
benachbarten Stützpunkten anzupassen, einen neuen Stützpunkt
hinzuzufügen oder einen zu löschen — ohne die Form von Grund auf
neu zu zeichnen.

<Demo src="/videos/segment-demo.mp4" caption="Doppelklick öffnet den Segmentbearbeitungs-Modus; danach ziehen Sie einen Punkt oder klicken auf ein Segment, um einen neuen einzufügen." />

## In den Segmentbearbeitungs-Modus wechseln

1. Drücken Sie <kbd>V</kbd> für das Select-Werkzeug.
2. Doppelklicken Sie auf einen Linestring, eine Lane oder ein
   Polygon.
3. Die Form wechselt in den Punkt-Editor-Modus: Jeder Stützpunkt
   wird zu einem ziehbaren indigofarbenen Anfasser.

## Einen Punkt verschieben

Klicken und ziehen Sie einen Stützpunkt. Wenn der Punkt mit einer
anderen Form geteilt ist (siehe
[Punktteilung](/de/guides/point-sharing/)), bewegen sich alle Formen,
die ihn halten, gemeinsam.

Bei Fahrspuren aktualisiert das Ziehen eines Randpunkts beide
Fahrspuren, die den Rand teilen — siehe
[Spurverbindungsmodell](/de/explanation/lane-model/).

## Einen Punkt hinzufügen

Klicken Sie irgendwo auf ein Segment (die Linie zwischen zwei
vorhandenen Punkten). An der Klickposition wird ein neuer
Stützpunkt eingefügt.

Das ist der schnellste Weg, eine Kurve in einen zuvor geraden
Abschnitt einzubringen: Punkt hinzufügen, dann ziehen.

## Einen Punkt entfernen

Wählen Sie den Stützpunkt aus (er wird vollindigo) und drücken Sie
<kbd>Delete</kbd> oder <kbd>Backspace</kbd>.

## Segmentbearbeitung verlassen

Drücken Sie <kbd>Esc</kbd>, klicken Sie außerhalb der Form oder
wählen Sie ein anderes Werkzeug. Die Form kehrt in den normalen
Auswahlmodus zurück.
