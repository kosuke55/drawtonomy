drawtonomy kann Ihre Szene als ASAM
[OpenDRIVE](https://www.asam.net/standards/detail/opendrive/)
(`.xodr`) und
[OpenSCENARIO](https://www.asam.net/standards/detail/openscenario/)
(`.xosc`) exportieren oder beides als ZIP für die
[esmini](https://github.com/esmini/esmini)-Wiedergabe bündeln.

![Eine drawtonomy-Szene nach dem Export in esmini wiedergegeben](/img/asam-esmini.png)

## Aus dem Editor exportieren

1. Zeichnen Sie Ihre Szene (Fahrspuren, Fahrzeuge, Ampeln …).
2. Öffnen Sie **File → Export → Export for esmini**.
3. Geben Sie auf Aufforderung einen Basisnamen ein.
4. Eine Datei `<name>.zip` mit `<name>.xodr` und `<name>.xosc`
   wird heruntergeladen.

## Wiedergeben

```bash
unzip my-scene.zip
esmini --osc my-scene/my-scene.xosc --window 60 60 1024 768
```

## Einzelne Formate

Wenn Sie nur eines der beiden brauchen:

- **File → Export → OpenDRIVE (.xodr)**
- **File → Export → OpenSCENARIO (.xosc)**

## Programmatischer Export

Der Exporter ist Teil von `@drawtonomy/sdk` und läuft ohne den
Editor. Setzen Sie ihn in CI-Pipelines, serverseitigem Tooling
oder Browser-Erweiterungen ein:

```ts
import { exporter, createSnapshot } from '@drawtonomy/sdk'

const snapshot = createSnapshot(shapes)
const { blob, baseName } = exporter.buildEsminiZip(snapshot, {
  baseName: 'my-scene',
})
```

Für die vollständige API und Erweiterungspunkte siehe die
[Exporter-SDK-Referenz](/de/extend/exporter-sdk/).
