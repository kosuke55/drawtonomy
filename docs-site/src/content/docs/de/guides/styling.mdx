Jede Form trägt ihren eigenen Stil. Sie können außerdem die
Editor-weiten Standardwerte ändern, sodass neue Formen gleich so
beginnen, wie Sie es möchten.

<Demo src="/videos/style-demo.mp4" caption="Pro Form: Farbe, Deckkraft, Breite und Vorlagenvariante über das Attribute Panel." />

## Stil pro Form

1. Drücken Sie <kbd>V</kbd> für Select und klicken Sie auf eine
   Form.
2. Das **Attribute Panel** rechts zeigt:
   - **Color** (Palette + benutzerdefiniert)
   - **Opacity** (0–100 %)
   - **Width** (für linienartige Formen)
   - **Style** (durchgehend / gestrichelt / Vorlagenvariante)

Mehrfachauswahl, um dieselbe Änderung gleichzeitig auf mehrere
Formen anzuwenden.

## Standardwerte

Damit jede neue Fahrspur z. B. mit 60 % Deckkraft beginnt:

1. Öffnen Sie das **Hamburger**-Menü.
2. Wählen Sie **Defaults**.
3. Ändern Sie den Wert unter **Lane**.

Standardwerte greifen für neu erzeugte Formen. Bestehende Formen
bleiben unangetastet.

## Farbpalette

drawtonomy verwendet eine Palette im Tailwind-Stil (grey-100 bis
grey-900 plus Farben). Die vollständige Liste finden Sie in der
[Farbpalette-Referenz](/de/reference/color-palette/).
