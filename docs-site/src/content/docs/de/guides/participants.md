drawtonomy bringt Vorlagen für die Akteure und Verkehrselemente mit,
die Sie in Fahrszenarien benötigen.

## Fahrzeuge

1. Drücken Sie <kbd>P</kbd>, um **Participants** zu öffnen.
2. Wählen Sie eine Fahrzeugvorlage (Sedan, Bus, Lkw, Motorrad).
3. Klicken Sie auf den Canvas, um es zu platzieren. Das Fahrzeug
   wird in der Standardgröße der Vorlage abgesetzt.

Ziehen Sie an einem Eckanfasser, um die Größe zu ändern. Ziehen
Sie am Rotationsanfasser, um es an einer Fahrspur auszurichten.

## Fußgänger

Im selben Participants-Menü wählen Sie eine Fußgängervorlage
(Walking, Simple).

## Ampeln

Das Participants-Menü enthält außerdem Ampeln für Fahrzeuge und
Fußgänger. Platzieren Sie sie an Kreuzungsecken. Sie sind statische
Formen; sie führen keine Signalphase aus.

## Eigene Vorlagen

Sie können eigene SVG-Vorlagen hinzufügen und per PR beisteuern.
Siehe den
[Template Guide](https://github.com/kosuke55/drawtonomy/blob/main/templates/TEMPLATE_GUIDE.md).

## Einen Pfad mit Fahrzeugen füllen

Um eine Reihe von Fahrzeugen entlang eines Pfads zu platzieren
(für Folgeabstands-Diagramme oder Follow-the-Leader-Szenen),
verwenden Sie [Path Footprint](/de/guides/path-footprint/).
