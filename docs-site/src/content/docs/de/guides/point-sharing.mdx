Ein *geteilter Punkt* ist ein einzelner Stützpunkt, auf den mehrere
Formen verweisen. Bewegen Sie ihn einmal, folgt jede Form, die ihn
referenziert. Damit halten Sie aneinandergrenzende Spurränder,
Polygonecken und Pfadgelenke fest miteinander verbunden.

<Demo src="/videos/share-demo.mp4" caption="Halten Sie Alt + Klick, um einen vorhandenen Punkt mit einer neuen Form zu teilen." />

## Einen geteilten Punkt beim Zeichnen erzeugen

1. Wählen Sie das Linestring- (<kbd>L</kbd>), Polygon-
   (<kbd>G</kbd>) oder Path-Werkzeug (<kbd>H</kbd>).
2. Halten Sie <kbd>Alt</kbd> (Option auf macOS).
3. Klicken Sie auf einen vorhandenen Stützpunkt einer anderen Form.

Die neue Form erhält einen Stützpunkt, der mit dem vorhandenen
*geteilt* ist — nicht nur auf dieselbe Koordinate gesnappt.

## Einen vorhandenen Stützpunkt in einen geteilten umwandeln

1. Doppelklicken Sie auf eine Form, um in die
   [Segmentbearbeitung](/de/guides/segment-editing/) zu wechseln.
2. Halten Sie <kbd>Alt</kbd> und ziehen Sie einen Stützpunkt auf
   einen vorhandenen.

## Visueller Hinweis

Geteilte Punkte erscheinen im Segmentbearbeitungs-Modus als
doppelter Anfasser. Einfach gesnappte Punkte erscheinen als
einzelner Anfasser.
