## Verktygsväxling

| Tangent  | Verktyg                              |
| ---- | --------------------------------- |
| <kbd>M</kbd>    | Hand (panorera)                |
| <kbd>V</kbd>    | Select                    |
| <kbd>L</kbd>    | Linestring                |
| <kbd>N</kbd>    | Lane                      |
| <kbd>P</kbd>    | Participants (Vehicle / Pedestrian) |
| <kbd>H</kbd>    | Path                      |
| <kbd>G</kbd>    | Polygon                   |
| <kbd>X</kbd>    | Crosswalk                 |
| <kbd>I</kbd>    | Intersection              |
| <kbd>W</kbd>    | LineArrow                 |
| <kbd>T</kbd>    | Text                      |
| <kbd>D</kbd>    | Freehand                  |

## Redigeringsoperationer

| Tangenter | Funktion |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Z</kbd> | Ångra |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Gör om |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Cmd</kbd>+<kbd>C</kbd> | Kopiera |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Cmd</kbd>+<kbd>V</kbd> | Klistra in |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Cmd</kbd>+<kbd>X</kbd> | Klipp ut |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Ta bort vald(a) form(er) |

## Modifierare under ritning

| Modifierare | Effekt |
|---|---|
| <kbd>Shift</kbd> | Inaktivera tillfälligt [snap](/sv/guides/snap/) |
| <kbd>Alt</kbd> + klick | [Dela en befintlig punkt](/sv/guides/point-sharing/) (Linestring / Polygon / Path) |
| Dubbelklick | Gå in i [segmentredigering](/sv/guides/segment-editing/) (Linestring / Lane / Polygon) |

## Förflyttning

| Tangenter | Effekt |
|---|---|
| Piltangenter | Flytta urval med 1 px |
| <kbd>Shift</kbd> + pil | Flytta urval med 10 px |
