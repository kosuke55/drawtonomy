drawtonomy kan läsa [Lanelet2](https://github.com/fzi-forschungszentrum-informatik/Lanelet2)-kartor
i OSM-format. Exempelkartor finns från
[Autoware-dokumentationen](https://autowarefoundation.github.io/autoware-documentation/main/demos/planning-sim/#download-the-sample-map).

<Demo src="/videos/lanelet-import-demo.mp4" caption="Importera en hel Lanelet2-fil." />

## Importera hela filen

1. Öppna **File**-menyn → **Import**.
2. Välj `.osm`-filen.
3. drawtonomy parsar filen och fyller canvasen med Lane-former
   plus deras kopplingar.

## Importera bara specifika körfält

För stora kartor kommer det att sakta ner redigeraren att
importera varje körfält. Använd dialogrutan för körfältsval
istället:

<Demo src="/videos/lanelet-select-import-demo.mp4" caption="Markera bara de körfält du bryr dig om med dragmarkering, och importera sedan." />

1. Öppna **File**-menyn → **Import → Select lanes**.
2. drawtonomy visar en förhandsgranskningskarta.
3. Klicka eller dra för att välja de körfält du vill ha.
4. Klicka på **Import selection**.

## Prestandatips

Håll den importerade scenen under cirka **500 körfält** för en
responsiv redigerare. För större ytor, dela upp ditt arbete över
flera filer, eller importera bara den region du behöver.

## Efter import

Importerade körfält är fullkvalitativa Lane-former; kopplingarna
från Lanelet2-filen bevaras. Redigera,
[mjuka](/sv/guides/smooth-lanes/) eller
[exportera tillbaka](/sv/guides/export-asam/) utan att förlora
topologi.
