Fem minuter från en tom canvas till en exporterad scen. Ingen
installation.

## 1. Öppna appen

Gå till [drawtonomy.com](https://drawtonomy.com). Allt körs i
webbläsaren; inget laddas upp.

## 2. Rita ett körfält

1. Tryck på <kbd>N</kbd>, eller klicka på verktyget **Lane** i
   verktygsfältet.
2. Klicka på canvasen för att placera startpunkten för
   mittlinjen, klicka igen för nästa hörn, och tryck på
   <kbd>Enter</kbd> för att avsluta.
3. Vänster och höger gränser visas automatiskt.

:::tip
Håll <kbd>Shift</kbd> medan du ritar för att kringgå
[snap](/sv/guides/snap/) för det klicket.
:::

## 3. Placera ett fordon

1. Tryck på <kbd>P</kbd> för att öppna verktyget **Participants**.
2. Välj **Vehicle → Sedan** och klicka på körfältet du just ritat.
3. Dra ett hörnhandtag för att ändra storlek, eller använd
   rotationshandtaget för att linjera det med körfältet.

## 4. Exportera scenen

Öppna exportmenyn och välj ett format:

- **PNG / SVG / PDF** — dela som en platt bild.
- **drawtonomy.svg** — sparar varje koppling så att du (eller en
  kollega) kan öppna igen och fortsätta redigera senare.
- **Export for esmini** — en zip med OpenDRIVE + OpenSCENARIO som
  är klar att spelas upp i [esmini](https://github.com/esmini/esmini).

[Exportera din scen](/sv/guides/export/) går igenom formaten i detalj.
